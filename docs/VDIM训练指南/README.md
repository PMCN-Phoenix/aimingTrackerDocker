## 📋 每份指南的固定结构

每个 Day 指南都包含以下 7 个部分，方便快速定位：

1. **本质定义** —— 这个主题在练什么
2. **5 个核心技术** —— 可实操、可固化的技术要点（🔑 标记）
3. **场景逐个拆解** —— 12 个场景分别练什么、注意什么
4. **首次打完整流程** —— 热身→主训练→打完后复盘
5. **进步的感觉** —— 主观阶段 + 客观指标
6. **半途而废陷阱** —— 3 个最常见陷阱 + 避开方法
7. **一句话总结** —— 打训练前看这一句就够了

## 📝 使用建议

1. **打训练前 1 分钟**：打开对应 Day 指南，看第七节"一句话总结"和第二节的 5 个核心技术标题
2. **训练中卡住时**：翻到第三节"场景逐个拆解"，找到对应场景看注意事项
3. **打完后复盘时**：用第五节"进步的感觉"自检，记录今天哪次感觉"对了"
4. **连续几天没进步时**：看第六节"半途而废陷阱"，对照自己是不是踩了陷阱
