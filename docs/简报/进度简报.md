## 术语表（项目自造口径，勿用通用定义曲解）

| 术语 | 定义 |
|---|---|
| **相对 PB** | 当轮分数 ÷ 该场景历史最高分 × 100%，用于剥离场景差异看当天状态 |
| **Monotony（训练单调性）** | 周日均轮次 ÷ 周内日轮次标准差（Foster 1998 的轮次代理版）；>2.0 视为警戒 |
| **三层量化** | 动作层（急停/peek 帧数）与结果层（DD/KAST/FK-FD）可信；练习分数层（Kovaak 分数）远迁移证据≈0，只当状态闸门 |
| **形态纯度** | 独成立 ÷ (独成立 + 摩擦)，衡量"不依赖队友也能打的动作占比"，≥80% 形态成立 |
| **独成立动作** | 成立不需要任何队友执行"我请求的事"的动作（trade 算：队友先接触是环境信号不是执行前提） |
| **DD 德尔塔** | 每回合造成伤害 − 受到伤害，比爆头率更干净的枪法结果指标 |
| **假过** | 结果门过、过程门不过——分数撞线但中位数/衰减/离散度不合格。用来把"运气"从"能力"里剥出来，与真过区分 |
