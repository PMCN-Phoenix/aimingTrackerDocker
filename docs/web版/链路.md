## 4. 四重检验标准

每个模块实现后必须通过四重检验：

1. **单元检验**：单个数据点 / 接口是否正确（比如查一条数据，确认值对不对）
2. **交叉检验**：格式 / 协议是否正确（比如 API 返回的 JSON 格式对不对）
3. **代码检验**：逻辑是否正确（比如边界情况、异常处理）
4. **端到端检验**：实际效果是否正确（比如浏览器打开页面，看和 Grafana 对比是不是一样）

模块之间需要做**集成测试**，确认模块之间的接口能正常对接。


## 6. 各文档必含内容

### 1. 数据库设计文档
- 现有 measurement 盘点：`aim_scenario / aim_reflection / aim_daylist / aim_bench`
- 每个 measurement 的 tag、field、时间戳格式
- 关键查询模式：按场景查成绩、按日期查清单、按场景查感悟
- 和现有 Python 脚本的映射关系

### 2. API 设计文档
- REST 前缀 `/api`：`/days /scenarios /scores /reflections /daylists /stats`
- 所有接口的请求参数、返回格式、错误码
- 生成 OpenAPI 文档作为契约底稿

### 3. 后端模块设计文档
- 分层：`API Layer → Service Layer → Repository Layer → InfluxDB`
- 模块：`api / core / repositories / services / scripts`
- 依赖方向：`DaylistService → BenchmarkService → ReflectionService → InfluxDBClient`
- 复用现有 Python 脚本（bench_rows / daylist_sync 等）

### 4. 前端信息架构与页面设计文档
- 页面：Daylist Dashboard / Scenario Detail / History Chart / Settings
- 路由与状态：React Router + TanStack Query（Server State）+ Zustand（UI State）
- **对照 Grafana**：逐面板映射"Grafana 已有 → React 实现"
- 组件拆分：完成度面板、成绩对比面板、历史曲线面板、感悟弹窗

### 5. 核心交互流程文档
- 主闭环：选清单 → 看完成度 → 看成绩对比 → 点场景看历史 → 写感悟
- 跨天统计流程：选多天 → 自动汇总 → 展示总和
- 数据更新流程：点按钮 → 触发脚本 → 刷新数据

### 6. 数据接入设计文档
- 复用现有脚本：`bench_rows.py / daylist_sync.py / aimlab_import.py`
- 触发方式：API 调用 / 手动运行 / 定时任务
- 幂等导入：重复运行不产生重复数据

### 7. 看板渲染设计文档
- **对照 Grafana 现有 3 个面板**：
  - 今日清单·完成度（gapit 自绘表格）
  - 今日清单·目标对比（gapit 自绘表格）
  - $scenario 历史曲线（timeseries 折线图）
- 每个面板的：数据格式、组件结构、交互（点击弹窗）
- 感悟弹窗：当天成绩 + 目标对比 + 历史感悟

### 8. 感悟系统设计文档
- 感悟存储：`aim_reflection` measurement，tag=scenario，field=note
- 展示：当天感悟 + 最近 3 天历史感悟
- 写入：从前端写入 API → 存 InfluxDB

### 9. 清单系统设计文档
- 清单存储：`aim_daylist` measurement，meta 存 start_ts / end_ts
- 跨天统计：按日期范围查询，自动汇总
- 清单管理：创建 / 修改 / 删除清单

### 10. 部署与运行设计文档
- 后端：FastAPI + uvicorn，端口 8000
- 前端：Vite 开发模式 / 生产构建
- 启动方式：`./start.sh` 一键启动前后端
- 开发模式：前端热更新，后端自动重载

### 11. 开发任务拆解与里程碑
- 里程碑：
  - **M0 项目骨架**（FastAPI + React 初始化 + InfluxDB 连接验证）
  - **M1 基础 API**（场景列表 + 成绩查询 + 日期查询）
  - **M2 完成度面板**（对照 Grafana 还原）
  - **M3 成绩对比面板**（对照 Grafana 还原）
  - **M4 历史曲线 + 感悟弹窗**（对照 Grafana 还原）
  - **M5 数据接入 + 清单管理**（复用现有脚本）
  - **M6 部署优化**（一键启动 + 性能优化）
- 每个里程碑绑定验收标准（对照 Grafana 现有效果逐项验证）
