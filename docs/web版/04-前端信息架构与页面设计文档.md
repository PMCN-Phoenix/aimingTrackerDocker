# 04-前端信息架构与页面设计文档

## 1. 概述

本文档定义前端的页面结构、组件、路由和状态管理，基于现有 Grafana 看板的交互效果进行还原，使用 React + Vite + Tailwind + Ant Design 技术栈。

**技术栈**：
- 框架：React 18 + Vite
- UI 组件库：Ant Design
- 样式：Tailwind CSS
- 路由：React Router
- 数据请求：TanStack Query（React Query）
- 状态管理：Zustand
- 图表：ECharts

---

## 2. 页面结构

### 2.1 页面总览

| 页面 | 路径 | 说明 |
| --- | --- | --- |
| 看板首页 | `/` | 默认跳转到今日清单看板 |
| 今日清单看板 | `/daylist/:daylistId` | 主页面，对应现有 Grafana 的 D 看板 |
| 基准总览看板 | `/bench` | 对应现有 Grafana 的 A 看板 |
| Aim Lab 看板 | `/aimlab` | 对应现有 Grafana 的 Aim Lab 看板（后续做） |
| 设置页 | `/settings` | 后续做 |

### 2.2 今日清单看板（主页面）

对应现有 Grafana 的 viscose-daylist 看板，是核心页面。

**页面布局**：
```
┌─────────────────────────────────────────────────────────┐
│  顶部导航栏：Logo | 看板切换 | 用户信息                      │
├─────────────────────────────────────────────────────────┤
│  过滤器栏：清单选择（下拉） | 日期范围 | 刷新按钮          │
├─────────────────────────────────────────────────────────┤
│  今日清单·完成度面板（表格）                                │
│  - 场景名 | 角色 | 要求轮数 | 已打轮数 | 进度条 | 状态      │
├─────────────────────────────────────────────────────────┤
│  今日清单·目标对比面板（表格）                              │
│  - 场景名 | 角色 | 目标分 | 现状 | 达成度 | 下一档线 | 命中率 │
├─────────────────────────────────────────────────────────┤
│  底部：状态栏 | 数据更新时间                                │
└─────────────────────────────────────────────────────────┘
```

**交互**：
- 点击场景名 → 弹出感悟弹窗
- 切换清单 → 自动刷新数据
- 点击刷新按钮 → 手动刷新数据

## 4. 路由设计

```
/                          → 重定向到 /daylist/Day3
/daylist/:daylistId        → 今日清单看板
/bench                     → 基准总览看板（后续做）
/aimlab                    → Aim Lab 看板（后续做）
/settings                  → 设置页（后续做）
```

**路由参数**：
- `daylistId`：清单名（如 `Day1` / `Day2` / `Day3`）

## 5. 状态管理

### 5.1 Server State（服务端状态）

用 TanStack Query 管理：
- `useDaylists()` - 清单列表
- `useDaylistProgress(daylistId)` - 完成度面板数据
- `useScenarioPopup(scenario, startTs, endTs)` - 场景弹窗数据
- `useScenarioHistory(scenario, days)` - 场景历史数据

**缓存策略**：
- 清单列表：缓存 5 分钟
- 完成度面板：缓存 1 分钟
- 场景弹窗数据：不缓存（每次打开都重新查）

### 5.2 UI State（UI 状态）

用 Zustand 管理：
- `useAppStore`：
  - `selectedDaylist`：当前选中的清单
  - `selectedScenario`：当前选中的场景（弹窗）
  - `isPopupOpen`：弹窗是否打开

## 7. 页面交互流程

### 7.1 首次进入页面

1. 加载清单列表（`/api/daylists`）
2. 默认选中最新的清单（如 Day3）
3. 加载该清单的完成度面板数据
4. 加载该清单的目标对比面板数据

### 7.2 切换清单

1. 用户选择新的清单
2. 更新 URL 参数（`/daylist/:newDaylistId`）
3. 自动加载新清单的数据
4. 刷新完成度面板和目标对比面板

### 7.3 点击场景名

1. 用户点击表格里的场景名
2. 打开场景详情弹窗
3. 加载弹窗数据（当天成绩 + 基准数据 + 历史感悟）
4. 展示弹窗内容

### 7.4 关闭弹窗

1. 用户点击关闭按钮或遮罩层
2. 关闭弹窗
3. 清空选中的场景

---

## 8. 响应式设计

- **桌面端**（> 1024px）：双栏布局（完成度 + 目标对比并排）
- **平板端**（768px - 1024px）：单栏布局（完成度在上，目标对比在下）
- **移动端**（< 768px）：单栏布局，表格横向滚动
