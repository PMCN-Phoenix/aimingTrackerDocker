# 05-核心交互流程文档

## 1. 概述

本文档定义用户在今日清单看板页面的完整交互流程，对照现有 Grafana 看板的操作方式，确保用户体验一致。

**设计原则**：
- 和 Grafana 操作逻辑一致，用户不需要重新学习
- 减少点击次数，常用功能放在显眼位置
- 操作有反馈（loading、成功/失败提示）

---

## 2. 主流程：查看今日清单

### 2.1 首次进入页面

```
用户访问 /daylist/Day3
    ↓
1. 加载清单列表（调用 /api/daylists）
    ↓
2. 默认选中最新的清单（如 Day3）
    ↓
3. 加载该清单的完成度数据（调用 /api/daylists/Day3/progress）
    ↓
4. 加载该清单的目标对比数据（调用 /api/daylists/Day3/progress + /api/scenarios/*/bench）
    ↓
5. 渲染页面
```

**交互细节**：
- 加载时显示 loading 动画
- 数据加载完成后自动渲染
- 如果加载失败，显示错误提示和重试按钮

---

### 2.2 切换清单

```
用户点击顶部清单选择下拉框
    ↓
1. 显示所有可选清单（Day1 / Day2 / Day3 / ...）
    ↓
2. 用户选择新清单（如 Day2）
    ↓
3. 更新 URL（/daylist/Day2）
    ↓
4. 重新加载该清单的数据
    ↓
5. 刷新完成度面板和目标对比面板
```

**交互细节**：
- 切换时显示 loading
- 切换完成后自动滚动到顶部
- URL 同步更新，方便用户分享/收藏

---

### 2.3 切换日期范围

```
用户点击日期范围选择器
    ↓
1. 显示快捷选项：今天 / 昨天 / 最近7天 / 最近30天
    ↓
2. 也可以自定义日期范围（日历选择）
    ↓
3. 用户选择新日期范围
    ↓
4. 重新加载该日期范围内的所有数据
    ↓
5. 刷新完成度面板和目标对比面板
```

**交互细节**：
- 默认选中"今天"（对应清单的 run_date）
- 快捷选项放在最前面，方便快速选择
- 自定义日期范围放在后面

---

## 3. 次要流程：查看场景详情

### 3.1 点击场景名

```
用户点击表格里的场景名（如 Popcorn MV Easier）
    ↓
1. 打开场景详情弹窗
    ↓
2. 加载弹窗数据（调用 /api/scenarios/Popcorn MV Easier/popup）
    ↓
3. 显示弹窗内容：
   - 当天成绩（得分、命中率）
   - 基准数据（下一档线、达成率）
   - 历史成绩折线图
   - 历史感悟列表
```

**交互细节**：
- 弹窗打开时显示 loading
- 弹窗居中显示，带遮罩层
- 点击遮罩层或关闭按钮可以关闭弹窗

---

### 3.2 关闭弹窗

```
用户点击关闭按钮 或 点击遮罩层 或 按 ESC 键
    ↓
1. 关闭弹窗
    ↓
2. 清空选中的场景
    ↓
3. 回到主页面
```

---

## 4. 数据更新流程

### 4.1 手动刷新

```
用户点击刷新按钮
    ↓
1. 重新加载所有数据
    ↓
2. 刷新完成度面板和目标对比面板
    ↓
3. 显示刷新成功提示
```

**交互细节**：
- 刷新时按钮显示 loading 状态
- 刷新完成后按钮恢复正常
- 顶部显示"最后更新时间"

---

## 5. 边界情况流程

### 5.1 空数据

```
如果清单不存在 / 场景没有数据
    ↓
1. 表格显示空状态提示："暂无数据"
    ↓
2. 弹窗显示："暂无该场景的数据"
```

### 5.2 加载失败

```
如果网络请求失败
    ↓
1. 显示错误提示："数据加载失败，请检查后端服务是否运行"
    ↓
2. 显示重试按钮
    ↓
3. 用户点击重试，重新加载
```

---

## 6. 和 Grafana 的对比

| 操作 | Grafana | Web 版 | 说明 |
| --- | --- | --- | --- |
| 切换清单 | 顶部变量下拉框 | 顶部清单选择下拉框 | 完全一致 |
| 切换时间范围 | 右上角时间选择器 | 右上角日期范围选择器 | 完全一致 |
| 点击场景名 | 点击表格里的场景名 | 点击表格里的场景名 | 完全一致 |
| 关闭弹窗 | 点击 X 按钮 | 点击 X 按钮 / 遮罩层 / ESC | 多了 ESC 键支持 |
| 手动刷新 | 右上角刷新按钮 | 右上角刷新按钮 | 完全一致 |
| 自动刷新 | 有（可配置间隔） | 无（按用户要求去掉） | 简化了 |
