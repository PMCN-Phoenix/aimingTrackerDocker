# 10-数据接入与部署设计文档

## 1. 概述

本文档设计数据接入和部署运行的方案，确保系统可以一键启动、数据可以方便更新。

**设计原则**：
- 一键启动：前后端一条命令启动
- 数据更新：方便触发，不需要手动跑多个脚本
- 部署简单：本地运行，不需要复杂配置

---

## 2. 数据接入设计

### 2.1 现有数据接入方式

目前数据更新需要手动跑多个脚本：
1. `import-aim` - 导入 Kovaak's 数据
2. `aimlab_import.py` - 导入 Aim Lab 数据
3. `tempo_sync.py` - 同步节拍数据
4. `daylist_sync.py` - 同步每日清单

### 2.2 改进方案

**Web 版数据接入方式**：
- 前端加一个"更新数据"按钮
- 点击后调用后端 API
- 后端依次执行所有数据更新脚本
- 更新完成后自动刷新页面数据

**接口设计**：
- POST `/api/data/update` - 触发数据更新
- GET `/api/data/status` - 查看更新状态

---

## 3. 部署设计

### 3.1 开发模式

- 后端：`uvicorn app.main:app --reload --port 8000`（自动重载）
- 前端：`npm run dev`（热更新）
- 访问：`http://localhost:5173`

### 3.2 生产模式

- 后端：`uvicorn app.main:app --host 0.0.0.0 --port 8000`
- 前端：`npm run build`，打包成静态文件，由后端直接提供
- 访问：`http://localhost:8000`

### 3.3 一键启动

**启动脚本**：`start.bat`（Windows）
- 启动后端服务
- 启动前端服务（开发模式）
- 打开浏览器

## 5. 交互设计

1. **点击更新数据按钮**：弹出更新进度弹窗
2. **更新进行中**：显示进度条，显示正在执行的脚本
3. **更新完成**：显示成功提示，自动刷新页面数据
4. **更新失败**：显示错误信息，显示失败的脚本
