# 06-看板渲染设计文档

## 1. 概述

本文档对照现有 Grafana 看板的每个面板，定义 Web 版的组件结构、数据格式、交互细节，确保视觉和体验完全还原。

**设计原则**：
- 1:1 还原 Grafana 现有面板的布局和数据
- 优化视觉效果（更好看、更清晰）
- 保持交互逻辑一致（用户不需要重新学习）

## 3. 各面板详细设计

### 3.1 完成度面板（800）——已实现

**Grafana 现状**：
- 表格，显示每个场景的：场景名、角色、要求轮数、已打轮数、进度条、状态
- 点击场景名弹出弹窗

**Web 版实现**：
- 组件：`ProgressTable`
- 列：
  - 顺序（order）：数字
  - 场景名（scenario）：可点击的链接样式
  - 角色（role）：文字（热身/卡口/主项）
  - 要求轮数（required_rounds）：数字
  - 已打轮数（done_rounds）：数字
  - 进度（progress）：进度条（百分比）
  - 状态（status）：标签（已完成=绿/进行中=橙/未开始=灰）

**数据接口**：`/api/daylists/{daylistId}/progress`

---

### 3.2 目标对比面板（810）——待实现

**Grafana 现状**：
- 表格，显示每个场景的：场景名、角色、目标分、现状、达成度、下一档线、命中率
- 数据来源：当天成绩 + 基准线数据

**Web 版设计**：
- 组件：`ComparisonTable`
- 列：
  - 场景名（scenario）：可点击的链接样式
  - 角色（role）：文字
  - 目标分（target）：下一档线分数（bench.nextLine）
  - 现状（current）：当天最佳得分（today.score）
  - 达成度（achievement）：百分比（current / target）
  - 下一档线（next_line）：和目标分一致？或者是上一档线？（待确认）
  - 命中率（accuracy）：当天命中率（today.accuracy）

**数据接口**：
- 清单行数据：`/api/daylists/{daylistId}/progress`
- 每个场景的成绩：`/api/scenarios/{scenario}/score`
- 每个场景的基准：`/api/scenarios/{scenario}/bench`

**交互**：
- 点击场景名弹出弹窗（和完成度面板一样）
- 达成度进度条：绿（≥100%）/ 橙（70%-100%）/ 红（<70%）

---

### 3.3 历史曲线（830）——待实现

**Grafana 现状**：
- 折线图，显示某个场景的历史成绩变化趋势
- X 轴：日期
- Y 轴：得分
- 显示最近 30 天的数据

**Web 版设计**：
- 组件：`HistoryChart`
- 图表库：ECharts
- 图表类型：折线图
- X 轴：日期（YYYY-MM-DD）
- Y 轴：得分
- 数据点：每天的最佳成绩
- 提示框：鼠标悬停显示日期 + 得分 + 命中率
- 参考线：下一档线（一条虚线）

**数据接口**：`/api/scenarios/{scenario}/history?days=30`

**位置**：
- 放在场景弹窗里（和 Grafana 一样，点击场景名弹窗里显示历史曲线）
- 大小：弹窗宽度的 90%，高度 200px

---

### 3.4 场景弹窗——待完善

**Grafana 现状**：
- 弹窗内容：
  - 场景名 + 角色
  - 当天成绩（得分、命中率）
  - 目标对比（目标分、下一档线）
  - 历史感悟（最近 3 条）
  - 历史曲线（小图）

**Web 版设计**：
- 组件：`ScenarioPopup`
- 弹窗内容（从上到下）：
  1. 标题：场景名
  2. 当天成绩：得分 + 命中率
  3. 基准数据：下一档线 + 达成率
  4. 历史曲线：折线图（HistoryChart 组件）
  5. 历史感悟：列表（ReflectionList 组件）

**数据接口**：`/api/scenarios/{scenario}/popup`

---

### 3.5 日期范围选择器——待实现

**Grafana 现状**：
- 右上角时间选择器
- 快捷选项：今天 / 昨天 / 最近 7 天 / 最近 30 天
- 自定义：日历选择器

**Web 版设计**：
- 组件：`DateRangePicker`
- 位置：顶部过滤器栏（和清单选择并排）
- 快捷选项：今天 / 昨天 / 最近 7 天 / 最近 30 天
- 自定义：日历范围选择器
- 默认值：今天（对应清单的 run_date）

**交互**：
- 切换日期范围后，自动刷新所有面板数据
- URL 同步更新日期参数

- 过滤器栏换行显示
