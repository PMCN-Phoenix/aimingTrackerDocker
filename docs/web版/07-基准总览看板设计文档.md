# 07-基准总览看板设计文档

## 1. 概述

本文档对照现有 Grafana B 看板（viscose-s2-easier），设计 Web 版的基准总览看板，完全还原 evxl charts 页的样式和功能。

**设计原则**：
- 1:1 还原 evxl charts 页的分组和配色
- 4 大类 14 子类分组总表
- 9 档达标线整格填色
- 顶部档位分布横向条

## 3. 详细设计

### 3.1 顶部档位分布横向条

**功能**：显示 9 个档位，每个档位有多少个场景。

**设计**：
- 横向条形图
- X 轴：9 个档位（Hare / Ermine / Lemming / ...）
- Y 轴：场景数量
- 每个档位颜色不同

**数据来源**：`/api/bench/groups`

---

### 3.2 大类标题

**设计**：
- 大字标题，加粗
- 显示大类名称（如 CONTROL TRACKING）
- 下面是该大类下的所有子类

**4 大类**：
1. CONTROL TRACKING
2. REACTIVE TRACKING
3. FLICK TECH
4. CLICK TIMING

---

### 3.3 子类行

**功能**：显示该子类的整体档位和进度。

**设计**：
- 子类名称（如 Arm）
- 档位标签（如 Hare）
- 进度百分比（如 75%）
- 下面是该子类下的所有场景

**14 子类**：
1. CONTROL TRACKING：Arm / Wrist / Fingertip / Blending
2. REACTIVE TRACKING：Control / Speed / Reading
3. FLICK TECH：Speed / Stability / Micro / Post-Flick
4. CLICK TIMING：Reading / Precision / Stability

---

### 3.4 场景行

**功能**：显示单个场景的详细数据。

**表格列**：
1. **场景名**：可点击，点击后弹出场景详情弹窗
2. **SCORE**：当前最佳得分
3. **进度条**：当前分 ÷ 下一档线（≥95% 绿、85-95% 橙）
4. **9 档格子**：9 个小格子，每个格子代表一个档位
   - 已达档 = 绿格 (#C0DD97)
   - 下一档 = 蓝格 (#B5D4F4)
   - 未达 = 灰格

**9 个档位**：

**数据来源**：`/api/bench/scenarios?list=viscose-s2-easier`

## 4. 组件设计

| 组件 | 说明 |
| --- | --- |
| `BenchmarkDashboard` | 基准总览主页面 |
| `RankDistributionBar` | 顶部档位分布横向条 |
| `CategorySection` | 大类区块 |
| `SubcategoryRow` | 子类行 |
| `ScenarioRow` | 场景行 |
| `RankCells` | 9 档格子组件 |
| `ScenarioPopup` | 场景详情弹窗（复用今日清单的） |

---

## 5. 数据接口

| 接口 | 说明 |
| --- | --- |
| `/api/bench/groups` | 获取所有大类和子类分组 |
| `/api/bench/scenarios?list=xxx` | 获取某个清单下所有场景的基准数据 |
| `/api/scenarios/{scenario}/popup` | 获取场景详情（复用） |

---

## 6. 交互设计

1. **点击场景名**：弹出场景详情弹窗（和今日清单看板的弹窗一样）
2. **切换清单**：顶部可以切换不同的清单（Viscose S2 Easier / Voltaic Iron 等）
3. **响应式**：移动端表格横向滚动
