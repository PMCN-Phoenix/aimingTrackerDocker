# 09-感悟系统设计文档

## 1. 概述

本文档设计感悟系统的功能，包括感悟的展示、写入、历史对比等。

**设计原则**：
- 1:1 还原现有感悟功能
- 支持从前端写入感悟
- 历史感悟按时间倒序展示

---

## 2. 功能设计

### 2.1 感悟展示

**位置**：场景详情弹窗里的历史感悟列表

**设计**：
- 按时间倒序展示
- 每条感悟显示：日期 + 感悟内容
- 最多显示最近 10 条

### 2.2 感悟写入

**位置**：场景详情弹窗底部

**设计**：
- 一个输入框 + 一个提交按钮
- 提交后保存到 InfluxDB
- 提交成功后刷新感悟列表

### 2.3 感悟编辑

**位置**：每条感悟的操作列

**设计**：
- 每条感悟有编辑和删除按钮
- 编辑后保存到 InfluxDB
- 删除后从 InfluxDB 删除

---

## 3. 数据接口

| 接口 | 说明 |
| --- | --- |
| GET `/api/scenarios/{scenario}/reflections` | 获取某个场景的所有感悟 |
| POST `/api/reflections` | 新增一条感悟 |
| PUT `/api/reflections/{id}` | 编辑一条感悟 |
| DELETE `/api/reflections/{id}` | 删除一条感悟 |

---

## 4. 组件设计

| 组件 | 说明 |
| --- | --- |
| `ReflectionList` | 感悟列表（已实现） |
| `ReflectionForm` | 感悟写入表单 |
| `ReflectionItem` | 单条感悟项（带编辑/删除按钮） |

---

## 5. 交互设计

1. **写入感悟**：输入内容 → 点击提交 → 保存成功 → 刷新列表
2. **编辑感悟**：点击编辑按钮 → 输入框变为可编辑 → 保存 → 刷新列表
3. **删除感悟**：点击删除按钮 → 确认删除 → 删除成功 → 刷新列表
