# 08-Aim Lab 看板设计文档

## 1. 概述

本文档对照现有 Grafana C 看板（Aim Lab），设计 Web 版的 Aim Lab 看板，完全还原现有功能。

**设计原则**：
- 1:1 还原现有 Aim Lab 看板的布局和数据
- 双栏布局（得分 + 命中率）
- 和 Viscose 看板视觉一致

---

## 2. 看板总览

### 2.1 页面结构

```
┌─────────────────────────────────────────────────────────┐
│  顶部导航栏：Logo | 今日清单 | 基准总览 | Aim Lab        │
├─────────────────────────────────────────────────────────┤
│  顶部：标题（Aim Lab 训练记录）                          │
├─────────────────────────────────────────────────────────┤
│  Aim Lab 任务列表（表格）                                │
│  - 任务名 | 得分 | 命中率 | 日期 | 操作                  │
├─────────────────────────────────────────────────────────┤
│  点击任务名 → 弹出详情弹窗（历史曲线 + 数据对比）          │
└─────────────────────────────────────────────────────────┘
```

---

## 3. 详细设计

### 3.1 Aim Lab 任务列表

**功能**：显示所有 Aim Lab 任务的训练记录。

**表格列**：
1. **任务名**：可点击，点击后弹出详情弹窗
2. **得分**：当前最佳得分
3. **命中率**：当前最佳命中率
4. **日期**：最近一次训练日期
5. **操作**：查看历史

**数据来源**：`/api/aimlab/tasks`

---

### 3.2 任务详情弹窗

**功能**：显示单个 Aim Lab 任务的详细数据。

**弹窗内容**：
1. 任务名
2. 历史成绩折线图（得分 + 命中率双轴）
3. 最佳成绩（得分 + 命中率）
4. 最近 5 次训练记录

**数据来源**：`/api/aimlab/tasks/{taskId}/detail`

---

## 4. 组件设计

| 组件 | 说明 |
| --- | --- |
| `AimLabDashboard` | Aim Lab 主页面 |
| `AimLabTaskTable` | Aim Lab 任务列表表格 |
| `AimLabTaskPopup` | 任务详情弹窗 |
| `HistoryChart` | 历史折线图（复用） |

---

## 5. 数据接口

| 接口 | 说明 |
| --- | --- |
| `/api/aimlab/tasks` | 获取所有 Aim Lab 任务列表 |
| `/api/aimlab/tasks/{taskId}/detail` | 获取单个任务的详情 |

---

## 6. 交互设计

1. **点击任务名**：弹出任务详情弹窗
2. **关闭弹窗**：点击 X 按钮 / 遮罩层
3. **响应式**：移动端表格横向滚动
