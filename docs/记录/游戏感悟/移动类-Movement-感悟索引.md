## 〇、先分清两套「movement」，别混着用

| | 实战移动瞄准 | 训练场移动跟枪 |
|---|---|---|
| 代表文档 | **Q006** 移动中瞄准定位 | **Q014** 匀减速急停、**Q004.3** 高速变向、**Q004.11** 薄目标变向、**Q021/Q022** 跟枪 |
| 场景 | Valorant 拉枪、摆射、deadzone | G 清单 14 个 strafe/dodge 场景 |
| 核心问题 | 瞄准放在「停」前还是「停」后 | 手的连续性与减速结构 |

两条线的交汇点只有三个词：**减速、连续、视觉焦点**。下面按这三个词归类。

---

## 一、调研文档与一句话结论

| 文档 | 一句话结论 |
|---|---|
| **Q006** 移动中瞄准定位 | 你不是瞄得慢，是把瞄准放在了「停住」之后；把它挪进减速窗口，停住只是扳机 |
| **Q014** 匀减速与急停 | 匀减速不是终点动作，是把「停止」改造成全程事件；制动式急停 = 共收缩 = EMD 粘滞 |
| **Q004.3** 高速变向反应不过来 | 场景是「匀速 → 减速 → 转向加速」循环；要观测到变向再改发力，不预判 |
| **Q004.11** Smooth Thin Strafes | 「眼睛反应不过来」的解法不是练眼睛，是**别让眼睛追**——准星停在摆动中心，让目标扫进来 |
| **Q021** 转火过头 | 到点卸力（松手滑停）比控制减速曲线简单一个数量级；默认欠瞄 5–10% 单向修正 |
| **Q022** 跟枪初速度匹配 | 「停下再加速」不可持续（全身制动）；改成「减速 → 加速」，张力有下限 |

### ⚠️ 有张力（两条调研互相打架，或和我的做法相反）

| 冲突 | 一侧 | 另一侧 | 我的处理 |
|---|---|---|---|
| **眼睛该追目标还是锁中心？** | Q006-4 / 我的 09-17 感悟：焦点锁目标、手随眼动 | Q004.11：别让眼睛追，准星停在摆动中心，让目标扫进来（WR 玩家相机速度≈0） | **按目标频率分**：低频大位移（Air 漂移类）→ 眼跟目标；高频往复（Thin Strafes / 短 strafe）→ 眼锁中心。同一条「手随眼动」不能套所有场景 |
| **先打再确认，还是等准星到了再开？** | Q004.9 Eclipse Flick：碰球只扣 10 分，晚 150ms 亏 200–300 分 → 先打 | Q006-6：大多数人输对枪是因为「shoot before ready」 | **按惩罚结构分**：计时刷分场景（30s 窗口）→ 先打；实战/一枪定生死 → 等准。两者不矛盾，是激励不同 |
| **Micro-adjust 用鼠标还是用移动？** | 我的习惯：手腕/手指微调（10-10「三者分工」） | Q006-3：差一点点应该用移动把准星「走」过去，纯手挪是典型错误 | **训练场没得选**（靶子不动、人也不动），这条只能在实战靶场验证，目前**未验证** |

## 三、结论与下一步

1. **减速/连续这条线最扎实**：Q014 + Q021 + Q022 三条调研，我这边有 5 条独立感悟互相印证（10-17 / 10-19 / 10-20 三篇），可以认为**已经内化**。
2. **视觉焦点这条线是分裂的**：Q006-4 与 Q004.11 结论相反，我自己的感悟也分两派。这不是谁错，是**场景频率**决定的——下一步该做的是：在 G 清单里给 14 个场景各自标注「该眼跟还是该锁中心」。
3. **实战迁移这条线是空的**：Q006 六条结论里，只有第 4 条我有训练场对应体感，其余五条（尤其「用移动代替微调」）在实战靶场一次都没验证过。这是移动类调研最大的落空处。
