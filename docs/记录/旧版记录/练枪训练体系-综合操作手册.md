# 练枪训练体系 · 综合操作手册（总册）

> 用途：一份文档掌握全部操作方案，之后调用（人工或 AI 均可）直接看这里。
> 建立：2026-08-07　|　适用：Docker 版练枪记录系统（`aim-tracker-docker`）
> 与健身系统完全独立：健身 = `training-tracker-docker`（8086/3000/1880），练枪 = `aim-tracker-docker`（8087/3001/1881），数据与仪表盘互不影响。

## 1. 系统是什么

「练枪」训练记录系统：自然语言录入（任务轮次 + 靶场打卡 + 数字指标）→ InfluxDB 存数据 → Grafana 折线图看进步路径。

- **4 个 Aim Lab 任务**（每轮记得分+命中率，全部轮次画点 + 3点移动平均）：六目标、水平跟枪、yay、多段直线；
- **2 个靶场数字项**：阶段2 侧面100Bot（完成用时，秒，越小越好）、阶段4 动态Bot（击败数，越多越好）；
- **7 个靶场打卡项**（只记做/没做）：阶段0热身、高台bot、铁壁、移动急停、绕圈跟枪、死区、移动100bot；
- **每日总时长**（分钟）。
- 统计口径（已与用户确认）：
  - **综合命中率线** = 每天各任务先取轮次均值，再对当天练过的任务取平均（任务等权），带 3点MA；
  - **完成项数线** = 当天打卡勾选数（0-7）+ AimLab/靶场数字项当天有记录 +1，上限 8，带 3点MA；
  - **任务线** = 每任务一面板，得分（左轴）+ 命中率%（右轴）双线，每轮一点 + 3点MA；
  - **连续坚持天数** = 有任意训练记录的天数连续累计（到最近一次记录为止）。

## 3. 数据模型（InfluxDB）

- `measurement` = 指标名（8 类）；每轮/每次一条逻辑点（InfluxDB 里每字段一行）；
- `fields`：
  - 4 任务：`score`（得分）、`accuracy`（命中率%），可只填其一；
  - 阶段2：`seconds`（完成用时）；阶段4：`kills`（击败数）；总时长：`minutes`；
  - 打卡：`done=1`；
- `tags`：`task` / `exercise` / `item`（显示名）、`round_index`（轮次，从 1 起）、`session_id`（每次录入一个）、`source`（demo/phone/自定义）；
- 时间戳：默认当前时刻，可用 `?time=2026-07-20T20:00:00%2B08:00` 指定；`?source=demo` 指定来源（默认 phone）。

## 4. 录入方案

语法：任务名后跟轮次（中文连写式），数字项后跟数值，打卡项出现即完成。

示例：
```
六目标 920分91% 940分93%  水平跟枪 88% 87%  yay 850分90%  多段直线 780分92%
阶段2 43秒 45秒  动态bot 62 68  总时长 45分钟
阶段0热身 ✓ 高台bot ✓ 铁壁 ✓ 移动急停 ✓ 绕圈跟枪 ✓ 死区 ✓ 移动100bot ✓
```

规则：
- 每轮三种写法：`920分91%`（得分+命中率）、`88%`（只命中率）、`780分`（只得分）；支持小数；
- 阶段2 后数字 = 完成秒数（可带「秒」）；动态bot 后数字 = 击败数；总时长后数字 = 分钟（建议写「45分钟」避免与得分「分」混淆）；
- 打卡项出现即记完成；跟上「没做/未做/✗」则跳过；
- 别名自动识别（见上表）；无法识别的文字被忽略；全部无法识别返回 400（带原文 detail），部分识别返回 200 并注明各项数量。

三种录入方式：
1. 命令行（Windows 用 curl.exe 避免中文乱码，或直接 Python/Postman）：
   ```powershell
   curl.exe -X POST "http://localhost:1881/add-aim" -H "Content-Type: text/plain; charset=utf-8" --data-binary "六目标 920分91% 阶段2 43秒 总时长 45分钟"
   ```
2. 手机/浏览器：任何能 POST 文本的工具，地址 `http://<电脑IP>:1881/add-aim`；
3. 演示/补录：`?source=demo`（演示数据）、`?time=2026-07-20T20:00:00%2B08:00`（指定日期）。

1. 改 `nodered_data\flows.json` → `aim-parse` 节点 `func` 的 `EX` 数组加一行（注意 JSON 转义）：
   ```js
   { id: 'aim_sixshot_alt', label: '六目标变式', type: 'aimlab', aliases: ['六目标变式'] }
   ```
   → `docker compose restart nodered`；改前先备份。
2. 改 `grafana\provisioning\dashboards\aim-training.json`：复制一个面板，改 id（2200+）/title/gridPos/Flux 匹配条件 → 用 `ConvertFrom-Json` 校验语法 → `docker compose restart grafana`（10~15 秒生效）。
3. 验证：curl 录入一条 → 面板出现新点。

## 11. 避坑速查（详见 `练枪训练体系-问题与经验记录.md`）

1. 本机无 `rtk`、`apply_patch` 不可用 → 用 Python 脚本写文件（捆绑版：`C:\Users\Rose\.cache\codex-runtimes\codex-primary-runtime\dependencies\python\python.exe`）；
2. PowerShell 读中文 UTF-8 文件必须 `-Encoding UTF8`；`&&` 用分号代替；
3. 面板 Flux 里按 tag 拆表时记得 `group(columns: [])` 合流（打卡 item / session_id 会把一条线拆成多条）；
4. 任何 curl 录入测试一律带 `?source=verify`，验收后删除（Flux delete predicate `source="verify"`）；
5. 应用内浏览器无法操作 localhost 页面 → 本地服务验证用命令行，页面由用户手动刷新；
6. 改 `flows.json` 前先备份；改仪表盘 JSON 用 `ConvertFrom-Json` 校验（provisioning 静默失败不报错）；
7. InfluxDB 的 `count()` 按行计数（每字段一行），别和「每轮一条」混淆；每轮得分+命中率 = 2 行；
8. 中文连写式 `920分91%`：`分` 后必须跟 `%`；总时长建议写「45分钟」，避免被当成得分。
