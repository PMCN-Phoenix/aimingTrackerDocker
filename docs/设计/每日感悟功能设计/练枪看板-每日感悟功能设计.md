# 练枪看板 · 每日感悟功能设计

> 版本 v0.1 ｜ 2026-09-18 ｜ 状态：设计底稿（待开发）
> 所属看板：D · 今日清单（viscose-daylist）

---

## 1. 功能概述

在 D 看板「今日清单 · 完成度」表格中，点击场景名（如 `1w2ts reload smallflicks larger`），弹出该场景的**每日感悟**弹窗，展示当天感悟、当天成绩、目标对比和最近 3 天历史感悟。

**核心价值**：练枪数据 + 主观感受联动，复盘时不仅看数字，还能回看当天的体感和总结。

---

## 2. 数据模型

新建 measurement：`aim_reflection`

| 标签/字段 | 类型 | 说明 |
|---|---|---|
| `scenario` | tag | 场景名（与 aim_scenario 一致） |
| `daylist` | tag | 所属清单（如 Day1），可选 |
| `_field` | — | 固定为 `note` |
| `_value` | string | 感悟文本内容 |
| `_time` | time | 感悟对应的日期（当天 00:00 +08:00） |

**唯一性**：scenario + date 唯一，同一天同一场景只存一条感悟（覆盖写入）。

**写入方式**：用户在对话中告知场景名 + 感悟内容，由助手调用写入脚本写入 InfluxDB。

## 3. 交互设计

### 3.1 触发

- D 看板 800 面板（完成度表）中，**场景名列**的文字变为可点击
- 视觉：hover 时文字下划线 + 背景微亮 + cursor:pointer，提示可点击
- 点击范围：仅场景名文字，不影响整行其他列

### 3.2 弹窗

- 形式：800 面板内自绘 modal（HTML/CSS/JS，覆盖在表格上方）
- 遮罩：半透明黑色背景，点击遮罩关闭
- 关闭：右上角 × 按钮 + ESC 键 + 点击遮罩
- 位置：面板居中，最大宽度 520px，内容超出可滚动

### 3.3 弹窗内容

```

├─────────────────────────────────────┤

│   得分: 100    命中率: 96.2%        │
│                                      │
```

**内容元素**：
1. 场景名 + 角色（热身/卡口/主项）+ 清单日 + 日期

4. 今日感悟：当天的感悟文本（无则显示"暂无感悟"）
5. 最近 3 天历史感悟：按日期倒序，无则显示"（无感悟）"

## 4. 技术实现要点

### 4.1 数据查询

800 面板新增一个 target（refId `C`），查询 `aim_reflection`：

```flux
from(bucket: "aim")
  |> range(start: -7d, stop: 2d)
  |> filter(fn: (r) => r._measurement == "aim_reflection" and r._field == "note")
  |> keep(columns: ["_time", "_value", "scenario"])
```

- 范围：最近 7 天（覆盖当天 + 最近 3 天历史 + 容错）
- gapit panel 的 JS 代码中，将查询结果按 scenario 分组，预加载到 JS 变量
- 点击场景名时，从预加载数据中查找该场景的当天和历史感悟

### 4.2 当天成绩与目标数据

- 当天成绩（得分/命中率）：800 面板已有 `count_flux`（refId B）查询当日轮数，可复用或新增查询 aim_scenario 当天数据
- 目标分/门槛/下一档线：810 面板已有 `day_json_flux`（refId A）查询 aim_daylist，800 面板可复用同一查询，从 dayJson 中提取目标分、门槛、下一档线

### 4.3 gapit panel JS 修改

在 800 面板的 `panelhtml` / `script` 中：
1. 场景名渲染时加 `<span class="scn-click" data-scn="...">` 包裹
2. 加 CSS：`.scn-click { cursor:pointer; text-decoration:underline dotted; } .scn-click:hover { background:rgba(255,255,255,0.08); }`
3. 加 click 事件委托：点击 `.scn-click` 时读取 `data-scn`，查找预加载数据，渲染 modal
4. modal HTML 结构 + CSS + 关闭逻辑

### 4.4 写入脚本

新建 `reflection_write.py`：
- 用法：`python reflection_write.py --scenario "场景名" --note "感悟内容" [--date 2026-09-18]`
- date 默认为当天（Asia/Shanghai）
- 写入 InfluxDB：measurement=aim_reflection, field=note, tag=scenario
- 同一天同场景覆盖写入（先删后写，或直接写——InfluxDB 同 tag+field+time 会覆盖）

## 6. 边界与注意事项

- **只读展示**：弹窗内不编辑感悟，写入走对话 + 脚本
- **无感悟时**：显示"暂无感悟"占位，不报错
- **热身项无目标分**：目标分/门槛显示"—"，下一档线来自 aim_bench_row
- **场景名匹配**：点击的场景名与 aim_reflection 的 scenario tag 必须完全一致（大小写、空格）
- **provisioning 重载**：修改 build_dashboard.py 后等 30 秒自动重载，无需 restart
