> 开始日期：2026-10-13（周一）
> 当前级别：Novice（Bronze → Gold）
> 目标：所有子类过 Gold 线 → 升 Intermediate

---

## 一、VDIM 是什么

**Voltaic Daily Improvement Method (VDIM) S5**，由 LG56 和 4RK 制作，是 Voltaic 官方推荐的周期化训练体系。

### 核心原理：区块周期化（Block-Periodization）
- 每天**只专注一个子技能**，通过"专注饱和"诱导更快的神经可塑性适应
- 每条神经通路每周被深度刺激1次，然后有6天恢复和巩固
- 解决"平台期效应"：每天练太杂 → 每条通路都只刺激了一点点

### 级别体系
| 级别 | 适用范围 | 进阶条件 |
| --- | --- | --- |
| Entry | Unranked → Bronze | 所有子类过 Bronze 线 |
| **Novice（当前）** | **Bronze → Gold** | **所有子类过 Gold 线（Gold Complete）** |
| Intermediate | Gold → Diamond | 所有子类过 Diamond 线 |
| Advanced | Diamond → Master | 所有子类过 Master 线 |
| Elite | Master → Astra+ | - |

## 三、进阶标准（Novice → Intermediate）

### 硬条件
当以下**全部满足**时，可以升 Intermediate：

- [ ] **Clicking 子类**（1w2ts / ww5t / 1wall6targets）全部过 Gold 线
- [ ] **Tracking 子类**（SmoothBot / Air CELESTIAL / Popcorn）全部过 Gold 线
- [ ] **Switching 子类**（Pasu / Controlsphere）全部过 Gold 线
- [ ] 连续 **2次基准测试**（间隔2周）都满足以上条件
- [ ] VDIM Novice 的 playlist 做起来感觉"不太吃力了"（能跟上节奏，不需要频繁暂停）

### 不要进阶的信号
- 某个子类**远低于** Gold 线（差20%以上）→ 继续 Novice，重点补这个子类
- 做 VDIM Novice 还是**很吃力**，每个 playlist 要分2次才能做完 → 继续 Novice
- 最近2周基准分数**没有进步**甚至退步 → 检查频率/睡眠/专注度，不要进阶

### 时间预估
| 训练频率 | 预计进阶时间 |
| --- | --- |
| 每天1小时+，每周6天，严格执行 | **4-6 周** |
| 每2天1次，每次1小时 | **8-12 周** |
| 三天打鱼两天晒网 | 不确定 |

## 四、不涨分可能遇到的问题（排查清单）

如果练了2-4周分数没涨，按以下顺序排查：

### 1. 频率问题（最常见）
- **症状**：练一天停三天，分数波动大
- **原因**：间隔超过2天，已建立的动作开始退化
- **解决**：至少每2天练1次，最好每天练；哪怕只练30分钟也比完全停好

### 2. 专注度问题
- **症状**：边看视频/听播客边练，分数不涨但也不累
- **原因**：注意力不在动作上，神经可塑性刺激不足
- **解决**：前30分钟全神贯注，后面可以听东西；每个场景开始前明确"这轮我要练什么"

### 3. 睡眠/恢复问题
- **症状**：练的时候感觉手沉、反应慢，分数比平时低
- **原因**：睡眠不足（<7小时），神经可塑性需要睡眠来巩固
- **解决**：保证7-8小时睡眠；训练前不要熬夜；如果前一天没睡好，当天只做半量

### 4. 疲劳累积问题
- **症状**：周一到周三分数涨，周四到周五分数跌
- **原因**：连续高强度训练，肌肉和神经疲劳
- **解决**：周日必须休息；如果某天真的很累，做半量或只做热身；每2周安排一个"轻松周"（训练量减半）

### 5. 方法错误问题
- **症状**：某个场景一直练但分数不涨，甚至越练越差
- **原因**：动作模式错误，在重复错误的动作
- **解决**：
  - 看 Voltaic 官方视频或高玩 VOD，学习正确动作
  - 降低难度（用更简单的场景练动作，再回到基准场景）
  - 录自己的回放，和高玩对比
  - 在 Voltaic Discord 发帖问，附自己的回放

### 6. 灵敏度/设置问题
- **症状**：大范围移动不够用，或小范围控制不住
- **原因**：灵敏度不适合当前水平
- **解决**：
  - 不要频繁改灵敏度（至少用2周再判断）
  - 如果大范围经常抬鼠标 → 降低灵敏度
  - 如果小范围控制不住、微调困难 → 升高灵敏度
  - 参考：eDPI 400-800 是大部分人的舒适区

### 7. 基准场景 vs 训练场景混淆
- **症状**：每天都在练基准场景，但分数不涨
- **原因**：基准场景是"考试"，不是"练习"；考试不能提高能力，练习才能
- **解决**：VDIM 里有很多基础训练场景（更简单、更适合练动作），认真做这些；基准场景每2周测1次就行

## 七、注意事项

1. **不要跳顺序**：VDIM playlist 里的场景是按从易到难排列的，按顺序做
2. **不要只追求分数**：VDIM 是练能力的，不是刷分的；关注动作质量，分数自然会涨
3. **可以听东西**：社区经验表明，边听长视频/播客边做 VDIM 可以让过程更轻松（但前几轮要专注）
4. **时间不够做半量**：如果某天只有30分钟，做 playlist 的前半部分也行，比完全不做好
5. **生病/疲劳就休息**：不要硬撑，疲劳状态下训练会强化错误动作
6. **每2周必须跑基准**：不跑基准就不知道有没有进步，也不知道该不该进阶
