## 一、技术栈选型

### 1.1 整体技术栈

和练枪看板 Web 版保持一致，复用现有基础设施：

| 层级 | 技术 | 版本 | 说明 |
| --- | --- | --- | --- |
| **后端** | FastAPI | 0.110+ | 轻量、自动生成 API 文档、和现有 Python 脚本兼容 |
| **前端** | React + Vite | React 18 + Vite 5 | 工程化、组件化、热更新快 |
| **UI 框架** | Ant Design | 5.x | 组件全、表单组件完善 |
| **样式** | Tailwind CSS | 3.x | 原子化 CSS，和现有项目一致 |
| **数据存储** | InfluxDB | 2.x | 现有数据都在里面，改动最小 |
| **文件存储** | Markdown 文件 | - | 人类可读、Git 版本管理、和现有记录方式一致 |
| **部署** | 本地 Python 服务 | - | `http://localhost:8000`，最简单 |
| **版本管理** | Git + Gitee | - | 现有仓库，分支 main |

### 1.2 选型理由

1. **复用现有基础设施**：练枪看板已经用 FastAPI + React + InfluxDB，游戏感悟直接复用，不需要引入新技术
2. **InfluxDB 适合时间序列数据**：感悟按日期组织，天然适合 InfluxDB 的时间序列模型
3. **Markdown 文件作为备份**：InfluxDB 存结构化数据，Markdown 文件存人类可读的完整内容，双重保障
4. **Ant Design 表单组件完善**：新增感悟需要复杂表单，Ant Design 的 Form 组件很合适

## 三、数据模型详细设计

### 3.1 InfluxDB 数据模型

#### Measurement: `game_reflection`

```
Tags:
  - id          (string)  感悟唯一标识，如 "ref_20261005_001"
  - theme       (string)  主题: warmup/aim/move/mind/map/agent/mindset
  - game        (string)  游戏: valorant/apex/cs2
  - mode        (string)  模式: ranked/deathmatch/custom/warmup
  - date        (string)  日期: 2026-10-05 (冗余 tag，便于按日期查询)
  - map_name    (string)  地图: Ascent/Haven/Bind (可选)
  - agent_name  (string)  英雄: Jett/Phoenix/Omen (可选)

Fields:
  - title       (string)  感悟标题
  - content     (string)  感悟内容 (Markdown 格式)
  - scenario    (string)  场景描述 (可选)
  - tags        (string)  标签，逗号分隔: "#预瞄,#急停,#头部高度"
  - warmup_item (string)  热身项目名称 (仅 theme=warmup 时有值)

Time:
  - 感悟创建时间 (纳秒级时间戳)
```

#### Measurement: `warmup_item`

```
Tags:
  - id          (string)  项目唯一标识，如 "warmup_001"
  - name        (string)  项目名称
  - type        (string)  项目类型: tracking/reaction/other

Fields:
  - description (string)  项目描述
  - created_at  (string)  创建时间

Time:
  - 项目创建时间
```

### 3.2 Python 数据模型 (Pydantic)

```python
from pydantic import BaseModel, Field
from typing import Optional, List
from datetime import datetime
from enum import Enum

class ThemeEnum(str, Enum):
    WARMUP = "warmup"
    AIM = "aim"
    MOVE = "move"
    MIND = "mind"
    MAP = "map"
    AGENT = "agent"
    MINDSET = "mindset"

class GameEnum(str, Enum):
    VALORANT = "valorant"
    APEX = "apex"
    CS2 = "cs2"

class ReflectionBase(BaseModel):
    title: str = Field(..., description="感悟标题", max_length=200)
    content: str = Field(..., description="感悟内容 (Markdown)")
    theme: ThemeEnum = Field(..., description="主题分类")
    game: GameEnum = Field(default=GameEnum.VALORANT, description="游戏")
    mode: Optional[str] = Field(None, description="模式: ranked/deathmatch/custom")
    map_name: Optional[str] = Field(None, description="地图")
    agent_name: Optional[str] = Field(None, description="英雄")
    scenario: Optional[str] = Field(None, description="场景描述")
    tags: List[str] = Field(default_factory=list, description="标签列表")
    warmup_item: Optional[str] = Field(None, description="热身项目名称 (仅 warmup 主题)")

class ReflectionCreate(ReflectionBase):
    date: str = Field(..., description="日期 YYYY-MM-DD")

class ReflectionUpdate(BaseModel):
    title: Optional[str] = None
    content: Optional[str] = None
    theme: Optional[ThemeEnum] = None
    tags: Optional[List[str]] = None
    # 其他字段可选更新

class ReflectionResponse(ReflectionBase):
    id: str
    date: str
    created_at: datetime
    updated_at: datetime

class WarmupItemBase(BaseModel):
    name: str = Field(..., description="项目名称")
    type: str = Field(default="other", description="项目类型")
    description: Optional[str] = Field(None, description="项目描述")

class WarmupItemResponse(WarmupItemBase):
    id: str
    created_at: datetime
    reflections: List[ReflectionResponse] = Field(default_factory=list)
```

#### 4.2.2 创建感悟

```
POST /api/reflection
```

**请求体：**

```json
{
  "title": "预瞄要放在头部高度，急停后再开枪",
  "content": "预瞄总是放在胸口位置...\n改进：预瞄直接放在头部高度...",
  "theme": "aim",
  "game": "valorant",
  "mode": "ranked",
  "map_name": "Ascent",
  "agent_name": "Jett",
  "scenario": "中路对枪",
  "tags": ["#预瞄", "#急停", "#头部高度"],
  "date": "2026-10-05"
}
```

**响应：**

```json
{
  "code": 0,
  "message": "success",
  "data": {
    "id": "ref_20261005_003",
    "title": "预瞄要放在头部高度，急停后再开枪",
    "created_at": "2026-10-05T21:00:00+08:00"
  }
}
```

**处理逻辑：**
1. 校验参数（theme 必须是枚举值，date 格式正确）
2. 生成唯一 ID：`ref_{YYYYMMDD}_{序号}`
3. 写入 InfluxDB（measurement: game_reflection）
4. 同步写入 Markdown 文件（每日汇总 + 按主题分类）
5. 返回创建结果

#### 4.2.3 更新感悟

```
PUT /api/reflection/{id}
```

**请求体：**（只传需要更新的字段）

```json
{
  "title": "更新后的标题",
  "content": "更新后的内容",
  "tags": ["#新标签"]
}
```

**处理逻辑：**
1. 根据 ID 查询 InfluxDB，确认存在
2. 更新指定字段
3. 重新同步 Markdown 文件（删除旧内容，写入新内容）
4. 返回更新结果

#### 4.2.4 删除感悟

```
DELETE /api/reflection/{id}
```

**处理逻辑：**
1. 根据 ID 查询 InfluxDB，确认存在
2. 从 InfluxDB 删除（InfluxDB 2.x 用 delete API）
3. 从 Markdown 文件删除对应内容
4. 返回删除结果

## 六、文件同步方案

### 6.1 双写策略

每次创建/更新/删除感悟时，**同时写入 InfluxDB 和 Markdown 文件**：

```
用户操作 → API 接收 → 校验参数
                    ↓
              写入 InfluxDB (主存储)
                    ↓
              同步 Markdown 文件 (备份 + 人类可读)
                    ↓
              返回结果
```

### 6.2 Markdown 文件同步逻辑

#### 创建感悟时：
1. 写入每日汇总文件：`docs/游戏感悟/2026-10/2026-10-05.md`
   - 如果文件不存在，创建文件和标题
   - 找到对应主题的分组（不存在则创建）
   - 追加感悟内容
2. 写入按主题文件：`docs/游戏感悟/按主题/对枪瞄准.md`
   - 找到对应日期的分组（不存在则创建）
   - 追加感悟内容
3. 如果是热身主题，同时更新热身项目文件：`docs/游戏感悟/热身项目/靶场平移机器人跟踪定位.md`

#### 更新感悟时：
1. 从每日汇总文件中删除旧内容，写入新内容
2. 从按主题文件中删除旧内容，写入新内容
3. 如果是热身主题，更新热身项目文件

#### 删除感悟时：
1. 从每日汇总文件中删除对应内容
2. 从按主题文件中删除对应内容
3. 如果是热身主题，从热身项目文件中删除对应内容

### 6.3 文件同步实现

```python
# app/services/file_sync_service.py

import os
import re
from pathlib import Path
from datetime import datetime

class FileSyncService:
    def __init__(self, base_dir: str):
        self.base_dir = Path(base_dir)
        self.daily_dir = self.base_dir / "每日"
        self.theme_dir = self.base_dir / "按主题"
        self.warmup_dir = self.base_dir / "热身项目"
        
        # 确保目录存在
        for d in [self.daily_dir, self.theme_dir, self.warmup_dir]:
            d.mkdir(parents=True, exist_ok=True)

    def sync_create(self, reflection: dict):
        """创建感悟时同步文件"""
        self._sync_daily_file(reflection, action="create")
        self._sync_theme_file(reflection, action="create")
        if reflection["theme"] == "warmup" and reflection.get("warmup_item"):
            self._sync_warmup_file(reflection, action="create")

    def sync_update(self, reflection: dict):
        """更新感悟时同步文件"""
        self._sync_daily_file(reflection, action="update")
        self._sync_theme_file(reflection, action="update")
        if reflection["theme"] == "warmup" and reflection.get("warmup_item"):
            self._sync_warmup_file(reflection, action="update")

    def sync_delete(self, reflection: dict):
        """删除感悟时同步文件"""
        self._sync_daily_file(reflection, action="delete")
        self._sync_theme_file(reflection, action="delete")
        if reflection["theme"] == "warmup" and reflection.get("warmup_item"):
            self._sync_warmup_file(reflection, action="delete")

    def _sync_daily_file(self, reflection: dict, action: str):
        """同步每日汇总文件"""
        date = reflection["date"]
        year_month = date[:7]  # 2026-10
        file_path = self.daily_dir / year_month / f"{date}.md"
        file_path.parent.mkdir(parents=True, exist_ok=True)
        
        # 读取文件内容（不存在则创建模板）
        if file_path.exists():
            content = file_path.read_text(encoding="utf-8")
        else:
            content = f"# {date} 游戏感悟\n\n> 自动生成，请勿手动编辑\n\n"
        
        # 根据 action 执行创建/更新/删除
        # ... (具体实现略)
        
        file_path.write_text(content, encoding="utf-8")
```

| 数据量增长后查询慢 | 低 | 目前数据量小（每天几条），InfluxDB 完全够用；后续可加索引和缓存 |
