## 一、项目背景与定位

### 1.1 背景

在练枪看板项目（aim-tracker-docker）中，我们已经系统化地记录了 Kovaak's 练枪的成绩和感悟。但在实际游戏（Valorant / Apex 等）实战中，同样会产生大量有价值的感悟和心得，这些内容目前散落在对话、笔记和脑海中，缺乏系统化的记录和管理。

### 1.2 定位

**游戏感悟功能**是练枪看板的延伸模块，专门用于记录游戏实战中的感悟和心得。

| 维度 | 练枪项目（现有） | 游戏感悟项目（新增） |
| --- | --- | --- |
| **核心** | 记录 Kovaak's 练枪成绩 + 感悟 | 记录游戏实战中的感悟，**不记录成绩** |
| **数据来源** | Kovaak's stats CSV（自动导入） | 手动录入（打完游戏后记录） |
| **分类维度** | 按场景（VT Controlsphere, Air CELESTIAL...） | 按**主题**（热身、对枪、身法、意识...） |
| **时间维度** | 按 Day（Day1, Day2...） | 按**日期**（2026-10-05...） |
| **项目关系** | 基础模块 | 延伸模块，同一仓库，独立目录 |

### 1.3 核心价值

1. **沉淀实战经验**：把每一次对枪、每一次决策的心得记录下来，避免"打完就忘"
2. **系统化复盘**：按主题分类浏览，便于针对性地回顾和改进
3. **和练枪数据联动**：练枪中的感悟可以迁移到实战，实战中的问题可以指导练枪方向
4. **长期成长追踪**：记录连续天数、覆盖主题数等，形成正向反馈

## 二、核心功能

### 2.1 感悟记录

- 每条感悟包含：标题、日期、游戏、模式、地图、英雄、主题、场景描述、感悟内容、标签
- 支持富文本（Markdown 格式）
- 支持多条感悟按主题分组展示

### 2.2 主题分类

共 **7 个主题**，每个主题有独立的颜色和图标：

| 主题 | 图标 | 颜色 | 说明 |
| --- | --- | --- | --- |
| **热身** | 🔥 | 红色 #ef4444 | 热身项目、热身流程、手感调整 |
| **对枪/瞄准** | 🎯 | 蓝色 #3b82f6 | 预瞄、拉枪、跟枪、急停、开枪节奏 |
| **身法/移动** | 🏃 | 绿色 #10b981 | 摆射、Peek、跳跃、移动路线 |
| **意识/决策** | 🧠 | 紫色 #a855f7 | 听声辨位、预判、经济管理、回合决策 |
| **地图理解** | 🗺️ | 黄色 #f59e0b | 点位、架枪位、爆弹、地图控制 |
| **英雄/角色** | 🎭 | 粉色 #ec4899 | 技能使用、角色定位、阵容搭配 |
| **心态/其他** | 💡 | 灰色 #6b7280 | 心态管理、情绪控制、团队沟通、设备设置 |

### 2.3 热身项目（特殊主题）

热身主题采用和练枪项目类似的结构——**按"热身项目"组织，每个项目有自己的感悟**。

当前已有的热身项目：

| 项目名称 | 类型 | 感悟核心 |
| --- | --- | --- |
| 靶场平移机器人跟踪定位 | 跟踪定位 | 手腕加肘部大调整，手指微调确认；眼睛盯死准星，余光看头 |
| 靶场平移机器人跟踪定位-不死鸟打闪 | 被闪反应 | 要眼睛锁死准星；被闪后保持准星位置，视力恢复后立刻继续跟踪 |

后续可扩展更多热身项目，每个项目独立记录感悟。

### 2.4 筛选与搜索

- 按日期筛选（全部日期 / 具体日期）
- 按游戏筛选（Valorant / Apex / CS2 / 全部）
- 按模式筛选（排位 / 死斗 / 自定义 / 全部）
- 按主题筛选（点击主题标签，单独展示该主题的感悟）
- 后续可支持关键词搜索

### 2.5 统计概览

- 总感悟数
- 今日感悟数
- 连续记录天数
- 覆盖主题数

## 三、数据结构设计

### 3.1 单条感悟的数据结构

```json
{
  "id": "reflection_20261005_001",
  "title": "预瞄要放在头部高度，急停后再开枪",
  "date": "2026-10-05",
  "game": "Valorant",
  "mode": "排位",
  "map": "Ascent",
  "agent": "Jett",
  "theme": "aim",
  "theme_name": "对枪/瞄准",
  "scenario": "中路对枪，敌人从 A 小拉出来",
  "content": "预瞄总是放在胸口位置...\n改进：预瞄直接放在头部高度...",
  "tags": ["#预瞄", "#急停", "#头部高度"],
  "created_at": "2026-10-05T20:30:00+08:00",
  "updated_at": "2026-10-05T20:30:00+08:00"
}
```

### 3.2 热身项目的数据结构

```json
{
  "id": "warmup_001",
  "name": "靶场平移机器人跟踪定位",
  "type": "跟踪定位",
  "description": "靶场中平移机器人的跟踪定位练习，热身核心项目",
  "reflections": [
    {
      "date": "2026-10-05",
      "content": "手腕加肘部大调整，手指微调确认...",
      "tags": ["#手腕肘部", "#手指微调", "#眼睛盯准星"]
    }
  ],
  "created_at": "2026-10-05T20:00:00+08:00"
}
```

### 3.3 InfluxDB 存储（可选，后续 Web 化时使用）

```
Measurement: game_reflection
Tags:
  - theme (warmup/aim/move/mind/map/agent/mindset)
  - game (valorant/apex/cs2)
  - mode (ranked/deathmatch/custom)
  - date (2026-10-05)
Fields:
  - title (string)
  - content (string)
  - tags (string, comma-separated)
  - map (string)
  - agent (string)
```

### 5.2 交互功能

- **主题标签筛选**：点击标签单独展示该主题的感悟
- **日期/游戏/模式筛选**：下拉选择，组合筛选
- **感悟卡片**：展示标题、元信息、内容、标签，支持编辑/复制
- **新增感悟**：右下角悬浮按钮，弹出表单录入
- **热身项目卡片**：特殊样式，按项目展示

### 5.3 视觉风格

- 深色主题（和练枪看板一致）
- 每个主题有独立的颜色（红/蓝/绿/紫/黄/粉/灰）
- 卡片左侧彩色边框标识主题
- 响应式布局，支持移动端

## 六、录入方式

### 6.1 当前阶段（Markdown 文件）

通过对话让 AI 帮你录入：
1. 打完游戏后，告诉 AI 你的感悟
2. AI 帮你整理成规范格式，写入对应的 Markdown 文件
3. 自动更新每日汇总和按主题分类

### 6.2 后续阶段（Web 表单）

在 Web 看板中点击"➕ 新增感悟"按钮，弹出表单录入：
- 选择主题（必填）
- 填写标题（必填）
- 选择游戏/模式/地图/英雄（可选）
- 填写感悟内容（必填，支持 Markdown）
- 添加标签（可选）
- 提交后自动写入 InfluxDB 和 Markdown 文件

## 七、和练枪项目的关系

### 7.1 数据联动

- **练枪 → 实战**：练枪中的感悟（如 Air CELESTIAL 的"区域覆盖跟枪法"）可以迁移到实战对枪中
- **实战 → 练枪**：实战中发现的问题（如"预瞄总是放胸口"）可以指导练枪方向（增加预瞄相关场景）

### 7.2 界面联动

- 在练枪看板的场景详情中，可以关联到游戏感悟中相同主题的内容
- 在游戏感悟中，可以引用练枪数据（如"今天练枪 Air CELESTIAL 突破 842 分，实战中尝试用区域覆盖跟枪法"）

### 7.3 统一基础设施

- 同一仓库（aim-tracker-docker）
- 同一套 InfluxDB（不同 measurement）
- 同一套 Web 技术栈（FastAPI + React + Tailwind）
- 同一套开发流程（写文档 → 实现 → 四重验证 → 集成测试）
