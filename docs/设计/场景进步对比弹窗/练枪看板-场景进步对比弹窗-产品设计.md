# 场景进步对比弹窗 · 产品设计底稿

> 所属看板：A 看板（viscose-s2-easier）面板 610「场景达标线总表」
> 状态：设计已定稿，待开发
> 生成：2026-09-19

---

## 一、需求一句话

点击 610 面板中的**场景名称**，弹出 modal 展示该场景**上次训练日 vs 本次训练日**的进步对比。

---

## 二、交互形式

- 和 D 看板「每日感悟弹窗」技术栈一致：gapit 面板内自绘 modal
- 场景名加 `.scn-click` 样式（鼠标手型 + hover 高亮）
- 点击 → 弹出 modal；点 × 或点背景关闭
- 不做页面跳转、不做路由

---

## 三、Modal 内容

### 3.1 顶部：训练日对比表

| | 上次（首测日） | 本次（最新日） | 变化 |
|---|---|---|---|
| **分数** | 696 | 931 | ↑ +34% |
| **命中率** | 13.8% | 17.9% | ↑ +4.1pp |
| **档位** | Lemming | Hare | ↑ 升档高亮 |

> "上次"= 该场景最早一条记录（9/16 首测）；"本次"= 最新一条记录。
> 如果该场景只打过一次（无对比数据），表格显示"暂无历史对比"。

### 3.2 中部：当天多轮趋势（SVG 折线）

如果本次训练日有多轮记录，画一条简单折线：
- X 轴 = 轮次序号
- Y 轴 = 分数
- 折线下方浅色填充
- 标最高分和最低分

> 如果该场景本次只打了 1 轮，此区域不显示。

### 3.3 底部：档位参考

- 下一档线：1050
- 还差：12.8%
- 较上次收窄了多少（如"上次差 34% → 现在差 12.8%，收窄 21.2pp"）

## 四、数据来源

### 4.1 新增 Flux 查询（refId B）

```flux
from(bucket: "aim")
  |> range(start: -30d)
  |> filter(fn: (r) => r._measurement == "aim_scenario"
    and (r._field == "score" or r._field == "accuracy")
    and r.list == "viscose-s2-easier")
  |> keep(columns: ["_time", "_value", "scenario", "_field"])
  |> group(columns: ["scenario", "_field"])
  |> sort(columns: ["_time"])
```

### 4.2 JS 数据处理

按 `scenario` 分组后：
- **上次** = 第一条记录（最早时间）
- **本次** = 最后一条记录（最新时间）
- **当天多轮** = 最新日期的所有记录（按时间排序）

---

## 五、边界情况

| 情况 | 处理 |
|---|---|
| 场景只打过一次 | 对比表显示"暂无历史对比"，只显示当前成绩 |
| 场景打过多天 | 上次=首测日最佳，本次=最新日最佳 |
| 当天只打了 1 轮 | 不显示趋势折线区域 |
| 分数下降了 | 变化值用红色显示（如 ↓ -5%） |
| 命中率下降了 | 同上，红色 |

## 六、与每日感悟弹窗的关系

| | 每日感悟弹窗（D 看板 800） | 进步对比弹窗（A 看板 610） |
|---|---|---|
| 触发 | 点击 D 看板完成度表场景名 | 点击 A 看板达标线总表场景名 |
| 数据 | aim_reflection（感悟文本） | aim_scenario（分数/命中率历史） |
| 内容 | 感悟 + 当天成绩 + 历史感悟 | 分数对比 + 命中率对比 + 趋势 |
| 写入 | 用户对话写入 | 只读，无写入 |

两个弹窗独立，互不干扰。

## 七、技术方案概要

- **面板**：610（gapit-htmlgraphics-panel）
- **新增 target**：refId B（历史成绩查询）
- **HTML/CSS/JS**：复用 D 看板弹窗的 modal 结构和样式
- **趋势图**：SVG 简单折线（手写，不引第三方库）
- **预估工作量**：改 build_dashboard.py 的 A 看板 610 面板，新增 1 个 target + modal HTML/CSS/JS

## 八、不做的事

- ❌ 不做按周/按月的趋势汇总（只有"首测 vs 最新"对比）
- ❌ 不做跨场景对比（只看单个场景自己的进步）
- ❌ 不做数据写入（纯只读展示）
- ❌ 不做导出/分享功能
