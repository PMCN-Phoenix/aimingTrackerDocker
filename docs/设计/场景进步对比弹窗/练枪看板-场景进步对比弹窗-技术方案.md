## 二、数据层

### 2.1 新增 Flux 查询（refId B）

```flux
from(bucket: "aim")
  |> range(start: -30d)
  |> filter(fn: (r) => r._measurement == "aim_scenario"
    and (r._field == "score" or r._field == "accuracy")
    and r.list == "viscose-s2-easier")
  |> keep(columns: ["_time", "_value", "scenario", "_field"])
  |> group(columns: ["scenario", "_field"])
  |> sort(columns: ["_time"])
```

**返回格式**：每个 scenario × field 一个 table，内含按时间排序的全部历史记录。

### 2.2 现有查询（refId A）

保持不变：`aim_bench_row` 的 `rowJson` field，返回 39 场景的静态配置（子类别、档位、下一档线、门槛等）。

## 三、前端数据处理（JS）

### 3.1 数据提取

遍历 `htmlGraphics.data.series` 所有 frames，通过 field 特征区分：

| refId | 特征 | 用途 |
|---|---|---|
| A | 字符串 field，值是 JSON（含 scenario/order） | 39 场景静态配置 |
| B | 数值 field，labels.scenario + _field（score/accuracy） | 历史成绩 |

**B 的数据结构**：按 `scenario` 分组，每个 scenario 内有 score 和 accuracy 两个 field 的时间序列。

### 3.2 每日平均分聚合

```
对每个 scenario：
  1. 把 score 的所有记录按 _time 的日期部分分组（YYYY-MM-DD）
  2. 每个日期算平均分 = sum(scores) / count(scores)
  3. 按日期排序 → 得到 dailyAvg 数组
```

**示例（PGTI）**：
- 9/16: [696] → avg=696
- 9/17: [700, 846, 857] → avg=801
- 9/18: [805, 848, 931] → avg=861

### 3.3 对比数据提取

| 字段 | 取值 |
|---|---|
| prevScore / prevAcc | dailyAvg[0]（首测日） |
| curScore / curAcc | dailyAvg[last]（最新日） |
| scoreDiff | curScore - prevScore |
| scorePct | scoreDiff / prevScore × 100% |
| accDiff | curAcc - prevAcc（单位 pp） |
| tierChanged | prevTier !== curTier |

## 四、Modal 渲染

### 4.1 HTML 结构

```
.modal-overlay
  .modal
    .modal-title（场景名 + 关闭×）
    table.cmp-table（对比表）
    .trend-wrap（SVG 折线，dailyAvg.length > 1 才渲染）
    .tier-info（下一档线 + 差距收窄）
```

### 4.2 SVG 折线

- 宽 500px，高 120px
- Y 轴：min/max 自适应，3 条参考线
- 绿色虚线：下一档线目标（如果在可视范围内）
- 数据点：蓝色小圆，最新点绿色大圆
- 每点上方：平均分数值
- X 轴：日期标签

### 4.3 事件绑定

- 场景名加 `.scn-click` class，CSS cursor: pointer
- 事件委托：`document.addEventListener('click', function(e) { if (e.target.classList.contains('scn-click')) rfOpen(scn) })`
- 关闭：× 按钮 + 点击 overlay 背景

## 五、边界情况

| 情况 | 处理 |
|---|---|
| 场景只有 1 天数据 | 对比表正常显示，不渲染趋势折线（dailyAvg.length <= 1） |
| 场景没有历史数据（未打过） | 对比表显示"暂无历史"，趋势不渲染 |
| 分数下降 | 变化值红色 |
| 命中率下降 | 同上 |
| 下一档线超出图表范围 | 不画虚线 |
