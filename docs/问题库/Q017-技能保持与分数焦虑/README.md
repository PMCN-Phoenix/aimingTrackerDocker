# Q017-技能保持与分数焦虑

> 立档：2026-10-18 ｜ 触发语："我明明学习了这项技能，这个技巧，但是等下一个周期再到相同的训练日的时候就用不出来了，而且会陷入一个很深的分数焦虑，我想要保持我第一次打这个场景的积极探索、不断调试的状态，而不是陷入这么深的分数焦虑，而且这对技巧的调试毫无用处"

## 核心裁决（30 秒版）

1. **"下个周期用不出来" = 热身损耗**（NBA 61 万罚球第二罚>第一罚；飞镖 3.6 万投第一镖最差）——瞬态、分钟级自愈、全人类共享，与能力无关
2. **"分数焦虑" = 再投入（reinvestment）**——焦虑把自动化技能拉回意识控制，人为降级到新手模式；隐性学习者对压力免疫（Masters 1992）
3. **"第一次打的积极探索" = 教科书式练习**——高情境干扰+全程重建动作计划=编码深刻；周期性重刷=blocked 练习，跨周期检索路径从未建立
4. **治焦虑和保持探索是同一个动作**：注意力在任务上（外焦点）=探索；在自己身上（内焦点）=再投入
