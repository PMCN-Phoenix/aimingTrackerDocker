# Q029 练了就能长吗与限制条件

## 问题概述

**练枪是练了就能长的吗？如果不是，限制条件是什么？** 要求针对当前状态（1391 轮本地数据 + 10-29 新训练计划 G1 四步平铺）作答。

## 三十秒结论

**不是。练习量只解释游戏成绩 26% 的方差**（Macnamara 2014，88 项研究元分析；精英层内仅 1%）。其余由七个限制条件决定：①难度匹配 ②既有基础天花板 ③专项练习的天然终点 ④变异性与巩固 ⑤质量≠数量 ⑥巩固与状态 ⑦迁移边界。

**本地数据判决**：45 个 ≥10 轮场景 = 32 涨 / 11 平 / 2 跌。时间分界线 09-13/09-16——之前 Iron/TE 档 155 轮零负增长（Pasu Voltaic Iron 44 轮 −10.5%，轨迹冲高回落），之后 Easier 档 +55~99%（Popcorn 87 轮 +98.7% 轨迹单调上升）。**变的不是人，是限制条件被满足了。**

## 对新计划的裁决

G1 四步平铺已覆盖 7 条中的 6 条（难度/天花板/终点/质量/状态/迁移均内嵌）；**唯一缺口 = 变异性**（固定 playlist = 块状练习），补丁：每周 ≤1 次变体轮（换场景/换顺序/灵敏度训练变体），不进判定数据。
