# Q022 跟枪初速度匹配与加速带

## 问题概述

在 `VT psalmTS Advanced Regen` 里：**跟一个目标需要一个"加速带"**——他向左移动，我得先在他右边一段距离停下，再向左加速才跟得住；如果一开始没有初速度、贴着过来，就不知道球飞哪去了，误差很大，跟不住。

## 三十秒结论

你说的"加速带"是**真实存在、有正式名字、且被教程明确点名为坏习惯**的东西。

它的正式名字是 **速度匹配（speed matching）**：跟枪的本质不是"对准目标"，而是**鼠标在屏幕上的移动速度，在每一瞬间等于目标的移动速度**。做不到连续匹配时，手会退化成"停—冲—停—冲"，而"在他右边一段距离停下"就是这个退化动作的起手式。

- **它为什么感觉有效**：从静止起步的加速度是**可控的**，从落后位置追赶的加速度是**不可控的**。你用一个"我能控制"的动作换掉了一个"我控制不了"的动作——这是一个**代偿**。
- **它为什么代价巨大**：217 次击杀只有 **36.4%** 干净，平均多打 **59.4%** 伤害。而**在干净击杀里，你的表现和 Novice 几乎完全一样**（20.0 发命中 vs 19.2 发）。**能力没变差，坏的是"跟丢"的频率。**

**一句话改法**：不要优化加速带，**取消这个阶跃**。目标减速时你也减速（像卡车一样有惯性），变向时"缓入"而不是"停下再冲"，**永远不要在目标外面停手**——要停也只停在目标的**边缘**上。
