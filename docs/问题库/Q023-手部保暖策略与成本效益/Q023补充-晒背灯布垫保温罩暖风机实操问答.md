## 1. 乌龟晒背灯给手臂取暖：具体要求与注意事项

### 选哪种灯（关键：给人用 ≠ 给龟用）

| 灯型                       | 是否适合给人暖手 | 原因                                         |
| ------------------------ | -------- | ------------------------------------------ |
| **UVA 加热灯（市面最便宜的"晒背灯"）** | ✅ 可用     | 本质是红外加热 + 可见光，发热为主，紫外线量很小                  |
| **UVB 灯 / 全光谱灯**         | ❌ 不要用    | UVB 会伤角膜和皮肤，且对人毫无补钙意义；全光谱灯 UVB 强度更高，灼伤风险更大 |
| **陶瓷无光加热灯（CHL）**         | ✅ 最隐蔽    | 只发红外无可见光，不刺眼，但要靠触摸确认位置                     |
| **近红外理疗灯泡（医用红外线灯泡）**     | ✅ 推荐     | 标准螺口 E27，光谱就是热辐射，宠物店和药店都能买                 |

**结论：给手臂取暖买"纯加热型"（UVA 加热灯 / 陶瓷灯 / 红外灯泡），绝对不要买带 UVB 的全光谱灯。**

### 参数要求

- **功率**：25W~~50W 够用（手臂距离 20~~30cm 的局部取暖，75W 会太烫）
- **灯座**：E27 螺口 + 夹子式反光罩（"夹灯"，宠物加热灯夹灯套装约 15~30 元）
- **距离**：20~30cm（与龟用安全距离一致）；再近会低温烫伤——**44℃ 以上持续接触 6 小时即可造成低温烫伤**，长时间固定照射更保守一点
- **定时**：必须插定时器或带定时插排，连续别超 1~2 小时；中途活动手臂自查皮肤
- **对照**：照 10 分钟后手臂皮肤应温热不发红；发红 = 太近或功率太大

### "聚焦手臂、不照到眼睛"怎么做到

1. **俯射布局**：夹灯装在桌面下方或桌沿，灯头从上往下 45° 照鼠标垫/手臂区域——灯永远低于视线水平线，光斑自然到不了眼睛
2. **反光罩自带聚光**：夹灯的锥形铝罩本身就是聚光器，光斑直径约等于距离的一半（距 25cm → 光斑约 30cm 圆），刚好盖住手臂+垫子
3. **补一块挡光板**：若灯位高于视线，用铝箔/硬纸板在灯罩开口朝显示器一侧加个遮檐，物理切断朝眼睛方向的溢光
4. **绝对禁忌**：平视或仰视角度让灯光直射面部；亮灯状态下长时间盯灯丝看（红外不可见但可见光刺眼，强光本身伤眼）
5. 眼睛发干、有异物感 = 溢光/热风吹脸了，调整灯位

### 使用注意汇总

- 不要隔布长时间烤（布会积热）；加热鼠标垫 + 灯选一样主力
- 皮肤有破损/湿疹的位置不要直照
- 灯泡工作时表面温度很高，夹子别夹在易燃物上，周围别堆纸巾织物
- 离开座位就关灯（定时器兜底）

## 2. 加热鼠标垫 + 薄布垫搭配：布垫要买多薄

**答案：1~2mm，越薄越好，上限 2mm。**

原因（外设圈共识 + 鼠标垫厚度研究）：

- **隔热**：加热垫的热量要穿过来；布越厚隔热越强，垫面温度越低。3mm 以上布垫会让加热垫几乎白开
- **操作手感**：1~~2mm 薄垫贴合桌面、稳定性高、无"滞后感"（厚垫 4~~6mm 会有明显滞涩与急停发闷）；FPS 玩家社区主流选择本来就是 3~4mm，但那是裸垫场景——叠在加热垫上要把厚度预算还给加热层
- **传感器**：过厚软垫在快速移动时有微形变，薄垫轨迹更线性

### 买什么

- **1~2mm 超薄硫化布垫**（细面/竞速面，别选粗纹大颗粒控制面——粗纹+加热垫双重阻尼会闷）
- 尺寸买 400×450 以上的"半桌垫"，手肘也能搭进热区
- 加热垫本体选 **表面是布面/绒面** 的款式，可以直接裸用（很多电竞加热桌垫本身就是布面），那就不用叠布垫；需要叠布垫的是**皮革/PVC 面加热垫**（光面传感器 tracking 差 + 手汗粘）
- 布垫定期洗（薄垫手洗晾干快），汗渍会影响顺滑度

### 一句话

> 加热垫（PVC/皮革面）→ 上面叠 **≤2mm 细面薄布垫**；或者一步到位买布面加热桌垫，省掉叠层。

## 3. 亚克力保温罩 DIY：最简单最省钱的做法

### 思路：不做全封闭盒子，做"三面挡风围板"

全封闭罩会挡手进出的路，而且粘接面越多难度越大。**桌面保温的核心是挡住冷风对流 + 锁住加热垫/体温的局部热量**，三面围板就够（左、右、后，前方留手臂进出口）。

### 材料清单（总计约 50~80 元）

| 材料                | 规格                          | 参考价     |
| ----------------- | --------------------------- | ------- |
| 亚克力板 3mm          | 让淘宝/拼多多商家**激光切割定制尺寸**（免自己锯） | 30~50 元 |
| 亚克力专用溶剂胶（或热熔胶枪）   | 一小支够用                       | 5~15 元  |
| L 型亚克力直角件（可选，加固用） | 4~8 个                       | 5~10 元  |

### 最省事流程

1. **量尺寸**：量桌面从鼠标垫后缘到显示器之间的宽度 W、深度 D、要挡的"风的高度" H（一般 25~35cm，不影响看屏幕）
2. **下单定制切割**：三块板（左右各一块 W×H? 实际为 D×H 两块 + 后面一块 W×H 一块），商家激光切割，边缘光滑免打磨
   - 板厚 3mm 足够（5mm 更挺括但贵一倍、重一倍）
3. **粘接**：平面直角拼接——把三块板在桌面上立成"冂"形，接缝处用**溶剂胶**（注射器沿缝滴，毛细作用自动渗入）或干脆**热熔胶**打缝（最便宜最简单，强度够用，就是丑一点）
   - 溶剂胶必须通风操作
4. **底部不封、不固定**：直接立在桌面上压住桌垫边缘即可，想挪就挪；怕倒就用 L 角件+免钉胶贴桌面
5. **进阶（可选）**：后板留一个线孔给鼠标线；或者罩一个 USB 加热垫在罩内构成"小暖房"

### 更省钱的替代（如果 50~80 也嫌多）

- 瓦楞纸板/KT 板三面围挡：0~10 元，效果一样，丑、怕水汽
- 透明塑料门帘膜挂桌沿：几块钱，挡风不挡视线
- **亚克力版的意义主要是"好看 + 不挡视线 + 不会一碰就倒"**，保暖效果和纸板没有本质区别

### 安全提示

- 罩内放加热垫/灯时，亚克力连续耐温约 70~90℃，加热垫温度档别开最高档贴着板烤，留 5cm 间隙
- 长期开加热垫的密闭小空间里别盖织物（积热）

**桌面选型硬指标**：PTC/石墨烯发热（几秒出热）、有**倾倒断电 + 过热保护**、低档噪音 ≤45dB、500W 上下就够桌面局部（2000W 桌面款纯浪费且干燥）。

**避坑**：

- 别买无 3C 认证杂牌（火灾风险）
- "负离子净化/仿真火焰/300㎡覆盖"这类都是噱头
- 出风口别对脸：热风直吹 = 皮肤干燥 + 口干 + 眼干三连

### 暖风机 vs 晒背灯：哪个让皮肤干得更快？

**答案：暖风机干得更快。**

机理对比：

|        | 暖风机（强制对流）                         | 晒背灯（红外辐射）                |
| ------ | --------------------------------- | ------------------------ |
| 加热方式   | 烧热空气吹出来                           | 电磁波直接加热皮肤                |
| 皮肤水分蒸发 | **风直接加速蒸发**——风速越大干得越快，且持续降低皮肤表面湿度 | 无风，蒸发慢；只要温度不烫、不出汗，干燥感明显低 |
| 空气湿度   | 对流会加速整个房间水分被带走，口鼻黏膜也干             | 基本不影响环境湿度                |
| 次生干燥   | 口干、眼干、嗓子干（整晚开着更明显）                | 主要是局部皮肤，若照太近太烫也会烤干皮肤     |
| 眼睛影响   | 热风吹眼 → 泪液蒸发快 → 干眼感                | 光照溢入眼睛会刺眼（布局得当可避免）       |

**使用策略**：

- 长时间开着 → **首选晒背灯/加热垫这类无风辐射+传导热**（对皮肤最友好）
- 暖风机放在**侧面朝桌下/朝房间中央**吹，别对手和脸直吹；开低档
- 用暖风机的日子备润唇膏 + 人工泪液；桌面放一小杯水或加湿贴缓解黏膜干燥
