# Q023 手部保暖策略与成本效益

## 问题概述

冬天打游戏手冷，想知道：**有哪些手部保暖策略、各自成本和性价比如何、具体买什么产品**。

约束条件（区别于网上绝大多数"户外保暖"攻略）：
- 场景是**室内 5–15℃**，不是户外 −10℃
- 要**连续 1–2 小时做亚毫米级鼠标操作**，右手不能戴任何东西
- 关注的是"手温是否影响瞄准质量"，不是"手是否舒服"

## 三十秒结论

**手冷靠"环境"解，不靠"穿戴"解。**

- **手冷真正毁的是灵巧度（速度）和触觉，不是最大力量**。手指皮肤温度 **~22.9℃** 是灵巧度陡降阈值（Chapman 2025, PMID 40343410）；而 8℃ 环境下握力/捏键的**力量控制精度并不下降**（Renberg 2020, PMID 32364982）。
- **比手冷更狠的是状态差/心理疲劳**：冷应激让复杂手工任务 −22%，心理疲劳单独 −30~36%（Valenza 2020, PMID 33074012）。**优先级：先管状态，再管手温。**
- **对手套要零容忍（右手）**：薄手套就让触觉阈值劣化 **6.5 倍**、握力 +14%、力变化率 +26%（PMID 27052582）；前臂肌肉活动 +22~78%（PMID 32885999）。这恰好复制了 Q021 证明的"加压→发抖→过头"病理动作。
- **单买加热鼠标垫是最常见的错误**：B站 189k 实测——「单独用没有这个罩子，手还是非常的冷，就是没有什么用」。原因是 2–3W 的垫子打不过手背的对流散热。**必须配挡风/保温罩**，且**必须叠一块布鼠标垫**（皮面"拖不动"）。
- **电加热手套是负收益**：实测加热感知弱、续航 2–3 小时；UP 主原话"再好的手套只是延缓热量散失，不能提供热量"。
- **性价比排序**：零成本回暖（热水洗手/搓手/暖脚）> 房间温度 > 一次性暖贴 > 加热桌垫+布垫+挡风罩 > 桌面暖风机 > 保温罩 DIY > 电加热手套（负）> 加热鼠标（559 元/116g）。

**核心推荐（≈70–130 元覆盖 90% 需求）**：USB 加热垫（17–30）+ 布鼠标垫 + 自制挡风罩（20–60）+ 暖贴一包（10）+ 红外测温枪（<30）。
