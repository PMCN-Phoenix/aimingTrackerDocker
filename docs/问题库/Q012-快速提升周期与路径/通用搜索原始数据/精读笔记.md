# 通用搜索 — 精读笔记

## 精读1：buyboosting.com — "Val Rank Hours: The Brutal Grind to Radiant"（2026-07-20）
URL: https://buyboosting.com/blog/valorant-rank-hours-grind-to-radiant/

**核心数字（累计游戏时长曲线）**：
| 段位 | 累计时长 |
|---|---|
| Iron | 52h |
| Silver | 240h |
| Gold | 343h |
| Platinum | 469h |
| Diamond | 610h |
| Ascendant | 840h |
| Immortal | 1050h |
| Radiant | ~3000h |

**关键论点**：
1. 曲线不是直线：Gold→Plat 只差 126h（"几个月下班后的排位就行"），但 Diamond→Immortal 的跃升比大多数玩家整个游戏投入还多。
2. "Diamond is where dreams go to die"：Diamond 之后机制不再是瓶颈，game sense 是税。"你可以有恶魔般的瞄准，仍卡在 610h 因为你不看信息就 peek。"
3. 方差：低段一个高手能 C 全场；高段对面也有高手，胜负取决于道具/时机/谁先心态崩。
4. "610 个 Diamond 小时里，很多不是学习时间，是反复重学同一课的时间"——因为 autopilot。
5. 高段玩家与你唯一不同的事：play for information, not frags；每个 peek 有理由、每个道具有用途、每次死亡都复盘而不是发怒。
6. "最快上分的人不是排得更多，而是排得更聪明，tilt 了就停。"

**对本调研的价值**：提供了最完整的"累计时长-段位"数据点，且定性解释了为什么高段时间成本指数增长。

## 精读2：betterfps.com — "How to Get Better at FPS Games in 2026"（2026-06-24）
URL: https://betterfps.com/blog/how-to-get-better-at-fps-games

**关键论点**：
1. 硬件层：60 vs 144 FPS = 40-50ms 输入延迟差（≈3 帧反应劣势）。稳定 165 FPS > 不稳 200 FPS。
2. 机械层：
   - 瞄准三件事 = tracking / flick / micro-adjust；玩家过度练 flick（因为爽），但 tracking 在高移动速度游戏中赢更多对枪。
   - Valorant/CS2 偏静态 flick + 微调（敌人移动慢、停枪射击）。
   - **Crosshair placement 是中段玩家 ROI 最高的技能**：把 250ms 反应射击变成 150ms 微调，零硬件成本。
3. 游戏意识层（对中段以上 ROI 最高）：
   - "一个瞄准中等但从不打烂架的玩家，会赢过一个瞄准好但乱 peek 的玩家。"
   - **Diamond→Immortal 的差距是压力下的决策，不是 flick 速度。**
   - 复盘方法：每个死亡问两个问题——"我当时有什么信息？我基于它做了什么决策？"大多数烂操作不是机械失败，是信息失败。
4. 反应时间：人视觉反应 180-250ms，训练提升有限；**真正提升的是模式识别速度**（看到 peek 前两帧就识别出敌人）。职业选手热身 20-30 分钟就是为了把识别速度和肌肉激活调回基线。
5. 长期主义："不是 30 天挑战，是 6 个月-2 年的项目。"每周一个具体微目标（周1：80% 死亡时准星已在敌人平面上；周2：减少死于道具；周3：每次报点含位置+人数+血量）。
6. **"Ranked is the test, not the practice."** —— 排位是考试，练习在 DM/aim trainer/VOD review。

**对本调研的价值**：把"训练结构"讲得最系统：硬件基线→机械→意识三层，且明确每层适用段位。

## 精读3（二手深读）：PLOS One — "Mind the gap: Distributed practice enhances performance in a MOBA"
URL: https://journals.plos.org/plosone/article/file?id=10.1371/journal.pone.0275843
- n=162,417 真实玩家数据 + 机器学习。
- **把游戏时间分散到多天的玩家，最终表现显著高于集中突击的玩家。**
- 高强度集中在什么时间点开始不影响结果，关键是 overall spacing。
- 与 aimbetween.games / Johanson 2019（CHI）结论一致：每天 15min×6 天 > 周日 2h 马拉松。
- **对周期规划的直接含义**：不要周末突击，每天练一点比一天练很久更有效率。
