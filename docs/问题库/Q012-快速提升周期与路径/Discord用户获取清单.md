## 重点关注内容类型

1. **教练/高玩的具体建议**（不是"多练"）：
   - "从黄金到钻石，你需要先解决X，再练Y"
   - "每天排位前做X，排位后做Y复盘"
   - "卡白金的人90%是因为X问题"

2. **个人提升记录帖**：
   - "我从白银到钻石用了X周，做了这些事"
   - "每天X小时，Y个月上超凡"
   - 有具体数字和方法的记录

3. **#resources 固定文档**：
   - 训练计划模板（每日/每周）
   - 段位能力 checklist（每个段位应该掌握什么）
   - VOD review 步骤清单

4. **争议讨论**：
   - "练枪到底有没有用" vs "只排位就能提升"
   - "单排提升快" vs "多排提升快"
   - 两种观点对立，看高赞回复
