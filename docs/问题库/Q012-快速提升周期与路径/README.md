# Q012 快速提升周期与路径

## 问题概述

VALORANT/无畏契约玩家："我想要全面提高游戏水平、快速达到指定段位，应该有怎样的周期，怎么去快速提升？"

即：从当前段位到目标段位的**提升周期规划** + **快速提升方法论**（训练优先级、效率最大化、瓶颈突破）。

**核心结论**：
- **周期**：累计时长曲线 Iron 52h → Gold 343h → Diamond 610h → Asc 840h → Imm 1050h → Radiant ~3000h。低段按月，Asc后指数增长。高强度冲段（每天6h）黄金→超凡可压缩到1个月。
- **杠杆按段位分层**：低段=预瞄+急停+经济；中段=站位+信息+peek纪律；高段=决策+心态+团队。Diamond是"机制税转决策税"的分界。
- **预瞄是全段位ROI最高的单项**；自我复盘>请教练；保下限>追上限；"Ranked is the test, not the practice"。
- **练枪软件在下三段"完全没用"是B站强共识**（洛洛spro 84万播放），整合结论：下三段优先游戏内靶场+死斗，软件练枪放钻石后。
- **8周冲段模板**：诊断期(1周)→基础期(2周)→强化期(2周)→冲段期(2周)→验收期(1周)，每天1.5-2h四段式。
