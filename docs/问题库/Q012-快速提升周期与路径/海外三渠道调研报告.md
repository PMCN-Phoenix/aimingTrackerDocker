## 2. 核心发现（按维度）

### 2.1 段位提升周期

**累计游戏时长曲线（社区+代练行业口径，三渠道交叉一致）**：
| 段位 | 累计时长 | 相对 Silver 的增量 |
|---|---|---|
| Iron | 52h | — |
| Silver | 240h | +188h |
| Gold | 343h | +103h |
| Platinum | 469h | +126h |
| Diamond | 610h | +141h |
| Ascendant | 840h | +230h |
| Immortal | 1050h | +210h |
| Radiant | ~3000h | **+1950h（指数跃升）** |

> 来源：buyboosting.com 2026-07（见通用搜索/精读笔记）；VLR 帖个人实测 Iron1→Asc ≈ 1600h。

**按每天 2 小时推算（代练行业口径）**：
- Gold1→Radiant ≈ 1260 场 / 735h / **约 368 天**
- Dia1→Radiant ≈ 900 场 / 525h / **约 263 天**
- Imm1→Radiant ≈ 360 场 / 210h / **约 105 天**

**"快速提升"的合理预期（三渠道共识）**：
- 机械层面：每日 15-30 分钟专项训练 → **2-4 周可见效，2-3 个月显著，6 个月-2 年到高于平均水平**（betterfps / playerbenchmark / computergamingworld）。
- 段位层面：低段（Iron→Gold）按月计；Gold→Diamond 是第一个明显瓶颈；**Ascendant 之后时间成本指数增长**。
- 影响周期的变量：①每周总投入；②训练质量（是否孤立弱点）；③是否复盘；④状态管理（tilt 停排）；⑤单排方差。

**反面意见**：Reddit/VLR 有声音认为 Radiant 应算 4000h（smurf 环境恶化）；也有人认为"Immortal 靠时间、Radiant 靠天赋"——这与教练圈"任何人都能靠正确 routine 上去"的叙事直接对立。

### 2.2 快速提升的核心杠杆（优先级排序）

三渠道高度一致，按段位递进：

| 优先级 | 杠杆 | 适用段位 | 来源 |
|---|---|---|---|
| 1 | **Crosshair placement（预瞄/准星高度）** | 全段位，尤其中段 | betterfps 精读："250ms 反应变 150ms 微调，ROI 最高"；VLR 高赞："aim 差其实是站位/peek 差"；Konpeki：Gold→Plat 的第一习惯 |
| 2 | **急停/peek 纪律/移动** | Iron-Gold | YouTube Konpeki/Woohoojin；betterfps |
| 3 | **经济与道具管理** | Gold-Plat | 多个攻略站；rooney "Skill Gap" |
| 4 | **决策与信息（play for info not frags）** | Plat-Dia-Asc | buyboosting："高段玩家唯一不同 = 每个 peek 有理由"；Woohoojin |
| 5 | **地图理解/默认站位** | Dia+ | betterfps："看一个主你位置的职业选手，抄 20 局默认站位" |
| 6 | **心态/状态管理** | 全段位 | buyboosting："tilt 了就停排"；Konpeki "Play Less" |

**80/20 法则**：
- "80% 表现来自 20% 技能；那 20% = 预瞄/反应/移动，不是花活"（dailyemerald）。
- "80% 真实比赛 + 20% 练枪"（thisgengaming）。
- Konpeki《1 Reason You're Hardstuck for Each Rank》：**每个段位只有一个最典型卡点，修掉就过段**。

**不同段位瓶颈差异**（rooney + Konpeki 交叉）：
- Iron/Bronze：基础枪法、急停。
- Gold：经济、道具、不 solo peek。
- Plat/Dia：站位、信息获取、peek 纪律。
- Asc+：决策、心态、团队配合。

### 2.3 训练结构与效率

**职业/教练四段式（Brinx 30 天实验 + gamecloudnetwork + gamingup）**：
1. 热身 10-20 分钟（DM/range）
2. 单项 drill 20-30 分钟（只练本周那个短板）
3. 带目标的排位（限额，状态差停）
4. VOD 复盘 1 场

**每周节奏（periodization）**：
- 周一 aim/排位；周二战术复盘；周三 aim+移动；周四恢复+VOD；周五专项场景；周六完整竞技块；周日恢复+计划（playforgames）。
- 半职业 15-25h/周 = 团队 8-12h + 个人排位 5-8h + 分析 2-5h（esportrecrutement）。

**VOD 复盘正确方法（Woohoojin 3XydhpDyKaU + betterfps 精读）**：
- 不是看高光，是逐死亡问两个问题："我当时有什么信息？我基于它做了什么决策？"
- 每次只盯 1-2 个错误模式，写成一句话规则下次执行。
- 结构化复盘 vs 非结构化：前者定位 root cause，后者只看表面。

**刻意练习 vs 无脑排位（科学依据）**：
- PLOS One：总时长解释表现，但**质量决定上限**；排位是 performance 不是 practice。
- PLOS MOBA n=162,417：**分散练习（每天短时间）> 集中突击**。每天 15min×6 天 > 周日 2h 马拉松。
- PubMed Space Fortress：90 分钟结构化反馈训练 > 4 小时盲目游戏。
- **"Ranked is the test, not the practice."**（三渠道金句）

**单排 vs 多排**：
- Reddit/社区共识：单排方差大（队友/心态），高段玩家常组固定队降低方差；但多排会削弱你对自己决策的责任训练。

### 2.4 瓶颈突破

**诊断方法**：
- 逐段对号入座（Konpeki vGFjCRN32vA）：先判断自己卡在哪个段的典型错误。
- 数死亡：本周最差的一场 VOD，数"多少死亡死于准星高度不对 vs 多少死于时机不对"（betterfps）。
- 连续 100 场同一档位 = 训练循环有问题，不是天赋问题。

**突破训练调整**：
- 一次只改一个习惯（周维度）：周1 只盯预瞄高度；周2 只盯经济沟通；周3 只盯报点内容。
- "如果我们失去点控制就 stop"——把规则写成一句话贴在屏幕边。

**ELO 地狱真相**：
- 社区共识：大部分 ELO 地狱是自己重复同样错误的结果，不是队友菜；"610 个 Diamond 小时里很多是反复重学同一课"。
- 反面：低段确实存在队友方差，但高段方差对所有人一视同仁。
