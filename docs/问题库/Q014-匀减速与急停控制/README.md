# Q014 - 移动中匀减速与急停控制（减速而非制动）

> **用户问题**：在一个速率移动鼠标时候怎么实现匀减速，怎么实现的减速而不是制动这种突然停下
> **调研日期**：2026-10-17
> **关联问题**：Q007-平滑后微调僵住（下游症状，本题是上游病因）｜Q004.4-ReflexFlick｜Q006

---

## 一句话结论

> **匀减速 = 把"停止"从末端事件改造成全程事件**：启动攒的张力在移动途中逐步泄掉（卸力），速度曲线成为斜坡而非悬崖，最后一段交给垫子摩擦力自然完成。制动式急停（终点收紧/下压/反向发力）是共收缩强行覆盖运动系统的默认平滑减速程序，代价是 EMD 粘滞 + 微调肌肉锁死——正是 Q007"僵住"的上游病因。

## 核心要点（速览）

1. **制动三禁忌**（晨曜）：终点再紧绷 / 下压鼠标 / 抬鼠标悬空
2. **解法 = 卸力**：途中泄力 + 摩擦力收尾，终点验收"预开火状态"（微微绷着蓄势待发）
3. **减速是独立技能**：甜糖三段拆解（发力→减速→确认）；M1 皮层分离编码加速/减速（Kadmon Harpaz 2019）
4. **减速三方式**（甜糖）：收紧小臂（准但锁死）vs 下压力（不锁死但干扰水平发力）vs 卸力（默认推荐）
5. **张力转移不是张力增加**：腕→前臂转移（Scucchi）；支点到极限就换（克礼无明）
6. **目标导向平滑**：Zeonlo 对每个目标 decelerate onto it，把近目标当 cluster 流过去
7. **⚠️ 命名冲突**：软件"鼠标平滑"（插值，关）≠ 手部平滑减速（技术，练）

## 训练方案摘要（2 周专注版，可与 Q007 叠加）

- **场景池**：Smoothbot 系列 / Smoothness Trainer Robot / Aimbeast Smooth V2 / vertical smoothness popcorn / PGTI
- **Drill 1** 拉枪制动不开枪（晨曜法）——与 Q007 的 COAX drill 同动作，可合并执行
- **Drill 2** 减速方式 A/B 自测：终点收紧 vs 途中卸力各 50 次，对比二次衔接与终点抖动
- **Drill 3** 隔离训练（xen2）：仅臂垂直平滑 / 仅腕水平精跟
- **Drill 4** 握压自检（钚荟画 7/6/5 框架 + 控制下压力）
- **验收 4 项**：Smoothbot 分数周环比 / 240fps 终点晃动分级 / 二次衔接胜率 / 排位"停-调"衔接体感
