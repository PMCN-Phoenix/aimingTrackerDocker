# Discord 用户获取清单 — Q009 练枪与上分匹配安排

> 用途：Discord 无公开 API，无法自动抓取。本清单列出你（用户）需要在三个服务器里手动查找的具体位置、关键词和产出方式。
> 制作日期：2026-10-13
> 目标问题：练枪和打排位怎么匹配时间、日常安排怎么定、怎样把练枪成绩转化为实战实力。

## 使用方法（通用）
1. 点开对应邀请链接，加入服务器（部分需过验证/ agree 规则）。
2. 进入指定频道，用 Discord 频道内搜索框（频道右上角或 `Ctrl+F` 在已加载消息里）搜关键词。
3. 对每条有用内容：**复制文本** 或 **右键消息→复制消息链接**，重要的 **截图**（含频道名+时间）。
4. 把收集到的内容贴回本调研的汇总文档。标注"已有替代来源，可选"的条目，若时间紧可跳过。

---

## 一、Voltaic 服务器（discord.gg/voltaic）

### V1. #resources 频道 — routine / 练习时长官方文档
- 频道：`#resources`（或置顶的 resources 分类下的 routine 文档链接）
- 搜索关键词：`routine`、`how long`、`daily`、`benchmark`、`weekly`
- 要找什么：
  - 官方对"每天练多久、每周练几天"的建议（Google Doc 已有替代：单场 30-40 分钟、"玩游戏比练枪更有效"——见原始数据 E3；此处找 Discord 里的置顶说明和最新赛季口径）。
  - benchmark 频次建议（每周日测一次？）。
  - Novice / Intermediate / Advanced 各档每周训练量。
- 操作方式：复制置顶/固定文档链接 + 文档里时长相关段落文本。
- 状态：**已有替代来源（Google Doc E3/E5），可选**。

### V2. #resources 或 #general — warmup 与 routine 的区别讨论
- 频道：`#general`、`#off-topic`、`#benchmarks`
- 搜索关键词：`warmup vs routine`、`before ranked`、`after ranked`、`fatigue`、`transfer`
- 要找什么：Voltaic 老用户/管理者对"heavy 训练放排位前还是后"的实际做法（社区共识，而非博客二手文）。
- 操作方式：复制高赞消息文本 + 消息链接。
- 状态：新增（通用搜索未覆盖社区一手做法）。

### V3. benchmark 分数与实际段位关系的自述
- 频道：`#general`、`#benchmarks`、`#off-topic`
- 搜索关键词：`voltaic rank`、`am I good`、`master in valorant`、`plat benchmark`、`percentile`
- 要找什么：用户自述"我 Voltaic 打到 X 档 / Valorant 段位是 Y"的对照样本——这是 benchmark-段位相关性**最缺的数据**（通用搜索只找到卖外挂网站的不可靠说法）。
- 操作方式：收集 5-10 条"benchmark 档 + 游戏段位"对照消息，截图或复制链接。
- 状态：**关键缺口，优先做**。

## 二、Woohoojin 服务器（discord.gg/woohoojin）

### W1. #resources 频道 — 官方 routine 与时间分配
- 频道：`#resources`
- 搜索关键词：`routine`、`playlist`、`aim`、`daily`、`30 minutes`
- 要找什么：Woohoojin x Voltaic routine 的官方置顶说明（每天一次、每周至少 5 天、30 分钟；Novice=Platinum 及以下 / Intermediate=Diamond+）。Google Doc 已有替代（原始数据 E4），这里找 Discord 置顶的最新版本与补充文字。
- 操作方式：复制置顶文档链接 + 说明文本。
- 状态：**已有替代来源（E4/E6 + NGA A4），可选**。

### W2. #vod-review 频道 — "练枪很多但实战没提升"的复盘实例
- 频道：`#vod-review`
- 搜索关键词：`aim`、`warmup`、`practice`、`transfer`、`drill`
- 要找什么：WHJ 团队（或认证教练）在复盘里如何点评"aim trainer 分数高但对枪输"的玩家——具体指出 transfer 断点（预瞄、急停、灵敏度、接仗选择）。
- 操作方式：复制复盘要点文本 + 消息链接；最好截图 VOD 标题。
- 状态：新增（通用搜索只有原则、没有一手复盘实例）。

### W3. #advice 频道 — "训练与排位时间怎么分配"的教练建议
- 频道：`#advice`
- 搜索关键词：`how long should I`、`aim trainer`、`before ranked`、`after ranked`、`how many hours`、`daily schedule`
- 要找什么：玩家提问、Woohoojin/mod/高等级成员回复的时间分配建议（例如：每天 2 小时 = 15 靶场 + 25 死斗 + 2 把排位 是否仍适用？）。
- 操作方式：收集 3-5 个问答串，复制完整一问一答 + 链接。
- 状态：**优先做**（这是 WHJ 对该问题的一手口径）。

- 频道：`#guides`

### R2. #gameplay-discussion 频道 — "练枪 vs 排位怎么平衡"的玩家讨论

- 搜索关键词：`aim trainer`、`warmup`、`grind`、`plateau`、`hardstuck`、`practice`

- 操作方式：收集 3-5 条高回复讨论串标题 + 链接，截图热评。
- 状态：优先做（补真实玩家视角）。

- 搜索关键词：`tilt`、`sensitivity`、`warmed up`、`first game`

- 操作方式：复制高赞消息。
- 状态：可选。
