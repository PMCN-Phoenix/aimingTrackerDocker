# Q009 练枪与上分匹配安排

## 问题概述

VALORANT/无畏契约玩家：练枪和正常打游戏上分应该怎么匹配、日常安排应该怎么样、怎样更好地发挥练枪后的实力。用户在执行 VDIM Novice 6 天训练计划（周一动态点击/周二静态点击/周三平滑跟枪/周四反应跟枪/周五速度转火/周六移动瞄准）。

**核心结论**：专项练枪 30–45 分钟/天、占总 FPS 时间 ≤20%；排位前只做 10–20 分钟轻热身（warmup ≠ training），高强度练枪放排位后；练枪成绩 ≠ 段位，转化需要"靶场迁移 + 无声死斗"桥；与 VDIM 按基本功分档衔接。
