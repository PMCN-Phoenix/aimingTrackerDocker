## D. 转化 / transfer（英文源）

### D1. Aimlabs 官方文章《Getting Better at Tasks is Not the Same as Getting Better at Aim》
- URL: https://aimlabs.com/articles/aimlabs/getting-better-at-tasks-is-not-the-same-as-getting-better-at-aim/
- 日期：2026-05-20
- 关键信息：把某个 task 刷分刷高 ≠ aim 变好；那种对任务本身的内部优化不一定迁移到实战。迁移最好的人是跨更广任务类型练习的人（tracking/flicking/switching 混合、难度混合），而不是死磕同一两个 task 直到平台期。

## 覆盖小结（供报告引用）
- 时间比例：多源收敛到"热身 10-15 分钟 + 专项 drill 10-30 分钟 + 排位主体"，每日总量 45-90 分钟、每周 5 天、每周 5 小时左右即可上分。
- 前后顺序：主流（WHJ、BattlePooja、aimtrainerpro、Gamiux）= 排位前轻热身、heavy routine 放排位后；Switchblade 反向（连 routine 也要排位前、pre-session only）——构成争议点。
