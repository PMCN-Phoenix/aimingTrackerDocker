# Discord 用户获取清单 —— 休息日精神状态恢复

> 用途：本文件**不自动抓取**，给用户/另一个 Agent 手动在 Discord 上检索用。
> 调研主题：VALORANT / FPS 玩家"精神状态不好时，休息日怎么过"的一线经验。
> 制作日期：2026-10-13
> 标注规则：
> - 【需抓取】= 通用搜索未覆盖，必须去 Discord 找玩家一手经验。
> - 【已有替代来源，可选】= 通用搜索已有较硬的科学依据，Discord 只用来补"玩家实际怎么做"的落地细节。

## 1. Voltaic Discord（discord.gg/voltaic）

Voltaic 是 aim trainer 圈最成熟的社区，有结构化 #resources 频道和老手教练。

| 频道 | 搜索关键词 | 要找什么 | 操作方式 |
|---|---|---|---|
| #resources | `rest day`、`rest days`、`recovery`、`routine`、`overtraining` | Voltaic 官方/教练写的休息日建议文档：一周练几天、休息日完全不碰 aim 还是做低强度跟踪、burnout 信号 | 进入 #resources 用 Discord 搜索框搜上述关键词，按 thread/消息过滤；优先 📌 置顶消息和 📑 wiki 链接 |
| #resources | `deload`、`break`、`burnout` | 教练对"状态下滑期"的判断：是该休息、降量还是换内容 | 同上 |
| #advice | `rest day`、`mentally tired`、`burnt out`、`can't focus`、`tilted` | 普通玩家描述"练不动了怎么办"的真实回答，看高赞回复/教练回复 | 在 #advice 搜索，按"最热门"排序，翻近 1–2 年的高赞 thread |
| #general-chat 或 #off-topic | `rest day`、`day off` | 老手休息日实际怎么过（打不打游戏、出不出去、做什么） | 搜完按 thread 读完整对话 |
| #coach-corner / coach 发帖区 | `recovery`、`schedule`、`periodization` | 职业 aim 教练怎么排周计划（练几休几、休息日强度） | 搜教练名字 + "rest" |

**重点抓**：Voltaic 对"休息日是完全不碰 aim 还是做轻量 micro-flick"有明确立场，通用搜索没覆盖到这个颗粒度。【需抓取】

## 2. Woohoojin Discord（discord.gg/woohoojin）

Woohoojin 是前 Radiant / 现教练，社区以"心态 + 训练方法"著称，对精神状态讨论非常多。

| 频道 | 搜索关键词 | 要找什么 | 操作方式 |
|---|---|---|---|
| #resources | `mental`、`mindset`、`recovery`、`tilt`、`burnout` | Woohoojin 本人或 mod 整理的心态/休息固定文档；他在播客/视频里讲过的"状态差时怎么办" | 进 #resources 看置顶、wiki 链接、`resources` 分类下的 #mental-game 子频道 |
| #advice | `mental`、`tilted`、`can't focus`、`bad day`、`rest`、`should I take a break` | 玩家自述"今天状态极差要不要停排"，看 Woohoojin/教练团的标准回答 | 搜关键词按"热门"排，优先带 ✅ 教练回复标记的 thread |
| #advice | `tilt recovery`、`after loss streak` | 连败后下一把/下一天怎么调整 | 同上 |
| #gameplay-discussion | `mental state`、`consistency`、`plateau` | "为什么我状态一天好一天坏"的经验讨论 | 搜近半年热门 thread |
| #voice-chat 历史 / vod-review 频道 | `rest`、`break` | 教练在复盘里对学员说"你最近练太多了"的原话 | 搜 vod-review 相关 thread |

**重点抓**：Woohoojin 对"状态差时是该停排还是换模式练 aim"有明确立场，这是 VALORANT 玩家语境下的关键决策点，通用搜索没有。【需抓取】

## 3. r/VALORANT 官方 Discord（discord.gg/valorant）

最大的玩家社区，但噪声大，主要用来验证"大众做法"。

| 频道 | 搜索关键词 | 要找什么 | 操作方式 |
|---|---|---|---|
| #guides | `rest`、`recovery`、`mental`、`tilt` | 高赞 guide 里关于休息/心态的章节 | #guides 内搜，按热度 |
| #gameplay-discussion | `rest day`、`break from ranked`、`tilted`、`losing streak` | 普通排位玩家对"停排一天有没有用"的一手经验 | 搜关键词，按热门，看评论区正反方 |
| #gameplay-discussion | `aim after break`、`comeback after break` | 停排一周/一个月后手感变化——验证"休息会不会丢枪" | 同上 |
| #off-topic | `routine`、`exercise`、`sleep` | 高段位玩家私下怎么安排作息和运动 | 搜 `Radiant routine` / `Immortal routine` |
| #clip-discussion 不抓 | — | 与本主题无关 | 跳过 |

**重点抓**：(a) 大众对"停排一天"的真实效果反馈（很多人说"停一天回来手感更好"或"停一天回来更菜"）；(b) 高段位玩家作息样本。【需抓取】

## 5. 用户操作建议（一次性跑完）

1. 三个 Discord 服务器依次进 #resources，把 📌 置顶和 wiki 链接扫一遍（10 分钟）。
2. 然后在每个服务器用 Discord 全局搜索搜上表中的"需抓取"关键词，按热门 thread 读 5–10 条。
3. 每条 thread 记录：服务器名 / 频道 / thread 链接 / 发言者段位或角色 / 核心结论。
4. 把结果追加到本目录的 `Discord用户访谈记录.md`（新建），不要改本清单。
