# Discord 用户获取清单 —— Q009.1.1 事情密度对恢复的影响

> 用途：本文件**不自动抓取**，给用户/另一个 Agent 手动在 Discord 上检索用。
> 调研主题：休息日一天排满事、密度很大，对精神恢复是帮助还是伤害？
> 制作日期：2026-10-13
> 标注规则：
> - 【需抓取】= 通用搜索未覆盖，必须去 Discord 找玩家/职场人一手经验。
> - 【已有替代来源，可选】= 通用搜索已有较硬的科学依据，Discord 只用来补落地细节。

## 1. r/productivity Discord

最大的效率社区，每天都有"休息日怎么过"的讨论，对"忙 vs 闲"的悖论特别敏感。

| 频道 | 搜索关键词 | 要找什么 | 操作方式 |
|---|---|---|---|
| #general 或 #productivity | `rest day`、`day off`、`burnout`、`busy rest day`、`active rest` | 高赞讨论：休息日是该躺平还是排满事？两种人各自的下场 | 搜索后按"热门"排，翻近 1–2 年 |
| #productivity | `attention residue`、`task switching`、`context switching` | 实际工作日里频繁切换任务后的疲劳感反馈 | 同上 |
| #advice | `I feel worse after a busy weekend`、`rest day but tired`、`busier on weekend than work` | 周末排满事后周一反而更累的案例——验证"密度过高反效果" | 重点找这类 thread，看高赞回复 |
| #watercooler / #off-topic | `hobby`、`weekend routine`、`weekend projects` | 高赞用户周末实际在做什么（修房子？做饭？游戏？） | 看 thread 里大家晒的 routine |
| #tools / #resources | `rest`、`recovery`、`planned rest` | 社区整理的"休息方法论"固定贴 | 看 📌 置顶 |

**重点抓**：(a) "周末排满事周一更累"的真实案例密度；(b) 大家公认的"恢复性活动"清单 vs "伪恢复活动"清单。【需抓取】

## 2. r/getdisciplined Discord

纪律/习惯社区，偏"如何安排一天"的硬执行视角，对"休息日该不该有结构"讨论极多。

| 频道 | 搜索关键词 | 要找什么 | 操作方式 |
|---|---|---|---|
| #general | `rest day`、`day off structure`、`lazy day`、`unproductive day` | 高赞用户对"休息日要不要留 schedule"的立场分歧 | 按热门排 |
| #advice | `should I plan my rest day`、`rest day routine`、`structured rest` | 新手问"休息日排计划会不会反而不休息"，看高赞回答 | 同上 |
| #advice | `busy weekend`、`social weekend`、`weekend recharge` | 周末社交/家庭活动排满后周一状态 | 找正反两类案例 |
| #journal / #check-in | `weekend`、`recovery` | 用户自发写的周末复盘，看他们怎么描述"恢复了 vs 没恢复" | 搜最近 3 个月的复盘贴 |
| #resources | `burnout`、`deload`、`rest` | 社区 wiki/置顶里关于倦怠与休息的固定文档 | 看置顶 |

**重点抓**：(a) 有没有人明确区分"rest day = 低结构空白"vs"rest day = 另一种节奏的事"；(b) 社交密集型周末（见朋友/家庭聚餐）对恢复的影响——通用搜索没覆盖社交密度。【需抓取】

## 5. 用户操作建议（一次性跑完）

1. 三个服务器依次进 #resources / #wiki，扫置顶（10 分钟）。
2. 然后在每个服务器用全局搜索搜"需抓取"关键词，按热门 thread 读 5–10 条。
3. 每条 thread 记录：服务器 / 频道 / thread 链接 / 发言者角色 / 核心结论（是支持"排满好"还是"排满累"）。
4. 结果追加到本目录的 `Discord用户访谈记录.md`（新建），不要改本清单。
