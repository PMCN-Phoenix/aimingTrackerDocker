## 一、结论先行

1. **"远距离拉不过去" = 腕的物理射程耗尽**。手腕左右弯曲只有 ~60-90° 的行程，映射成屏幕角度就是你的"腕射程"；超过射程的目标用手腕去够，就是克礼无明描述的那个画面："物理上已经到极限，再用臂强行拖过去，一顿一顿一卡一卡"。这不是手感问题，是发力结构选错了。
2. **"微调过度" = 弹道段出甩太狠 + 修正无上限**。学术上修正过冲要三个运动事件（停、反向、再瞄），修正欠甩只要一个；Voltaic 官方对 Pokeball 的打法说明就是"平滑、尽可能少微调"——微调次数是被主动规划的，上限 1 次。
3. **"打多了手感变差" = 张力累积 + 冲量变异性放大**。Schmidt 冲量变异性：力越大、散布越大，累了还硬甩大角度就是往大散布上叠紧绷震颤。手感变差是信号不是错觉，降速降张力是符合神经系统设计（signal-dependent noise）的最优应对。
4. **临界点动作有标准答案**：commit 一次果断出甩（80-90% 力度、瞄准落点稍短）→ 对称减速（减速相=加速相）→ 落地时手腕回中立位 → 一次慢微调 → 确认重合 → 点击。整条链在 Meyer 1988 优化子动作模型里有严格依据。

## 二、三个症状的机制拆解

### 症状① 远距离拉不过去

- **腕射程**：Aimlabs Pivot Point Training 的方法论——先测出"手腕左右最大弯曲时准星够到的墙宽"，那就是你的腕射程边界；罗恩教练特别警告"别一直把腕压死在最大弯曲，会带来前臂紧张"——**要留余量**
- **MYCRUSH eDPI 分级表**（10-17 调研唯一带完整分级表的来源）：低敏（瓦 <284 eDPI）应由臂主导大拉+腕只做微调；你如果腕-only 去够远目标，等于让最短的结构干最长的活
- **物理账**（Schmidt 1979）：距离翻倍→所需冲量翻倍→力的变异性翻倍→落点散布翻倍。远目标"拉不过去+拉过去也不准"是同一条定律的两面
- **commit 不足**：fpstrain——试探式两段甩（先蹭一半再补）比一次果断动作更慢更不稳定；"拉不过去"有时不是力不够，是中途犹豫切断了冲量

### 症状② 微调过度

- **Voltaic 官方 How**（Bardoz routine）："hold down 全程、目标间直接切换、**用平滑动作，尽可能少微调**"——注意官方把"少微调"当成技术目标而不是天赋
- **一次修正上限**（aimbetween）：甩→一次小修正→点击；需要第二次修正就说明出甩速度超过了当前校准
- **Baldog 方法**（yRinth 中字教程）：甩要快、微调要慢（新手阶段）；高手是甩快+微调也快，但**永远只有两个动作**——"没有一个浪费的动作"
- **节拍器陷阱**：按固定节奏点击会让你在远目标上"保持命中期"而错过调整——节奏必须动态，近目标连点（cluster farming）、远目标单独走完整流程

### 症状③ 打多了手感变差

- **张力累积**（sens-convert 2026）：高张力下肌肉物理性震颤不可避免；MYCRUSH：错误发力结构→肌肉紧绷→加速疲劳→状态下滑
- **冲量变异性放大**：疲劳时力量控制精度下降（力变异性的标准差∝力均值），同样的大甩散布更大——"手感没了"的数学形式
- **/session 长度红线**（mouseaccuracytest）：20-40 分钟专注训练足够，"长 session 鼓励垃圾重复"，垃圾重复练的是坏习惯
- **克礼无明的垫步模型**：小臂肌肉收缩-舒张循环产生**弹性势能**，连续定位要主动利用它（如羽毛球的垫步）；一直绷着不舒张，势能循环断掉，第 3-4 个目标开始手感崩——和你"打多了不太行"的体感完全对应

## 三、临界点动作标准（核心交付）

把"临界点"定义为：**大甩的减速落地窗口——从出甩结束到微调开始的那一段手部状态**。四步标准动作：

1. **出甩：一次果断、80-90% 力度、瞄准"稍短"**
   - 用臂（小臂平移带鼠标走直线，MYCRUSH：别以肘为圆心画弧），不用腕去够
   - 落点瞄准目标前方一点点（欠甩偏置）——修正欠甩=同向继续一个事件，修正过冲=停+反向+再瞄三个事件
2. **减速：对称卸力**
   - Meyer 1988：优化动作的减速相与加速相同等强度——减速是被规划的半个动作，不是甩完以后的余韵
   - 接 Q014.1"起手加压、提前一档松"：约 80% 路程开始松力，靠垫子摩擦自然收尾
3. **落地：手腕回中立位**
   - MYCRUSH："落地前确保手腕自然伸直，不左歪不右歪，给左右留微调空间"——歪着落地 = 微调空间已经用掉一半，只能过度修正
   - 若已滑到腕射程边缘：**先复位（抬鼠回中）再微调**，不要在极限姿势上继续掰
4. **微调：一次、慢、指腕小结构，确认重合再点**
   - 畅想tc 确认感："持续判断准星是否与头重合，重合后开枪"——跳过确认的连点就是"互相摆射都打不动"的来源
   - 微调用手指/腕的小结构，速度刻意放慢（最小方差理论：慢=神经信号更安静=更准）

**自检口诀**：拉不过去=结构选错（该用臂）；拉过头=卸力太晚；来回蹭=落地手腕歪/微调超一次；越打越糊=张力没释放，去抖手。

## 五、反面意见（单列）

1. **倒 U 反例**（Urbin 2022 / Molina 2023）：多关节弹道技能中速度-精度权衡不成立，变异性在 60% 力度附近峰值后回落——"80% 力度"法则未必普适，需实测校准个人曲线
2. **欠甩偏置派系之争**：部分高手主张 commit 到正中（fpstrain"commit fully"）与 aimbetween"落稍短"直接矛盾——折中理解：学习期用欠甩偏置建立控制，自动化后回填到正中
3. **Voltaic"hold down 全程"针对 Auto 变体**（按住自动开火）；1w4ts 是 TS 变体（点击节奏自控），照搬按住流不适用
4. **zion low 流派反证**：MattyOW 指出"对每个目标减速流"能靠流畅补速度，但会牺牲确认精度——慢微调不是唯一高分路线
5. **手感变差未必是技术**：睡眠/握姿漂移/垫子温度都会改变摩擦系数；先排除外因再归因动作
6. **克礼无明"长结构优先"在超高敏下不成立**：MYCRUSH 分级表明示 420+ eDPI 手腕手指就够——先确认自己的 eDPI 档位再套用
