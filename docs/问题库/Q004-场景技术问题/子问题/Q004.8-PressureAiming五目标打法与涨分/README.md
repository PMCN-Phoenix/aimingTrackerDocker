## 一、先搞清楚这个场景在考什么

Pressure Aiming 的核心机制：**目标会随时间缩小（并最终消失/过期），越犹豫越难打**。它本质上是一道"Fitts 定律实时加息"的考题：

- Fitts 定律：MT = a + b·log2(2A/**W**)——**目标宽度每减半，难度指数 +1 bit**，需要的时间按对数上升。缩靶 = W 在实时变小 = 你在跟一个越来越难的题目赛跑
- 它惩罚两件事：①犹豫到靶变小才出手（难度自找）；②为了赶时间提前加速（Chiu 2011 实验证明：高难条件下人"移动更快然后犯更多系统性错误"）
- 所以它真正考的是：**在时间压力下维持动作质量的能力**——即"快而不急"。这恰好是你 Q004.7 临界点四步 + Q014.1 卸力的综合应用场

## 二、快速涨分策略（按见效速度分层）

### 第一层：今晚就能涨（跑分策略，不碰技术）

1. **打"老"不打"新"**：5 个目标同时在场时，先处理**生成最早、已经缩得最狠**的——它最接近过期且你现在打它最贵；新目标还大，晚点打便宜。错误做法是按生成顺序或从近到远
2. **靶大时早 commit**：出甩决策在靶还是大尺寸时做掉。Kovaak 官方 FAQ 的跑分经验："稍微降速换准确，往往直接出 PB"——approach 阶段不减速，但**决策要早**
3. **状态窗口跑分**：benchmark 分数对手感极敏感——热身完 10 分钟内、状态好的时段跑；跑 3-5 场取最好即可收工，**跑分不是训练量**
4. **跑分前用该场景慢速打 1-2 场**（4rk Benchmark Focus Routine 思路）：把"甩-停-调-点"四段先顺一遍再上强度

### 第二层：一两周能涨（技术策略）

1. **甜糖的预判式确认**：确认不是"等准星与靶重合的瞬间才下指令"——像球类运动的击球点，**预判"它将会重合"，提前下达点击指令**。静态靶上就是：微调轨迹指向靶心、且偏差已在收敛，就点。等"完全重合"再点，你的神经传导延迟已经把点击送到了靶缩小的下一帧
2. **7ommy 的停顿-调整-确认**：定位到附近后允许一次短暂停顿+微调，确认收敛后点。这与"早 commit"不矛盾：commit 的是出甩（第一段），停顿发生在最后 25%（Q004.6 停机时间）
3. **修正上限 1 次**（Meyer 优化子动作）：每次修正都耗时有限——缩靶场景里修正次数直接换算成靶缩小的尺寸。两次修正的击杀几乎必然丢分
4. **准确率红线 85-95%**：rappy-world 教练共识——先准确后速度，"速度在准确率锁死后自己会来"。慌了提速是 Chiu 2011 实验里被证伪的策略

### 第三层：一两个月（底层能力）

1. **Q004.7 临界点四步直接平移**：果断 80-90% 出甩→对称减速卸力→腕回中立位→单次慢微调确认。Pressure Aiming 就是这套动作加一个倒计时
2. **关准星测屏幕中心感**（Ashes33 测试法）：关掉准星打 bot 八九不离十=中心感好，中心感好的人敢早 commit
3. **连续多目标确认感训练**（Ashes33）：一次快速连灭 2-3 个目标，中间的确认感自然建立
4. **张力管理**（克礼无明 3400h）：缩靶的"压力"会诱发高张力→震颤→更缩→更紧张的正反馈；每 3-4 目标抖腕释放（Q014.1 习惯）

## 三、本场景动作时序（一杀的完整拆解）

```
看到目标(大) → 眼先行锁点 → 臂甩(80-90%,瞄准稍短) → 途中卸力
→ 最后25%: 微调轨迹指向靶心、偏差收敛即"预判重合" → 点击(不等完全重合)
→ 击杀音效=确认反馈 → 眼已在下一个(最老/最小)目标上 → 循环
```

**丢分自检表**：

| 症状           | 病根             | 对策                   |
| ------------ | -------------- | -------------------- |
| 靶缩到很小才打、手忙脚乱 | 处理顺序错了：先打了新的大靶 | 打"老"不打"新"            |
| 甩过去但不敢点、反复微调 | 确认等"完全重合"      | 预判重合提前下指令（甜糖）        |
| 甩过头/来回蹭      | 出甩太狠+修正超上限     | Q004.7 四步、修正≤1次      |
| 越打越慌、越慌越缩    | 张力正反馈+提速错误     | Chiu2011: 维持质量勿提速；抖腕 |
| 空枪多          | commit 早但弹道没校准 | 回 Q004.7 欠甩偏置 W1-W2  |

## 五、反面意见（单列）

1. **跑分≠训练**：本报告第一层全是"榨取现有水平"的策略，涨的是分数不是能力；技术层（第二三层）才是真涨分
2. **"预判重合"有准确率代价**：提前下指令=接受小概率空枪；MattyOW 提过 zion low 流派"迫使命中率下降"——红线要自己实测（85% 是起点不是终点）
3. **缩靶策略的个体差异**：顶级玩家（如克礼无明 8400）的节奏未必可复制，其 8400 录像无字幕，视觉拆解待做
4. **Yerkes-Dodson 外推**：倒 U 来自一般任务心理学，具体到"缩靶点击"的个人最优唤醒区需自测
5. **幕川北式蝴蝶点/抖动点击与本场景无关**：缩靶点击考的是时序精度不是 CPS，别被点击速度教程带偏
6. **PGTI 被部分网站误归为 tracking**：归类混乱说明社区对该场景研究不深，本报告结论以机制推演+交叉验证为主，单一权威源少，置信度中上
