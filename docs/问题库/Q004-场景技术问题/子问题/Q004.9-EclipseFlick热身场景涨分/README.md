# Q004.9 Eclipse Flick Warmup（LG56 热身）涨分

## 问题概述

**"Eclipse Flick LG56 WARMUP 怎么提高分数，我在打的时候会经常性打到中间大圆圈导致打不中"**

场景：KovaaK's「Eclipse Flick Warmup」（Steam 创意工坊 id 2838039877，作者 LG56 热身清单的最后一棒，30 秒）。

**核心结论**：
1. **"中间大圆圈"是不可摧毁的球**（invincible sphere），官方设计如此。目标和球**同色**，只能靠**轮廓凸起**分辨——人眼默认瞄合并剪影的**质心**，而质心在球上、命中红点在边缘。这就是你系统性打空的机制。
2. **分数公式 = 100×击杀 − 9.9×空枪**（用结算面板精确验证：4000 − 108.9 = 3891.1）。→ **碰球的代价 90% 是时间，10% 是分数**。不要为"不碰球"而放慢。
3. **瓶颈不是精度，是节奏**。你的命中率 83.8% 高于中位数玩家（77.55%），但每杀耗时 1.11s（中位数 0.88s）。目标是把每杀耗时压到 0.88s。
