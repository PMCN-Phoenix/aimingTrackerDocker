# Q004.12 tamTargetSwitch Control —— 追击变向目标时一直抖、手腕不灵敏

## 问题概述

**"「tamTargetSwitch Control」在追击这个变向目标时候一直会有抖动，感觉手腕很不灵敏啊"**

场景：KovaaK's「tamTargetSwitch Control」（Steam 创意工坊 id 2183788318）。官方描述："Small regenerating dots **wiggle back and forth** around you, **0.5s ttk**, **up to 1s to regen to full**, **starts regening 0.3s after going off target**"。

**核心结论**：

1. **回血速度 = 伤害速度的一半**（0.5 s 打死 / 1 s 回满）。→ `TTK = 1/(3p−1)`，p 是在目标上的时间占比。**p < 1/3 时目标永远打不死。**
2. **模型实测验证**：50 杀档 Accuracy 61.8%、像素法 60.9%、ROI 法 59.7%（三源吻合）；模型算出的伤害时间 1.21 s 与面板击杀间隔 **1.197 s** 差 1% 以内 → **切换开销 ≈ 0，顶尖玩家"从不停止输出"**。对照 40 杀档：命中率更高（73.8%）但 TTK 更长（1.497 s），切换开销 0.68 s → **在这个场景里"不停"比"准"值钱**。
3. **顶尖玩家的"抖"里几乎没有生理性震颤**：手抖 RMS 3.3–4.1 px（0.25–0.31°），频谱 **64.5–84.2% 在 0.5–3 Hz，峰值 1.88 Hz，8–14 Hz 只占 1.1–5.0%**。→ **"抖"不是手在颤，是手在跟一个 1.9 Hz 的往复。**
4. **目标 0.53 s 一个来回（1.88 Hz），每 0.26 s 要求一次"零速反向"**。腕关节反向切换的机械时间常数约 0.1 s，占半周期 38% → 腕部跟这个频率必然"过冲—回补"。
5. **"不灵敏"和"抖"是同一个物理：静摩擦 stick-slip**。手掌下压 + 手腕蹭垫 → 正压力↑ → 静摩擦↑ → 要么不动（不灵敏），要么弹过去（抖）。B站 165 赞评论是同症状的实测对照。
6. **解法不是"练稳"，是换执行器**：微调支点从"腕/小臂"换成"掌根"（1–2 成张力），打法从"追摆动"换成"守中线 + 等它扫过"。
