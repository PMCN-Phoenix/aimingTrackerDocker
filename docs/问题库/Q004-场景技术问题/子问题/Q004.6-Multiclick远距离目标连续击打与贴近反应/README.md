## 一、结论先行

> **你发现的"看好几个→判断距离→再打"就是转火的标准打法，两个失灵也各有名字：**
>
> 1. **远距离打空** = 弹道段（initial impulse）没有提前减速 + 增益校准漂移。Woodworth 双成分模型（1899 年至今仍是金标准）：甩枪前一大段是**预编程弹道，甩枪速度下根本没时间中途修正**（视觉修正循环要 100-200ms，只作用于最后 25% 路程）。"来不及修正"不是你修正得慢，是**修正窗口被你的起手张力吃掉了**。
> 2. **贴近时反应不过来** = 你在贴近段还在"追着打"，而高手把它当**读目标窗口**。学术结论：视觉反馈只对最后 25% 路程有效（Elliott 2001）；Viscose 说的"瞄准纪律"就是在这里强制一个短暂停顿：读→停→微调，而不是边贴近边乱点。
> 3. **先说公道话**：Fitts 定律摆在那——目标距离翻倍，动作时间必然按对数上升。**远距离连打天生更慢，这是任务属性，别拿近距离的节奏要求自己。**

## 二、问题一：距离远的两个目标怎么连续击打

### 2.1 机制层：三个叠加原因

| 原因          | 证据                                                                 | 表现                       |
| ----------- | ------------------------------------------------------------------ | ------------------------ |
| ① 弹道段无反馈    | Woodworth：弹道段纯预编程，Keele & Posner：视觉修正循环 100-200ms                  | 起手张力拉满→落地过冲→反向回拉→窗口没了    |
| ② 增益校准漂移    | aimfinder：系统性过冲 +10% 以上=马达校准与灵敏度增益不一致                              | 总是甩过一点点（注意区分：系统性偏长≠随机偏长） |
| ③ 腕-only 大甩 | aimfinder："wide flicks done from the wrist arrive hot"；转火教学："手臂同向" | 只有 40°+ 大角度过冲、小角度正常=该上臂了 |

### 2.2 训练法（按优先级）

**① 两段式甩枪：第一段甩 80-90%，第二段微调（最重要）**

- TenZ 原话（训练场自述）："我 flick 的时候其实心里知道第一下不会正好落在目标上——所以我做的是**双摄：先甩一次，紧接着再弹一次**，X 轴 Y 轴分开。看起来是一下，其实是两下。"
- 学术同构：Meyer 优化初始冲动模型——弹道段覆盖大部分距离，残余误差交给修正子动作
- 与 Q014 卸力结论完美衔接：**起手张力拿速度 → 飞行途中泄一档 → 落地剩 10-20% 路程留给微调**。你的"来不及修正"= 落地时剩的路程是 120%

**② 打第一个目标前，眼睛已经在第二个目标上**

- xen2（转火连杀篇）："**锁定你要甩的目标；在完成第一个目标前立即规划第二个目标**，让接下来的线路在脑海里清晰"
- fpstrain："Move your eyes to the target first, then let the hand follow"
- 效果：第二个目标的大甩在第一个目标击杀瞬间就已经"起跑"，省掉的不是手速是**决策时间**——这正是你在 Multiclick 里"看好几个"打法的正规化

**③ 垫边复位技巧（转火教学独有，大角度必备）**

- Target Switch 360 类场景手臂必然拉到垫子极限。教学给的两个合法复位：
  - **命中目标不松左键，快速抬手给手臂复位**（长 TTK 项目，LLOD 调低保证不脱靶）
  - **大目标下"借复位拉枪"**：确认左侧无目标、右侧有目标时，正常往右拉（这次拉枪本身就是复位）——确保每次都在极限时才换边，**反复左右小拉效率最低**
- WIFO（100T 职业哥）实战版："**在到达一个角度之前就复位**"——带着最强壮的手位进对枪

**④ 系统性过冲先动灵敏度，别先怪手**

- aimfinder 判据：整场 kill 系统性偏长 10%+（冷静击杀也一样）→ eDPI 降 10-15% 小步调（大跳=重置肌肉记忆）；5% 内的轻微过冲=人类方差，别追零
- 你 eDPI 448 在瓦高敏带：如果复盘确认是系统性偏长，这是唯一便宜的修法

**⑤ 场景菜单**（转火教学 list + fpstrain wide flick 家族）：

| 场景                                     | 练什么                           |
| -------------------------------------- | ----------------------------- |
| VT Bounce 180 TS / PatTargetSwitch 360 | 大角度+垂直怪角+**复位效率**（打满垫宽才复位得回来） |
| Kovaak's Bounceshot / wide angle 家族    | 大角度获取不丢停住控制                   |
| 1wall6targets small / Sixshot（WIFO 圣杯） | 90%+ 准确率优先的微 flick，先慢后快       |
| 速度转火 list（转火教学 7500 字）                 | 血条显示开起来（视野外靠血条定位）+ 音调调节器（节奏感） |

## 三、问题二：贴近目标的过程中怎么反应过来

### 3.1 机制层：贴近段的真实功能

**"贴近"不是用来反应的，是用来读的。** 学术证据链：视觉修正循环 100-200ms + 只作用于最后 25% 路程（Elliott 2001）→ 贴近段恰好就是那个"最后 25%"——**它是你唯一来得及做视觉引导的窗口**。你感觉"反应不过来"，是因为把它当成了"继续加速冲刺段"，正确的用法是减速换信息。

### 3.2 三个具体动作

**① 瞄准纪律：落地前强制一个"停机时间"**（Viscose 微调指南）

- "像 Alexander/Sova 这种纪律性极强的玩家，你能看到他们在开始微调前有**一点停顿**——这个停顿就是纪律：先读懂目标，再启动微调"
- 明令禁止："没有实际控制运动就仓促出手/垃圾连点（spam clicks）"——你"反应不过来"时的乱点正是垃圾点击
- 对应到 Multiclick：贴近→准星到达→**读半拍**（确认这个目标是不是你要的、血条够不够）→点。宁可选后 50ms

**② 钩取阶段（hook phase，MattyOW）**

- 连招结尾与下一次动作开始之间的过渡叫钩取：**迅速把准星锁上目标且保持跟随**，防抖动/防生硬过渡
- 钩取失败=前臂手腕指尖在获取瞬间还是僵的（张力没释放）；钩取干净=落地即贴住，下一步自动是微调或点
- 与 Q014 卸力"落地即 loose & ready"是同一件事的两个名字

**③ 引导射击：点提前量，让目标来找准星**（MattyOW）

- "点击时不要直接瞄准目标，**提前一点预判它的移动并点击，当目标到达准星时正好命中**"——减少击杀所需的总运动量
- Multiclick 静态目标用不上移动提前量，但"确认出生位→提前占位→等目标出现即点"就是同一个思想的静态版（你在 Q004.5 已经会了）

### 3.3 一句话串联

> **眼先行锁定第二目标 → 第一目标击杀瞬间起跑弹道段（起手张力）→ 途中泄力 → 最后 25% 减速进入读目标窗口（钩取+停机时间）→ 确认即点 → 复位。**  
> 打不出来的那一下，先问自己卡在哪一段：打空=弹道段没收（张力）；贴不住=钩取僵（张力没卸）；点不出=停机时间没留（纪律）。

## 五、反面意见与边界（照例单列）

1. **双段式不是万能**：aimfinder 提醒轻微过冲 5% 内是人类方差，**刻意"先甩 80%"可能变成新的过度思考**——TenZ 的双摄是自动化的结果不是目标；W2 之后应让它退回潜意识（xen2"裁判比喻"：观察引导但不干扰执行）。
2. **降敏派 vs 练手派**：aimfinder 主张系统性过冲先降 eDPI 10-15%；xboxplay 社区主张锁死灵敏度练肌肉记忆。裁决：**先测量（录屏统计偏长率）再选择**——随机偏长练手，系统性偏长动增益。频繁换敏比任何单一灵敏度都毁人。
3. **Fitts 定律的另一面**：远距离慢是物理事实，**别为了追平近距离节奏牺牲停住**（转火教学："所有的速度建立在能停住之上"）——高分速度转火玩家的分数来自"停得稳所以不用返工"，不是甩得快。
4. **复位技巧有场景边界**：垫边复位是速度转火项目技巧，实战 VALORANT 里"命中不松左键抬手"不存在（有开枪惩罚）；实战对应物是 WIFO 的**角度前复位**。两套别混用。
5. **停机时间有代价上限**：Viscose 的 0.3s 停顿是训练轮规范；顶分局对枪窗口没有 300ms 可停——W3 的压缩曲线（0.3→0.15s）必须走完，否则练出"慢半拍"新毛病。
6. **视力与疲劳红线**（沿 Q015）：疲劳时扫视变慢、修正变迟——同一张图午后 miss 率上升先查状态再怀疑手感。
