# Q004.11 Smooth Thin Strafes Raspberry Easy —— 变向时眼睛反应不过来

## 问题概述

**"「Smooth Thin Strafes Raspberry Easy」怎么打，我在他变相时候眼睛根本反应不过来"**

场景：KovaaK's「Smooth Thin Strafes Raspberry Easy」（Steam 创意工坊 id 3584328702）。官方描述："Smooth Thin Strafes w/ **jumps** and slightly more responsive physics than the original"；原版（id 1620729015）描述："Smoothly track **very thin bots** that make **fast strafes**"。

**核心结论**：

1. **目标每秒变向 1.8–3.1 次**（中位间隔 0.21–0.56 s），而眼球平滑追踪的启动潜伏期约 0.1 s、跳视约 0.2 s。→ **眼球在这个场景里没有能跟上的运动系统**，不是你的眼睛差。
2. **WR 玩家的相机速度 = 0 px/s**（背景光流实测，两窗口一致）。他把准星停在目标摆动的中心（目标 x 均值精确 = 屏幕正中 480），**手基本不动，让目标自己扫过来**。
3. **"眼睛反应不过来"的解法不是练眼睛，是别让眼睛去追**：眼睛锁在屏幕中心一小块区域，用余光感知，目标扫进来才确认。
4. **细目标会主动破坏你的眼动**：Heinen 2016 证明目标越小（落在中央凹内）→ catch-up 跳视越多 → 每次跳视都"打断追踪并破坏清晰视觉"。所以 "Thin" 不只是难打中，是专门反眼动设计的。
5. **计分：分数 = 伤害 × 3，命中率 ≈ 分数**。WR 12,720 / 70.65%；排行榜 57,714 条中位 6,999；理论满分 18,003。
