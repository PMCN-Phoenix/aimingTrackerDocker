# Q004.10 Centering II 180 no strafes easier —— 变向端点"停不下来"

## 问题概述

**"「Centering Il 180 no strafes easier」怎么打，我在他移动最边缘的时候不能同步停下来"**

场景：KovaaK's「Centering II 180 no strafes easier」（Steam 创意工坊 id 2291213582，官方描述 "Centering with a 180 map and minimum 103 FOV"；LG56 WARMUP 变体 id 2828056077 为 5 倍粗 / 更慢 / 30 秒）。

**核心结论**：

1. **停止不是一个动作，是一个已经完成的状态。** 你的做法是"保持速度 → 看到它慢下来 → 刹车"，但**反应延迟（0.15–0.25 s）≈ 目标减速段长度（0.2–0.4 s）**，两个数字同量级 → 等你刹完，它已经停住甚至反向，而你的手还在滑。这就是"滑出去"。
2. **"滑出去"不是因为你快，是因为你之前慢了、正在补。** 闭环过冲：目标减速 → 你落后 → 你加速追 → 目标停住 → 你的"追"还在执行。规则是 **宁可一路慢半拍，也不要追**。
3. **端点常落在你行程的尽头。** 手腕行程用完还要继续跟，就只能手臂+手腕一起动 → "两个物理运动相悖"（B站字幕原文）→ 抖动/卡顿/停不下来。**复位要在端点前 0.5 秒，不要留在端点做。**
4. **这个场景的命中率 ≈ 分数**（击杀数全程为 0，分数来自持续伤害）。和 Q004.9 的计分逻辑完全相反——那里"宁可打空也别慢"，这里"每一次脱靶都直接掉分"。
5. **端点是可数的**：参考录像自相似度显示往返周期约 12.0 秒、单程约 6 秒，非常稳定。减速启动点应该"数到"，不是"看到"。
