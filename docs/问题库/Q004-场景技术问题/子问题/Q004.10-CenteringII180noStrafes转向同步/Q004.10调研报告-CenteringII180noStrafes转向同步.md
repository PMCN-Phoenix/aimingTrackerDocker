## 一、结论先行

### 1.1 这个场景是什么

官方描述（作者原文，Steam 创意工坊 **id 2291213582**）：

> "Centering with a **180 map** and **minimum 103 FOV**"

LG56 WARMUP 变体（**id 2828056077**）：

> "Centering with a 180 map and minimum 103 FOV.
> **LG56 WARMUP: 5 times THICCER, a lil bit slower and 30 seconds challenge**"

三个可验证的场景事实（从参考录像逐帧测得）：

| 事实 | 数值 | 意义 |
|---|---|---|
| 目标形状 | 约 **0.4° 宽 × 4–6° 高**的竖直细杆（≈11:1） | 横向只有一条边，**速度线索极弱** |
| 计分方式 | **击杀数全程为 0**，分数来自持续伤害 / 命中 | **命中率 ≈ 分数**，和 Q004.9 完全相反 |
| 参考玩家 | **10,477 分/分**，命中 280/549 = **50.8%**，FOV 103.7 | "1 万分/分" 是这个场景的第一道墙 |

第三条要特别注意。参考录像 29 秒时的 HUD 是：

```
击杀数：0        每分钟击杀：0
命中率：280/549 (50.8%)     伤害：1,734/3,414 (50.8%)
每分钟得分：10,477
```

**这个场景不靠"打死"计分**。所以 Q004.9 学到的"宁可多打空枪也要快"在这里**完全反了**——这里每一次脱靶都是直接掉分。

### 1.2 你的症状，别人在同一个场景里说过一模一样的话

B站《细说平滑和变向在跟枪中的差别》评论区，一个玩家写：

> "打 **c180** 卡 **1w 分**了，准星不是比目标快一点就慢一点。然后到**最左和最右边 30° 角**的时候准星就会**比目标慢**。**到达最边缘目标停下的时候，准星会停不下来滑出去**。"

这一段同时说清了三件事：

1. **"c180" = Centering 180**，就是这个场景；"卡 1w 分" = 卡在 10,000 分/分，正好压在参考玩家的水平线上 → **这是这个场景的典型瓶颈，不是你一个人的问题**。
2. **"准星不是比目标快一点就慢一点"** —— 平滑跟枪的本质是**速度匹配**，人做不到精确匹配，永远在"略快 / 略慢"之间摆动。
3. **"到最边缘目标停下的时候，准星会停不下来滑出去"** —— 和你的"不能同步停下来"是同一件事。

关键在顺序：他先"**比目标慢**"，然后才"**滑出去**"。这两句不矛盾，是**因果**——见 2.3。

### 1.3 主结论：你缺的不是"停"，是"提前开始减速"

记住这句话：

> **停止不是一个动作，是一个已经完成的状态。**

你现在的做法（也是绝大多数人的默认做法）是：

```
保持速度跟住 → 看到它慢下来 → 刹车
```

问题出在"刹车"这一步：**从你看到它减速，到你手上真的减下来，需要 0.15–0.25 秒；而它从全速减到 0 也只要 0.2–0.4 秒。两个数字同量级。**

所以等你刹完，它早就停住甚至开始往回走了，而你的手还在往原方向滑——这就是"滑出去"。

正确做法是：**在减速段就把速度降下来，让"到端点"这个时刻发生在你已经接近零速的时候。** 端点处你不需要"停"，因为**你已经停了**。

## 二、机制层：为什么端点必然是全场最难

### 2.1 目标在端点做的是"慢速停止 → 反向"，不是"急停"

KovaaK's 的 bot 沿路径移动，到端点必须先减速再反向，所以端点附近的速度曲线是**连续降到 0、再反向升起**的，不是阶跃。

《跟枪学习完全攻略指南》（`BV1ox4y187nd`，字幕原文）把速度变化模式列得很清楚：

> "常见的是**匀加速和匀减速**的变化，也会存在**突然加速、突然减速、慢速停止、快速停止**等组合模式。"

这个场景（**no strafes** = 没有横向抖动，只有大范围平滑移动）属于**慢速停止**那一类。

这是好消息：**它给了你减速的过程**。坏消息：这个过程太短，不够你反应。

### 2.2 时间账：反应式减速在物理上没有余量

| 环节 | 耗时 | 说明 |
|---|---|---|
| 视觉识别"它开始变慢" | 0.10–0.15 s | 速度是**二阶信息**（位置变化率的变化率），比位置本身更难察觉 |
| 运动指令传导 + 肌肉执行 | 0.05–0.10 s | 从"松力"到鼠标真的慢下来 |
| **合计（纯反应式）** | **0.15–0.25 s** | |
| **目标减速段长度** | **0.2–0.4 s**（估计） | 场景设计的"慢速停止" |

**结论：反应式减速几乎没有余量。** 你必须靠"预判减速的开始"，而预判唯一可靠的来源是**节奏**。

参考录像的零位移帧间自相似度（`_period.py` 可复现）：

```
lag(s)   0     5    10    12    17    22    24    29
zncc  1.000 0.364 0.890 0.840 0.370 0.900 0.839 0.363
                ↑谷              ↑谷              ↑谷
```

**谷值（端点）出现在 lag 5 / 17 / 29，间隔恒为 12 秒；峰值出现在 lag 10 / 12 / 22 / 24。→ 往返周期约 12.0 秒，单程约 6 秒，非常稳定。**

这意味着：**端点是可数的。** 你不需要"看出"它要停，你可以"数到"它要停。

⚠️ 这个周期是从**非 easier 版**的参考录像测的。`easier` / `LG56 WARMUP` 变体的 bot 速度可能不同（官方写了 "a lil bit slower"），**你需要自己在场景里数一遍**（Drill 3）。

### 2.3 闭环过冲：为什么"慢"反而导致"冲出去"

这是本次调研最重要的一条机制。

跟枪是**闭环控制**：误差（准星-目标距离）驱动手的动作。人在闭环里有一个天然缺陷——**积分饱和（windup）**：

```
① 目标匀速      → 你和它同速，误差 ≈ 0
② 目标开始减速  → 你的手还在原速 → 误差开始积累（你落后了）
③ 你看到误差    → 加速去追 → 你的速度 > 目标速度
④ 目标停住      → 你的"追"还在执行 → 冲过去
```

那个 B站玩家说的"**到最边缘准星比目标慢**"→"**目标停下时准星滑出去**"，就是这条链：

> **"滑出去"不是因为你快，是因为你之前慢了、正在补。**

所以有一条反直觉的规则：

> **宁可一路慢半拍，也不要追。**
> 慢半拍只是持续的、稳定的误差（还可以靠"不动鼠标"吃掉）；追会产生过冲，而过冲在端点是致命的。

《跟枪学习完全攻略指南》里有一句正好对应：

> "有时候你有足够的能力阅读时会发现，**不动鼠标是跟踪小幅度变向的一种方式**。"

端点附近目标速度趋近于 0 → 需要的鼠标位移也趋近于 0 → **正确的动作是"不动"，而不是"精确地慢慢动"**。人手做不到"精确地慢慢动"，但完全做得到"不动"。

### 2.4 支点耗尽：端点常常正好落在你行程的尽头

B站《跟枪不平滑？为什么我停枪时会抖》（`BV1EZ4y1m7EA`，字幕原文，507 赞）：

> "很快很快就会到了你的**手腕移动的极限**，然后你就要开始移动了。移动的时候你还是在用这个手抵着在这里，然后这样子边抵着边在移动，**就你两个物理运动相悖了**。"
>
> "你移动到一定极限的时候，你这个**支点就已经没有用了，你要换一个支点**用的。"
>
> "你想要往左平滑的时候，你的手其实是在往下压的，然后这里又在往左动，这个时候**两个物理运动相悖了，它们之间在互相干扰**，所以你感觉到了有摩擦，你感觉到很难做到平滑。"

这段话解释了"**为什么偏偏在端点**"：

- 一个 180 场景单程扫角很大，你的**手腕行程会用完**；
- 行程用完之后你还要继续跟，就只能"手臂带手腕一起动"——**两个支点同时工作**；
- 两个支点同时工作时，它们的运动方向不完全一致，互相干扰 → **抖动 / 卡顿 / 停不下来**。

而在端点，目标速度趋近于 0，你需要的是**最精细的控制**——偏偏这时候你的支点在最远处、最紧张、最不精细。

> **难度曲线和目标速度曲线正好相反。**

### 2.5 一个被忽略的视觉问题：你在用最差的线索读速度

参考录像里，目标是一根 0.4° 宽的竖杆，贴在**有横向砖缝的白墙**上。

- 判断"它在减速"需要读**速度**，而速度只能从**边缘的位移**读；
- 0.4° 宽的物体，在跟枪速度下每秒钟要移动几十个自身宽度 → 边缘信息几乎不可读；
- 而**背景（墙砖缝）的流动**是大面积、高对比、多边缘的 → 人眼对大范围光流的速度感知**远比对小物体精确**。

所以：

> **你的速度线索应该来自背景，不是来自目标。**

这条是本次调研里最实用的一条改法（见第 1 层）。

## 三、怎么打：五层，从最有效到最次要

### 第 1 层｜把"减速段"当主战场（最高优先级）

| 现在 | 改成 |
|---|---|
| 用**位置**跟：盯着目标，准星追着它跑 | 用**速度**跟：让准星速度和目标速度**相等**，位置误差允许存在 |
| 减速 = 到端点才发生的事 | 减速 = 从"看到它开始慢"就持续进行的事 |
| 到端点时"刹车" | 到端点时"已经松完" |

**判断标准：如果你在端点还需要"刹"，说明你前面没减速。**

具体做法是把每一段跟枪切成三段：

| 段 | 占时 | 你在做什么 |
|---|---|---|
| **匀速段** | ~70% | 准星速度 = 目标速度，误差稳定在 ±1 个目标宽内，**不做修正** |
| **减速段** | ~25% | 目标开始慢 → 你**同步松力**，让手自然滑停，不要主动"刹" |
| **端点段** | ~5% | 目标停住的那 0.2–0.4 秒 → **手完全不动**；它反向之后，用最小幅度重新起步 |

补充一条：**速度线索从背景读**（2.5）。眼睛盯目标，但"它有没有变慢"用余光从墙砖缝的流速判断——背景流速下降比目标自身减速更容易被察觉。

### 第 2 层｜停止 = 撤力，不是加力

《解决最常见的瞄准难题——张力控制》（`BV1A9KpzTEHL`，873 赞评论区）里有两条总结，直接可用：

> "启动的时候紧绷发力，甩起来还没到目标的过程中放松，再用手腕或者手指稍微用点力停下，停下以后再放松来微调。就是**确定目标（紧）→ 跟踪目标过程（松）→ 停止（紧）→ 开枪微调（松）**。"

> "总结就是：【用力———————收力—停下】改成【用力————收力————停下】。"

第二条是关键：**收力要占一段距离，不能只占一个点**。绝大多数人的错误是第一种——一路用力到端点，然后"收力—停下"挤在最后 50ms 内完成。

对应到本场景：

| 错误 | 正确 |
|---|---|
| 全程保持张力（怕掉） | 匀速段张力降到 **3–5 成** |
| 端点前 50ms 才松 | 端点前 **200–300ms** 开始松 |
| 松完立刻反向发力 | 松完 → 停 0.1–0.2 s → 再反向起步 |

### 第 3 层｜提前换支点（复位时机）

《跟枪学习完全攻略指南》：

> "复位的时机如同电影在合适的时间插入配乐：**即将到舒适极限距离，或者是鼠标已经行至鼠标垫边缘时，要及时复位**。"

对这个场景，**端点就是"舒适极限距离"**。所以：

- **不要在端点复位**——端点是你最需要精度的地方，复位会产生一次位移跳变；
- **在端点前 0.5 秒、匀速段中段复位**（那时目标还在匀速，误差容忍度最高）；
- 复位之后要保证：**端点落在你行程的中段，而不是尽头。**

自测方法：打一局，注意端点时你的手腕角度。如果端点时手腕已经"拧到底"或手臂已经"伸到底"，就是支点耗尽——把复位提前。

### 第 4 层｜允许误差存在，禁止"追"

- **允许 1 个目标宽以内的误差**，误差在这个范围内时**不做修正**——修正的代价（抖动、屏幕晃动）比误差本身大。
- 误差超过 2 个目标宽才修，且修正只做**一次**。《细说平滑和变向》的高赞笔记：**"变向瞄准不是多次定位纠正，而是单次纠正后继续平滑跟枪"**。
- 还有一条来自《一个可以让你理解变向的项目》UP 主本人的回复，讲的是同一个机制：

> "如果目标变向了，你往反方向修正，那么**目标相对于你速度是变得更快了**。然后**频繁的修正错误会导致屏幕晃动失去对目标的视觉清晰度**……你看我的视频目标的运动轨迹是很清晰的，因为**我准星一直和它同向运动**。"

"准星和目标同向运动"——这一句比任何技巧都重要：**反向修正 = 相对速度翻倍 = 你更看不清 = 更修不准**。

### 第 5 层｜参数层

1. **FOV ≥ 103（水平）**。官方写死的限制，参考玩家用 103.7。**FOV 越低，端点前后的屏幕位移越平缓**，越容易跟。别用 120+。
2. **灵敏度**：这个场景是**大角度平滑跟枪**，需要手腕 + 手臂接力。参考《跟枪不平滑》的判定法——**以肩膀为支点、一次不抬鼠能转不到 270°，就说明灵敏度太慢**。cm/360 超过 45 的话，这个场景会让你在端点频繁抬鼠。
3. **确认你打的是哪一个变体**（见待拍板 #1）：`easier` 原版 vs `LG56 WARMUP`（5 倍粗 + 更慢 + 30 秒）。两者目标宽度差 5 倍，目标值完全不同。

## 四、训练处方（15 分钟）

### Drill 1｜只减速，不反向（4 分钟）★ 最有效

- 进场景，正常跟枪
- **规则：目标一开始变慢，你就松力到零，然后保持不动，直到它反向移动 0.3 秒后再重新跟上**
- 目的：把"减速"从"端点事件"变成"一段过程"
- 前 2 分钟分数必然掉，正常。这条 drill 练的是"不再滑出去"，不是分数

### Drill 2｜端点零速（4 分钟）

- 只打**端点前后的 1 秒**（其他时间随便打）
- 目标：端点这 1 秒内，准星相对目标的偏差 **不超过 2 个目标宽**
- 目的：把"端点"从"最容易脱靶"变成"最稳的 1 秒"

### Drill 3｜数拍子（3 分钟）

- 进场景**不开枪**，只数目标往返的秒数（参考录像约 **6 秒单程 / 12 秒往返**）
- 数准之后，**在端点前 0.5 秒开始默数"松——停——走"**
- 目的：把减速的启动点从"看到"改成"数到"

### Drill 4｜换支点预演（2 分钟）

- 每次目标到端点前，**先复位**（抬鼠或换支点），让端点落在行程中段
- 目的：消除 2.4 的"两个物理运动相悖"

### 收尾｜3 轮正式打（2 分钟）

记 `每分钟得分 / 命中率`。**只看命中率有没有涨**（这个场景命中率就是分数）。

## 五、反面意见

**① "提前减速会掉分"——短期对，长期错。**
提前减速在匀速段会带来一点持续误差，但端点不再滑出去。**先接受匀速段掉 1–2%，换端点段涨 3–5%。**

**② "不要预判变向"——这句话对，但别用错。**
《跟枪学习完全攻略指南》说的"过度预判"是指**目标还没变向你就先变向**（"目标没变向，但是你准星变相了"）。这里要预判的是**减速**（连续量，可感知），不是**反向**（离散事件，不可预判）。

> **减速要提前，反向要等。** 这两件事别混。

**③ "目标停下时应该继续微调保持压枪"——在这个场景不成立。**
这个场景的分数来自停留在目标上。端点时目标几乎不动，你"不动"就是满分，主动微调只会制造抖动。

**④ 参考录像的 50.8% 不能直接当你的目标。**
你的记录里 CenteringII 命中率是 79–83%（9,306 / 9,108 / 9,522），明显高于 50.8%。最可能的原因是**目标宽度不同**（WARMUP 版 5 倍粗）。**纵向比自己的历史值，横向只比"端点段的命中率"。**

**⑤ 关于"180"的含义，官方没解释。**
描述只写了 "a 180 map"，没说 180 指什么（场地名 / 扫角 / 弧段）。从参考录像看是**大角度连续转身**，不是小范围抖动。这一条不影响打法，但别拿"180°"去推算具体角度。
