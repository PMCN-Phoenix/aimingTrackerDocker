# Q015 周边视觉与注意力分配

> **触发语**："非注意力聚焦圆圈出现目标我反应不过来也看不到，转视角也是反应不过来新的视野出现人了，而如果纵观整个屏幕又不好对枪打不准，这种情况是人体缺陷吗，我怎么可以更快反应过来"
> **调研日期**：2026-10-17｜**状态**：调研完成，四周方案已出待执行
> **渠道**：B站 319 视频→15 精选→8 字幕 + 学术回源 3 篇（Green & Bavelier 系列）+ 英文社区 3 源

## 一句话结论

**是人体构造不是缺陷**（中央凹仅 2° 高清，余光只做运动检测），但"注意的有效范围（UFOV）"可训练（10 小时动作游戏训练即扩大 20-30%）；"纵观全屏"方案本身错误，正确解法是 **soft focus + 分时段注意力分配**（能开枪看准星，不能开枪看小地图）。
