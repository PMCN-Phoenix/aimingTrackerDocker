# Q018-练枪一小时与排位频率

> 立档：2026-10-18 ｜ 触发语："我每天练一个小时枪，我不想干涉日常生活又想有持续进步应该多久时间打一次瓦"

## 核心裁决（30 秒版）

1. **问题不是"多久打一次"，是"每周几次 × 每次几把 × 间隔多长"** → **每周 3 次、每次 2 把、间隔 ≤3 天**
2. **间隔上限 3 天**：手感（热身损耗）几分钟自愈，但地图感/清点流程/对手模型靠检索维持，间隔越长成本越高
3. **总量固定时，拆成更多天 > 单次更久**：Walsh 2023——保持取决于 **session 总数**，不取决于每次练多少
4. **1 小时练枪已经超配**：按「练枪 ≤ 总 FPS 时间 20%」反推需要 35h/周总时长 → 不现实。这 1 小时应拆成 **15 热身 + 30 专项 + 15 游戏内迁移**
5. **不能只练枪**：Valorant 的练枪→实战转化率在 FPS 里属最低一档，枪法只占胜负一小部分
6. **掉段不是约束**：官方已移除 14 天不打隐藏段位，普通段位无 decay；只有 Immortal+ 排行榜需每周 1 场
