## 四、VDIM 评分说明

### VDIM 本身没有独立的评分系统

VDIM 是**训练计划**，不是评分系统。它用 **Viscose 基准**来衡量进步。

### 每个训练日的场景分为两类

| 类型 | 说明 | 有档位对比吗 |
|------|------|-------------|
| **benchmark（基准场景）** | Viscose S2 Easier 基准场景（或近似版本） | ✅ 有档位线（Gold/Platinum/Diamond等） |
| **training（训练场景）** | 纯训练场景，用来提升技术 | ❌ 只有分数记录，没有档位线 |

### 各训练日的基准场景

| 训练日 | 主题 | 基准场景 |
|--------|------|---------|
| Day1 | 平滑跟枪 | Controlsphere、Smoothsphere |
| Day2 | 反应跟枪 | （VT Plaza Novice、VT Air Novice 为训练版） |
| Day3 | 速度转火 | psalmTS Voltaic Easy |
| Day4 | 移动瞄准 | （无直接对应基准，补弱项用） |
| Day5 | 动态点击 | Floating Heads Timing 400%、Popcorn Voltaic Easy、B180 Voltaic 3-click |
| Day6 | 静态点击 | （训练场景为主） |

### 怎么看进步

1. **每天**：看当天基准场景的分数是否比上次高
2. **每2周**：跑一次完整 Viscose 基准，看各子类的档位变化
3. **整体**：看有多少子类过了 Gold/Platinum/Diamond Complete

## 五、进阶标准

### Viscose 基准档位（从低到高）

Bronze → Silver → Gold → Platinum → Diamond → Jade → Grandmaster → Nova → Astra → Celestial

### VDIM Novice → Intermediate 进阶标准

**满足以下多数条件即可考虑进阶**：
- [ ] VDIM Novice 连续完成4-6周
- [ ] 最近一次基准测试中，**所有子类过 Gold Complete**
- [ ] 至少3-4个子类达到 Platinum
- [ ] VDIM Novice 的场景感觉"不够有挑战性"
- [ ] 没有明显的平台期，进步趋势稳定

**注意**：
- 不要急于进阶，Novice 打扎实比匆忙上 Intermediate 更重要
- 如果有明显的弱子类，可以在 Novice 多停留1-2周专项补强
- 进阶后前1-2周可能表现更差，这是正常的学习曲线，要坚持

### 各档位进阶的正常时间参考（从Gold Complete开始）

| 目标 | 参考时间 | 前提 |
|------|---------|------|
| Gold Complete → Platinum Complete | 2-4周 | 每天1-2小时，100%专注 |
| Platinum Complete → Diamond Complete | 4-8周 | 同上 |
| Diamond Complete → Jade Complete | 2-4个月 | 同上，可能需要增加变异性训练 |
| Jade → Grandmaster | 3-6个月 | 同上，高阶需要更系统的训练 |

> 注意：以上为参考，实际进度因人而异。关键看趋势，不要看单日波动。

## 六、平台期判断与应对

### 什么时候算平台期

- 连续**2-4周**多数子类分数停滞，无明显进步
- 不是单日波动，而是**平均分趋势**停滞

### 平台期突破优先级

1. **先查基础**：专注度、睡眠、是否害怕失败、是否分心
2. **从卡壳场景休息**：暂时不练那个场景，练其他的
3. **增加变异性**：每周同一天子类但换不同场景
4. **改变变量**：换灵敏度、玩更难的变体
5. **尝试双灵敏度法**：低灵敏度练手臂+高灵敏度练手腕
6. **分数阈值法**：每个场景设阈值，达不到不进入下一个
7. **休息1-2周**：完全不影响水平，回来可能反而突破
8. **放下高分执念**：放松+坚持训练计划，分数自然会来
