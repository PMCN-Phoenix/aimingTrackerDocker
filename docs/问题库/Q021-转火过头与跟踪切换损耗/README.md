# Q021 转火过头与跟踪切换损耗

## 问题概述

在 `E - Friday - Speed TS (Novice) - LG56`（= VDIM Day3 速度转火，12 项 / 48 轮 / `KovaaKsTaggingAlmightyHip`）中：**跟踪单个目标时平滑稳定，但目标切换瞬间出现明显损耗、准星跳过头。**

## 三十秒结论

不是"切换太慢"，而是**切换这一段的制动没建立**，被三件事放大：

1. **视觉上不可能"看到位再停"**——感知位置是 ~70ms 滑动平均，平滑追踪对变向的响应要 90–130ms；高速切换时你"看见过头"时早已过去。
2. **切换瞬间手部状态变了**——跟踪是低张力轻贴（摩擦小、微调灵敏），切换会自然加压（握力上冲，压力再放大：鼠标瞄准任务里握力 +51%、腕屈肌 EMG +140%，而精度几乎不变）；落点后微调"不粘"，只能再推一次 → 越过。
3. **强项在拖后腿**——静态点击 93–96% 命中，切换点击掉到 65–83%，典型的"过度依赖微修正"画像。

**一句话改法**：把"甩到位再修正"换成"**甩到附近就主动卸力，让鼠标自己滑停**"，并且切换瞬间保持松握。顺序：先松，再准，最后才是快。
