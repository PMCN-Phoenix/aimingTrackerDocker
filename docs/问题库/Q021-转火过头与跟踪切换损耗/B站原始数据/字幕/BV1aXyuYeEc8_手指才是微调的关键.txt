# 手指才是微调的关键
# BV1aXyuYeEc8

如果今天你完全达不到对手的摆设
其实这个会是手指跟微调的问题哦
来我们看我们今天把手每个地方负责的部位
去跟大家做分享
如果一个大部分选手会选择常态模式
会是像这样子
把手臂放在整个鼠标垫上
用整只手去完成在实战中右手的全部分工
那具体上来说有哪些工作呢
一微调
二小定位
三中定位
四大定位
其实这么多的定位说白一点就是距离
距离跟你的出力有什么连接性呢
其实就是你离目标越远
出力越大
而离目标越近
出力就越小
而我们在实战中
目的就是永远将准星瞬间自动吸附到
最合理的育苗上
最后透过育苗或微调或定位完成击杀
以这样子的概念来看的话
所有的预瞄跟定位本质上是相同的
也就是说整个瓦关于右手瞄准
整个的核心概念
就是透过发力控制及手的协调性
每一个部位负责不同的区域来达到无限定位
眼睛看着想预瞄的区域
判定跟准星的距离
瞬间去决定出发力大或是小
接着用收紧肌肉的方式啊
收紧手臂肌肉
再捏紧你的手指
做一个制动
将它停在目标上了
接着微微放松
马上来准备下一次的定位
手臂必须去负责转身以及大定位和中定位
手腕则是小定位
手指则是微调
而我自己的手姿势上来说
手臂当成发力支点
手腕悬空连接到手指
刚刚好打通了一个相对支点
手指跟手臂的操纵性就会很好
以这样的理论来说的话
平滑瞄准是个完全没有意义的一件事情
你唯一需要做平滑瞄准的原因
就是你的手对于鼠标的控制制动技术不佳
导致你的定位是很差劲的
结果反而变成了你需要降低自己的移速
使其更好去被控制
除了平滑瞄准没有意义之外
其实很多时候大家打不到摆设的
最大原因就是右手的分工错误了
有些人是没有手指操控这个概念哦
手指操控怎么做
大拇指无名指
小拇指捏住操控
这里是负责操控微调及小定位的最佳填区了
我有一个右手定位速度极快的学生哦
他却连微调都做不好
原因是什么
原因在于
虽然他花了大半个月的时间去练习
但却永远是使用手腕
在负责贴近敌人的这块区域
这会导致他的微调永远都会过头
所以呢他的一次定位永远不会准嘛
最后形成的解决方案就是
他每次应该使用微调的时候
都是使用成了适合小定位的手腕
导致它超出了一个微调的范围
没有办法定位到
然后才将鼠标定位回正
拉稍微刚好远离头线
再做第三次定位
你看你多加上了这次的回正
你是不是就多浪费一次定位
而且本质上你一次定位是永远不可能准的
除非刚刚好你敌敌人的头部就是你的完美天区
这会造成什么后果
也就是说你的预瞄摆的越好
反而会影响你自己的击杀
因为你的头越接近敌人的时候
你反而会因为你的手腕没有一个微调
你不是用手指操控吗
你用手腕你永远都会超过它
你的一次定位根本就不可能达到他
你只有当摆到百分之百准确使用预瞄去杀人
或是刚刚好90分的一个误差
你才能够刚好在一个手腕的田区上去击杀敌人
当你的田区是处于90~99的时候
这些预瞄误差完全都会导致
你的一次定位是永远不可能中的
因为你的动作里面根本就没有微调
那么大B呢自然就是为了做大范围甩动
跟中范围移动了
不管如何
你唯一需要注意的其实就是什么
发力你得用力
你得用最快的速度
达到你希望准星到达的目标点
接着当敌人出现的时候
你是不是就只需要发微微的力
交给前方的手指处理就行了
这套逻辑就形成了完美的
右手瞄准的标准答案哦
我知道大部分的玩家都会在某一方面产生一
部分的偏离
甚至是非常大的偏离
那你需要做的其实就只是说你知道自己的问题
到底距离标准答案有多少
我们再进行修改或强加就好好
