## 一句话结论

**枪法之外至少有 9 项能力可以自己练，其中 4 项能"数字自动采集"（急停停射、预瞄头线、首杀/决策、经济），3 项能"结构化计数"（Peek、道具、信息），2 项只能间接观察（沟通、心理）。**
最该先练的不是最有名的身法，而是**急停停射纪律**——它零成本、每天 10~15 分钟、且已有 Kovaak 场景可以直接出分（Valorant Peek Practice / Counter-Strafe One-Taps）。
