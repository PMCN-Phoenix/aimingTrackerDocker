## 一句话结论

**枪法之外有 9 项能力能自己练，但「能量化」不等于「值得量化」**：只测**动作层**（急停有没有停住 / peek 暴露几帧 / 准星在不在头线）和**结果层**（DD 德尔塔 / KAST / 经济纪律），**不要迷信练习分数层**——那一层的远迁移证据基本为零（2024 综述 + 《A Search for a Phenomenon》）。
