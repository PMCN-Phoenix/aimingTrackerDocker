# Q025.2 三项验收指标：怎么算、怎么取数、怎么做到

> 配套 [Q025.1 执行卡](Q025.1-非枪法执行卡.md) 的第六节。  
> 三项难度完全不同：**KAST 是取数问题 · 无信息接敌是行为问题 · 形态纯度是结构问题**。不能当成三件平行的事。

---

## 〇、先说一个必须纠正的前提

**国服拿不到现成的 KAST。**

KAST 是 tracker.gg 的统计口径，覆盖 Riot 国际服账号；国服由腾讯代理、账号体系独立。国服可用的三个渠道（掌上无畏契约 / 小黑盒 / WeGame 战绩页）给的是 **KDA、场均伤害、爆头率、六维图、段位**——**没有 KAST**。

所以「KAST 70%+」这条要么**自己算**，要么**换成国服能数出来的两个替代指标**（第二节）。下面两条路都给。

---

## 一、KAST 70%+ —— 怎么算、70% 从哪来

### 1.1 真实定义（必须先钉死，否则算出来是错的）

```
KAST = 有(击杀 或 助攻 或 存活 或 被交易)的回合数 ÷ 总回合数
```

**关键：每个回合只算一次。** 一个回合里既杀两人又被打死再被队友交易回来，仍然只贡献 1。

### 1.2 近似公式与它的偏差（5 分钟/周，免费）

国服能拿到的原始数：场均击杀 K、场均助攻 A、场均死亡 D、该局回合数 R（比分总和）。

```
近似 KAST = (K + A + (R − D) + T) ÷ R        T = 被交易次数（回放数）
```

**这个公式系统性偏高**，因为 K、A、S 在同一回合会重复计数。所以：

- ❌ **绝对值不能跟 70% 对标**
- ✅ **只能同口径做趋势**（本周 vs 上周 vs 30 天前）

### 1.3 更可靠：拆成两个国服数得出来的数（推荐）

对你的形态（接应/反打型）来说，KAST 的四项里 **K 和 A 是枪法已经在产出的**，真正缺的是 **S（存活）和 T（被交易）**——而这两个恰好是国服能自己数的。

| 指标        | 公式                      | 国服怎么取                    | 目标      |
| --------- | ----------------------- | ------------------------ | ------- |
| **回合存活率** | (R − D) ÷ R             | 掌瓦/小黑盒看场均死亡 + 比分回合数，无需回放 | 基线 +5pp |
| **被交易率**  | 我死后 5 秒内队友补掉凶手的次数 ÷ 死亡数 | **回放数**                  | ≥40%    |

**这两个数才是你 KAST 的真实来源。** 它们达标了，KAST 自然上去；只看近似 KAST 会一直被「偏高」骗。

### 1.4 70% 的行为层路径（不是靠枪法）

KAST 分子四项，提升方式完全不同：

| 项         | 怎么提                            | 对你的难度            |
| --------- | ------------------------------ | ---------------- |
| K 击杀      | 枪法（已在做）                        | 低（已是强项）          |
| A 助攻      | 技能/伤害助攻，需要前压或配合                | **高**（0 接口形态，最难） |
| **S 存活**  | **不无信息接敌**                     | 中（靠默认动作，见第二节）    |
| **T 被交易** | **进攻站第二身位、防守站 off-angle 有人能补** | 中（靠站位，不靠手）       |

> **这是本文最重要的一条**：KAST 70% 和「无信息接敌 −30%」**不是两个独立指标**。  
> 减少无信息接敌 → 存活率上升 → S 项上升 → KAST 上升。  
> 所以别把它俩分开排期，**后者是前者的手段**。

## 二、无信息接敌 −30% —— 怎么数、怎么减

### 2.1 定义必须钉死到能照做

**接触前 3 秒内，以下四者一个都没有 = 无信息接敌：**

1. 听到脚步 / 枪声 / 技能音
2. 看到身影 / 弹道 / 技能特效
3. 队友报点或 ping
4. 已知的敌方最后位置（小地图 30 秒内的红点，或队友死亡位置推断）

四选一命中就算「有信息」。**"我觉得他在那"不算信息。**

### 2.2 怎么数（3 分钟/局，和半买同一遍回放）

只看两个瞬间，然后倒推 3 秒：

- 自己的**首次交火**瞬间
- 自己的**死亡**瞬间

**记「每局次数」，不记占比。** 因为占比会被局数波动污染——回合少的局容易假进步。

```
基线（首周）：X 次/局
目标（第 4 周）：≤ X × 0.7
```

### 2.3 怎么减（行为层，三条硬规则）

| 规则               | 具体动作                                 | 依据                                                        |
| ---------------- | ------------------------------------ | --------------------------------------------------------- |
| **1 回合前定死架位**    | 买枪阶段就把「这回合我架哪」说死（对自己说也行），不给"到时候看"留口子 | `BV1sht262EfJ` [01:07]：低段位首要问题是「不知道自己该架哪里」——不做这步，被动会退化成发呆 |
| **2 过角前停 0.5 秒** | 停一下，找 2.1 的四类信息中的任意一个；找不到就不过         | 无信息接敌的本质是「用枪法赌信息」                                         |
| **3 不做第一个暴露的人**  | 进攻站第二身位、防守站 off-angle                | Q026 §6.4：第一枪要静精度（你的弱项），第二枪要重捕获（你的强项）                     |

### 2.4 一个反直觉点

**无信息接敌不是靠「打得更准」降下来的，是靠「默认不动」降下来的。**

你的形态是被动触发型，这恰好是优势：**你不需要变主动，只需要把「没信息就不动」变成默认。** 反过来，如果你试图用「反应更快」来解，就是在用强项掩盖问题——那些接敌大概率还是会输，只是输得好看一点。

## 三、形态纯度 ≥80% —— 怎么算、怎么提

### 3.1 公式与两个数字的唯一定义（口径不许改）

```
形态纯度 = 独成立 ÷ (独成立 + 摩擦)
```

| 列       | 定义                                                     | 记什么     |
| ------- | ------------------------------------------------------ | ------- |
| **摩擦**  | 我**想做但没做**的动作，原因是「需要队友配合」                              | 计数，不写原因 |
| **独成立** | 我做的、**不需要任何回应**就有效的动作（架点拿到信息 / trade 成功 / 残局接住 / 单点守住） | 计数，不写原因 |

**打完 60 秒内记完。** 超过 60 秒就会开始给自己讲故事，那是复盘不是计数。

### 3.2 80% 是什么意思（别误读）

不是「打赢 80%」，是「**80% 的动作不依赖队友**」。分子分母都是**动作数**，不是回合数、不是击杀数。

### 3.3 怎么提到 80%：三步替换，不是「练」

| 步        | 动作                        | 为什么有效                     |
| -------- | ------------------------- | ------------------------- |
| **1 记账** | 每局记两个数，连记 5 局             | 你会看到摩擦集中在那 2~3 个动作上，不是弥散的 |
| **2 替换** | 把 top 3 摩擦动作换成下面的「0 接口版本」 | 分子侧直接降                    |
| **3 加产** | 每局至少做 **2 件**独成立动作        | 分母侧增加，且防止「什么都不做刷高纯度」      |

**替换清单（这是提高纯度的全部内容）**

| 有摩擦的版本    | 0 接口版本                                                 | 出处               |
| --------- | ------------------------------------------------------ | ---------------- |
| 让队友帮我架某条线 | 自己站 off-angle，等对方先探                                    | Q026 §6.4        |
| 叫队友一起进点   | 等第一个进的人，站第二身位做 trade                                   | 同上               |
| 指挥转点 / 分配 | 只跟**已经打起来的那一侧**（有声音 = 有触发信号，没信号就不动）                    | 同上               |
| 要求队友报点    | 自己用 **L1 三条广播**：我在看哪 / 我看到谁 / 我什么时候动——**以「我」开头，不要求回应** | Q026 §8（广播 ≠ 请求） |
| 补位        | 专精 1 个角色，不主动补                                          | Q026 §2.1–2.2    |

> **不要试图「让队友配合」来减少摩擦**——那是在增加接口，摩擦只会更大。所有解法都必须落在「我一个人就能做完」上。

### 3.4 判据

| 纯度     | 含义                       |
| ------ | ------------------------ |
| ≥80%   | 形态成立，随机性伤不到你             |
| 50–80% | 形态在形成，还有一半动作挂在别人身上       |
| <50%   | 你其实在打「5 人队」，只是没有 5 人队的配合 |

## 四、三项其实是一条因果链（最重要的一节）

```
行为改动：  无信息接敌 ↓（默认不动）  +  第二身位/off-angle 站位
                    ↓
中间指标：  回合存活率 ↑  +  被交易率 ↑
                    ↓
结果指标：  KAST（S + T 项）↑
                    ↓
结构指标：  形态纯度 ↑（这两个动作本身就是 0 接口的）
```

**所以三项不是三个任务，是一件事的三个测量面。**

这也解释了 Q025.1 第六节那句「只过一条就砍到只留选位与对枪时机」——因为**选位与对枪时机这一项同时喂三个指标**，它是唯一的三重收益项。经济纪律是独立加成（不影响这条链），所以砍不动时才砍它。

## 六、三个会骗你的坑

| 坑                     | 为什么是坑                        | 怎么防                                |
| --------------------- | ---------------------------- | ---------------------------------- |
| **拿近似 KAST 跟 70% 对标** | 公式重复计数，系统性偏高                 | 只看同口径趋势；真要对标 70% 就逐回合打勾（一局 20 分钟）  |
| **数「占比」不数「次数」**       | 局数/回合数波动 → 假进步               | 一律用「每局次数」，目标写成「相对首周 ×0.7」          |
| **靠「少做事」刷高纯度**        | 什么都不做 → 摩擦 0、独成立也少，比率虚高但影响变小 | 硬性下限：**每局至少 2 件独成立动作**，不达标就记「本局无效」 |

第三条尤其要注意：**纯度可以刷，影响不能刷。** 如果纯度上到 90% 而 ADR 和 KAST 都在跌，那不是形态优化成功，是退化成「躲着打」。

---

## 七、一句话版

```
KAST：国服没有现成的 → 用「存活率 + 被交易率」代替，回放数被交易
无信息接敌：四选一都没命中就算 → 减它靠「停 0.5 秒 + 不做第一个暴露的人」
形态纯度：独成立 ÷ (独成立+摩擦) → 提它靠「把 top3 摩擦动作换成 0 接口版本」
三者一条链：站位改 → 存活/被交易涨 → KAST 涨 → 纯度涨
```
