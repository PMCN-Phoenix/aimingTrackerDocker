## 〇、v2 相对 v1 改了什么（先说清楚）

v1 只做了通用网页搜索，没有真实抓取、没有原始数据留档，因此**有两处结论被这轮证据推翻或修正**：

| v1 的说法 | v2 的修正 | 证据 |
|---|---|---|
| 「急停停射门槛最低、收益最高，优先级第 1」 | **降到第 3**。Valorant 急停只需 8 帧（≈133ms），反向键只快 10ms，天花板比想象的低 | 大东彦 `BV1MY4y1H79Z` [00:30]–[00:47] |
| 「训练场 Shooting Test Hard 是官方可量化考核，职业稳定 25+」 | **降级为「热身参考」**。高分玩家实测 17–22 就够打到神话二；职业 25+ 是幸存者数据 | `BV1qxtSzdEHX` 评论 967 赞 / 429 赞 |
| 「Kovaak 已有 Peek Practice / Counter-Strafe One-Taps 可直接出分」 | **你库里这两个场景是 0 轮**（154 个场景全查过），属于「需要新增」不是「已有」 | 本地 stats 全库扫描 |

**v2 的核心论点也变了**：v1 只问「能不能量化」，v2 加了一道更严的筛子——**能练 ≠ 能测 ≠ 值得测**。

## 一、核心结论（7 条）

1. **「可量化」不是一维的**。同一项能力有三个层次：①**动作层**（你身体做了什么，可数）②**结果层**（比分板上的产物，可读）③**练习分数层**（训练软件给的分数，最容易被伪造）。这一轮最重要的发现是：**练习分数层的迁移证据几乎为零**，而 v1 把它当成了主战场。

2. **远迁移（far transfer）没有可靠证据**。2024 年综述结论是「perceptual/cognitive training 到运动表现没有一致证据」；更狠的二阶分析直接叫《A Search for a Phenomenon》——控制安慰剂与发表偏倚后，远迁移效应≈0。同年 KovaaK 试点研究很能说明问题：Macro Flicking 85.29%→87.04%、hits/s 2.57→2.63（测量信度 ICC 0.947–0.995 优秀），但 **Micro Flicking 和 Strafe Tracking 同一批人没有显著改善**。

3. **所以真正值得测的只有两类**：**动作层**（急停有没有停住、peek 暴露了几帧、准星在不在头线）和**结果层**（DD 德尔塔、KAST、FK/FD、经济纪律）。中间那层练习分数，只用来做「当天状态闸门」，不用来做能力评价。

4. **B站 最重要的技术性修正：Valorant 的急停跟 CS 不是一回事**。60 帧下从松键到速度归零只需 **8 帧（≈133ms）**，按不按反方向键差异「基本不存在」；海外用红点精密测试的结论是**只快 10ms**。所以「狂练反向急停」是照搬 CS 的错配——大东彦自己就说「大部分玩家在瓦遇到的问题，并不是急停」`BV1MY4y1H79Z` [01:15]–[01:17]。反方向键的真正价值是**确认感**，不是速度 [01:01]。

5. **眼动实验给出了「非枪法」最硬的量化指标**（Aalto 2024，80 名 CS2 玩家，Tobii 600Hz）：职业（FPL+）vs 黄金新星——平均注视时长 **190ms vs 430ms**；peek 期间每秒扫视 **4.1 vs 1.9**；**预测性注视 72% vs 14%**；注视点偏离准星 **3.2° vs 11.4°**；头线预瞄保持率 **89% vs 31%**。CS:GO 传感论文（90% 分类准确率）另一组数：职业注视准星 **65.4% vs 43.2%**，看雷达 **1.3% vs 11.9%**，A/D 用得多、W 用得少，且会打 A+Ctrl+左键 这类复合操作。**代价是要眼动仪，所以落地时降级为「录屏抽样人工计数」。**

6. **新增一个 A 级结果指标：DD 德尔塔**（每回合造成伤害 − 受到伤害）。B站 超凡二作者自报 DD=+31，并明确说「比爆头率更能证明枪法水平，因为有些人爆头率高不是因为枪法好，而是不爆头就杀不了人」`BV1C6421G7pP` [00:15]–[00:45]。这条正好补上 v1 只用 HS%/KAST 的盲点。

7. **你的库里已经有 5 类「非枪法代理场景」，共 633 轮**（详见第五节）——但 **Peek / 急停类场景 0 轮**。也就是说：移动中瞄准你练了，停射纪律你一次都没测过。

**迁移距离**：**近** = 与实战动作同构 ｜ **中** = 同一认知过程、环境不同 ｜ **远** = 只有分数像，动作/情境不同构

## 三、逐项详解（带 B站 时间戳引用）

### 3.1 经济纪律（ROI 第 1）

**为什么排到第一**：它是唯一「零机械成本、当天生效、每局有 5–8 个决策点」的项目。而且硬数据全在：

- 手枪局双方各 **800**，赢家比输家每人多 **1100** `BV1Ca411d7oC` [00:28]–[00:37]
- 赢一局 **+3000**，输一局 **+1900**，连败补偿 **+500/次、最高叠到 2900** `BV1bs4y1N71U` [00:40]–[00:47]
- 满买线 **3900**（2900 主战 + 1000 大甲）`BV1bs4y1N71U` [00:14]–[00:23]
- 手枪局的钱要花完，因为「小枪局决定了第二局的经济优势」`BV1Ca411d7oC` [00:31]–[00:34]

**量化口径（A 级，纯计数）**

| 指标 | 定义 | 目标 |
|---|---|---|
| 半买回合数 | 队内花费 >1000 但未满买的回合 | ≤1 局/周 |
| 同步买率 | 全队同回合满买 ÷ 总买枪回合 | ≥80% |
| 崩盘链条 | 半买后下一回合仍未满买的次数 | 0 |
| 残钞率 | 回合结束剩 >1000 credits 的回合占比 | <10% |

**怎么记**：回放开着，只看买枪阶段（每回合 5 秒），打勾即可。一局 24 回合 ≈ 3 分钟。

---

### 3.2 选位与对枪时机（ROI 第 2）

**这是本轮最反直觉的一条**。B站 帮上百人复盘后的结论：到了白金—钻石，「选位的权重比就开始逐渐重于枪法的发挥」，原话是：

> 「牢记**选位大于枪法**，**选择对枪的时机大于枪法的发挥**」——`BV1pdVozEEbS` [06:11]–[06:15]

**量化口径（B 级）**

- **无信息接敌率** = 死亡时自己没有任何敌人位置信息 ÷ 总死亡数
- **不该打的枪** = 回放中「1v2 以上且无掩体、无道具、无队友 trade」的主动接敌次数
- **换位率** = 同一位置连续两回合架枪的次数（应趋近 0）

**验收**：无信息接敌率周环比 −30%，就是有效。

---

### 3.3 急停停射（ROI 第 3，v1 的第 1）

**先纠一个流传很广的错**：Valorant 不需要 CS 式反向急停。

> 「在 60 帧的视频下，不论按不按反方向键，瓦洛兰特的急停只需要 **八帧** 的时间……按反方向键比不按要快 **10ms**，基本上是没法感受到的差别」——`BV1MY4y1H79Z` [00:30]–[00:49]

社区实测也一致：评论 358 赞「反向急停第一枪不准的，没用，我老 CS 玩家了，瓦最好的还是松手急停」。但反方向键有另一个作用——**确认感**：

> 「按反方向键来急停，有利于加强急停的**确认感**，从而提高身位控制能力」——`BV1MY4y1H79Z` [01:00]–[01:03]

卡子说得更细：「我不推荐你们所有人都用松开急停……在练习反方向 AD 急停时，你能用急停给自己一个**信号**」`BV1we48ejEXe` [00:20]–[00:38]。

**两个常见错误动作**（都可数）

1. **为了急停而急停**：`BV1MY4y1H79Z` [01:23]–[01:26]「急停是为了更好的击杀敌人而服务的」
2. **用蹲代替急停**：`BV1MY4y1H79Z` [02:21]「在瓦罗兰特里蹲并不能代替急停的作用」——必须先松方向键再蹲 [02:26]

**量化口径**

- **A**：录屏 60fps，抽 10 次开火，逐帧看「开火那一帧速度是否为 0」→ 静止开火率
- **A**：Kovaak 新增 `Counter-Strafe One-Taps` / `Valorant Peek Practice`（**你库里目前 0 轮，属于新增**）
- **B**：靶场 50 发单点，「完全静止后开火」的比例

**判定练成**：静止开火率 ≥95%，且不再出现「移动扫射」。

### 3.4 预瞄头线（ROI 第 4）

**两个免费方法**（这条特别实用）：

> 方法一：靶场走到机器人中间，「瞄准机器人头部转着圈打……**请指在水平方向移动，不要有垂直方向上的移动**，每天可以练习 **3 到 5 分钟**」
> 方法二：「无畏契约的设计师早就在地图的很多位置给了我们很多参照……**一些箱子的高度以及一些墙上的装饰，其实都是爆头线所在的位置**……最简单的还是将准星对准队友的头部」——`BV1irySBCEMP` [00:19]–[01:06]

**准星放置的距离怎么定？** Kiddo 给的原则可以直接公式化：

> 「优秀的准星放置，不仅需要做到**对自己反应能力的理性判断**，也需要学会换位思考」——`BV1Pe411k7Vi` [04:11]–[04:16]

翻译成可算的：**架枪预留角 = 你的反应时 × 目标横移角速度**。反应 250ms、敌人横移 200°/s → 需要预留 50°；如果你只有 200ms，预留 40° 就够。**架太宽 = 白送，架太窄 = 打不到**。这也是为什么「学主播的架点」经常无效——你们反应时不一样。

**量化口径**

- **A**：HS%（**只看步枪局**，手枪局会污染）
- **B**：把「箱子高度 / 墙上装饰 / 队友头部」当标尺，回放中数「准星低于头线」的次数
- 参考：职业头线预瞄保持率 89%，业余 31%（Aalto 2024）

### 3.5 结果层读数：DD 德尔塔 / KAST / FK-FD

**DD 德尔塔 = 每回合造成伤害 − 受到伤害**（`BV1C6421G7pP` [00:15]–[00:30]）：

> 「这个数据是比爆头率更能证明你的枪法水平的，因为有一些玩家他爆头率高，不是因为他枪法好，而是**不爆头就杀不了人**」——[00:37]–[00:45]

作者段位超凡二，自报 **DD = +31**，感受是「对枪经常能赢，压力不算特别大」；负数说明「很难做到稳定的一换一」[00:54]–[01:05]。国服需小黑盒查，国际服可 tracker.gg 绑定。

**读数纪律（原 v1 的 5 步法保留）**

1. 只在 session 结束后看，不在两局之间看
2. 每周只挑**一个**施工点
3. 只跟自己 30 天趋势比
4. 按地图/角色拆
5. 知道什么时候停

### 3.6 道具覆盖率

**单人跑图怎么开**（这是最实用的一条操作）：主菜单 → 对战 → **自定对战** → 勾选「**允许秘籍**」→ 进图后按 C 打开秘籍菜单 → 全开（无限技能 / 无限弹药）→ 用幽灵模式看落点 → 「提早结束」拉光幕进入正常阶段练习 `BV1js4y1Y7so` [00:23]–[01:21]。

点位查表：`BV1Mcgp6MEfH`（自制 700 点位网站，评论 1478 条）。

**量化口径（B 级）**：自定义房同一点位投 10 次，**≥9 次到位**记为「掌握」；覆盖率 = 掌握数 ÷ 需要数。每图每英雄先记 2 个（一攻一防）。

### 3.7 Peek 与身法

**核心可数指标藏在「暴露帧」里**：

> 「相当于将自己的每一段 peek 地速从零拉高、归为零的一个全过程**都暴露在了掩体外**」——`BV1x3JCzYELk` [00:46]–[00:50]

也就是说，正常走路应该「为下一段 peek **保留加速空间**」[01:12]–[01:18]；每段从静止重新加速，就是白白多给对手 0.2–0.3 秒。

**量化口径（B 级）**

- 每段 peek 的**暴露帧数**（录屏数帧；60fps 下 12 帧 = 200ms）
- 「同一角度连续 peek 两次」次数（每周目标 0）
- jiggle 被击中率 <20%

---

### 3.8 意识：拆成三段就能数

白羊给的框架非常适合量化——**意识 = 拿信息 → 做决策 → 执行**：

> 「意识本质上是一个**实时运转的信息处理系统**……更是在比谁能在**信息不对称中创造出 timing 优势**」——`BV1W4HTzeELF` [01:55]–[02:05]
> 「侦查阶段拿信息，然后策划阶段做决策……我称之为意识」——[04:47]–[04:53]

**所以按三段分别计数**：

| 段 | 计数项 | 单位 |
|---|---|---|
| 拿信息 | 开局 20 秒内主动获取的信息条数（语音/技能/小地图/听声） | 条/回合 |
| 做决策 | 决策前是否说出了「依据」（自己出声或心里默念） | 是/否 |
| 执行 | 决策到落位的时间 | 秒 |

**这比「意识好不好」这种主观评价靠谱得多**，而且回放时能逐回合打。

---

### 3.9 眼动模式（有条件才是 A 级）

如果没有眼动仪，就用录屏抽样近似：**暂停在交火前 1 秒，看准星离敌人头部多远**（这就是「注视点偏离准星」的可视化替代）。职业 3.2°、业余 11.4° 的差距，在录屏里表现为「准星是不是已经在头线上等着」。

---

### 3.10 心理与状态：用「闸门」而不是打分

时雨给了一个可直接用的协议：

> 「我都会打十几分钟的 aim 训练，**观察自己的分数是否起伏波动**，看看自己是否能做到专注于对枪」——`BV1WE421K7PY` [06:04]–[06:09]

再加「60 分定律」[01:57] 和 Kiddo 的「降低开游戏的心理预期和心理成本」`BV1km421M7av` [04:40]、[05:28]。

**落地**：开排位前打 10 分钟固定场景，**分数低于自己 30 天中位数 90% 就不排位，改练枪**。这就是把「状态」变成了 0/1 的闸门，不用自评。

## 四、量化的三个陷阱（v2 新增，必读）

### 陷阱 1：练习分数会通胀，而且通胀方式是「改动作」

> 「你为了追求高分……他需要换特殊的握法，用特殊的灵敏度，而且通常是高灵敏度，那跟你实战有什么关系呢？**一点关系都没有**」——`BV1rN4y1Q7X3` [00:44]–[00:58]

他还给了正解：练枪时必须把「**回中**」（把鼠标抬回舒服位置）带进去，因为「实战中一定会需要多次用到」[01:43]–[02:06]。**刷分时不会做回中，因为回中浪费时间。**

### 陷阱 2：远迁移 ≈ 0

前面已给证据（2024 综述 + 《A Search for a Phenomenon》）。**含义**：训练分数涨了别急着高兴，要问「这个动作在实战里出现过吗」。

### 陷阱 3：指标污染

| 指标 | 污染源 | 处理 |
|---|---|---|
| HS% | 手枪局、喷子/机枪局 | 只看步枪局 |
| KAST | 队友不 trade 会拉低 | 单排只看趋势不看绝对值 |
| ACS | 刷伤害、残局捡人头 | 只作参考 |
| 靶场困难分 | 甩枪式打法能刷高 | **不作能力评价，只作热身** |

**一句话**：**测动作，测结果，不测练习分数。**

### 5.2 建议的落库方式（不新建 measurement，只加 tag）

现有 `kovaak_score` 已经能承载，**加一个 `skill` tag** 即可，避免 v1 提议的「新建子类」污染统计口径：

```
kovaak_score,scenario=...,list=...,skill=aim|movement|switch|air|discipline score=...
```

- `skill=discipline` 只给 Peek/Counter-Strafe 场景用
- VDIM 主分计算时 `filter(fn: (r) => r.skill != "discipline")`
- 好处：不改表结构、不双写、现有 1371 轮默认 `skill` 可回填推断

## 八、反面意见（7 条，全部来自这轮抓取）

1. **靶场困难模式不是训练手段**：国服第一挑战 20 个就说「练这个没用」`BV1qxtSzdEHX` [00:31]–[01:22]；967 赞评论「我平均 17，最好 22，打到神话二都够了」；729 赞「不符合精确瞄准准则，全凭感觉甩枪，最后连停稳开枪都丢失了」；429 赞「也就热身还行」。
2. **AIMLAB 十万分可以零迁移**：`BV1rN4y1Q7X3` 全程在讲这件事。
3. **爆头率是结果不是原因**：65 赞评论「你应该是做好了预瞄、架好头线……得到了高爆头这个**结果**，而不是为了追求高爆头率放弃击杀效率」。
4. **远迁移证据为零**：见第一节第 2 条。
5. **量化会反噬**：Kiddo 建议「降低预期、降低开游戏的心理成本」`BV1km421M7av` [04:40]/[05:28]。
6. **别同时修 5 项**：一周只设一个施工点（原有结论，本轮无反驳）。
7. **「意识」这个词本身有毒**：它把三件可数的东西（拿信息/决策/执行）打包成一个玄学词，`BV1W4HTzeELF` [01:52]–[01:55] 自己也说「意识是一种感觉」。拆开就可用，不拆就只能感慨。
