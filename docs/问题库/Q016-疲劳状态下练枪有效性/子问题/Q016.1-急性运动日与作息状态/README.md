## 核心结论速览

- 高强度运动（1000 米 ≈ 85%+ HRmax）注入三种瞄准噪声：过量儿茶酚胺（信噪比破坏）、增强性生理震颤（手抖 2-5 倍放大）、注意资源枯竭（难捕捉变向）
- 运动是倒 U：中等强度（46-63% VO2max）20-30 分钟 = 最佳开状态工具；高强度后 2-4h 避开精度敏感内容
- Walker 2002（Neuron）：技能收益的落盘发生在睡眠（+20% 速度/+30-50% 准确率），清醒同样时间零收益
- 午睡 20-30 分钟 = 合法的状态重置（腺苷清除），超 30 分钟反效果
- 自动化是抗疲劳护甲（击剑研究：高水平组血乳酸下精度不降）
- 手抖处理顺序：查睡眠/咖啡因/进食 → 查控鼠发力 → 才是加练
