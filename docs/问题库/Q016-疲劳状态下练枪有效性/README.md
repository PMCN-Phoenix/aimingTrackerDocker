# Q016 疲劳状态下练枪有效性

## 问题概述

**"很累的情况下练枪有用吗，那种因为其他事务造成的累"**——即非练枪本身引起的、由工作/杂事/情绪消耗造成的疲劳，此时练枪是否还有训练价值。用户视角：VALORANT + VDIM 6 天计划执行者，日常有工作事务消耗。

**核心结论**：不是"有用/没用"的二元问题，**取决于"哪种累"**——
- **认知/心理疲劳**（开会、写方案、处理杂事）：当天表现↓，但**学习不受影响**（Godoi Filho 2026，n=92）→ 能练，但要换内容、减时长
- **局部神经肌肉疲劳**（久坐颈肩僵、手腕酸）：**最可能破坏学习**（Hassar 2026 系统综述）→ 停该部位
- **睡眠债**（熬夜/长期 <7h）：**破坏离线巩固**（Fischer 2005）→ 先睡，练了存不住

配套三条反直觉结论：① 你察觉不到自己变差（Smith 2019 NASA-TLX）；② 疲劳下练习**不产生**抗疲劳能力（Godoi Filho 2026 专门否定了这条）；③ "累的时候练会巩固错误动作"只在肌肉疲劳支成立，认知疲劳支无直接证据。
