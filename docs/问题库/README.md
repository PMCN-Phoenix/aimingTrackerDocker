## 编号规则

- **一级问题**：`Q001`、`Q002`、`Q003`……
- **子问题**：`Q001.1`、`Q001.2`……放在父问题的 `子问题/` 目录下
- **子子问题**：`Q001.1.1`……以此类推

## 每个问题文件夹必须包含

- `README.md`：问题概述、当前状态、产物索引、子问题列表

## 新增问题流程

1. 确定问题层级（一级问题还是某问题的子问题）
2. 创建文件夹：`QXXX-简短描述/`
3. 写 `README.md`（问题概述、当前状态、产物索引）
4. 把相关产物放进文件夹
5. 更新本 README 的问题列表
6. 如果是场景技术问题，同时更新 `Q004/索引表.csv`
