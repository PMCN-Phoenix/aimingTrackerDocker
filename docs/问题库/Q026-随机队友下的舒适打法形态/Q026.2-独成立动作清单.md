# Q026.2 独成立动作清单（按回合阶段，尽量全）

> 配套 [Q025.2 三项验收指标](../Q025-枪法之外可量化能力/Q025.2-三项验收指标怎么算与怎么做.md) 第三节。
> 用途：`形态纯度 = 独成立 ÷ (独成立 + 摩擦)` 的**分子素材库**。Q025.2 要求「每局至少 2 件独成立」，这份清单就是你可以挑的那池子。

---

## 〇、判定标准（先背这一条）

> **这个动作的成立，是否需要某个队友做了「我请求的事」？**
> 不需要 → 独成立。需要 → 摩擦。

两个容易误判的边界：

- **队友的行为可以是触发信号，但不能是执行前提。** trade 算独成立：队友先接触是环境信号，我补第二枪不依赖任何人听我指挥。反过来「叫队友等我一起进」是摩擦。
- **广播算，请求不算。** ping 和 L1 三条事实（我在看哪/我看到谁/我什么时候动）不要求回应，发出即完成，有人听是 bonus（Q026 §8：广播 ≠ 请求）。

## 九、灰名单：独成立，但对你是**减分**项

**独成立 ≠ 好动作。** 纯度只测「不依赖队友」，不测价值。这几件虽然算独成立，但对你的形态是负资产，做多了纯度虚高、实际变差：

| 动作 | 为什么减分 |
| --- | --- |
| **主动补位**（哪里缺去哪里） | Q026 §2.1：补位收益的前提「队友会配合」在路人局不成立；你付出熟练度损失换不到回报 |
| **过度保枪**（每局都保） | 存活率上去了，KAST 的 K/A/T 全没；这是 Q025.2 第三节「少做事刷纯度」的实战版 |
| **全程 off-angle 不给任何主动信息** | 被动退化成发呆；配合 #36「每 3 回合主动一次」才平衡 |
| **抢默认位挂机等 40 秒** | 同上，等待要有信息目标（#6/#7/#8） |

```
每局开始：从这 37 条里挑 2 件写进备忘录（例：#14 trade + #21 不无信息接敌）
每局结束：60 秒内数 独成立✕几 摩擦✕几（口径见 Q025.2 §3.1）
```

## 十一、#21「不无信息接敌」具体执行程序

> 四类信息判定（Q025.2 §2.1）在实战里没时间理性列清单，必须压缩成一个动作。

### 11.1 压缩成一个动作：停半秒，扫小地图，听

| 四类信息（判定口径） | 实际检查动作 |
| --- | --- |
| ① 脚步 / 枪声 / 技能音 | **听**（停下来的半秒里耳朵自然覆盖） |
| ② 身影 / 弹道 | 不用找——看见了就是看见了 |
| ③ 队友报点 / ping | **听 + 小地图**（ping 直接显示） |
| ④ 小地图 30 秒内红点 | **扫小地图**（半秒够） |

执行动作 = **停 0.5 秒 → 扫一眼小地图 → 听**。答得上「地图上有什么、耳朵里有什么」就有信息；两样都空 = 无信息，不动。

### 11.2 只记三个触发时点（不用每秒自检）

1. **进攻过角前**——最高频发生地，先只练这个
2. **交火后的 re-peek 前**（刚打完想追枪的瞬间最危险）
3. **跑图转场时**（回防/转点路上被截，是防守方无信息接敌的主产地）

回合中其他时间不用想这条规则——想多了会僵。

### 11.3 检查完的分支（关键：没信息 ≠ 发呆）

```
有信息 → 正常打（此时是有信息接敌，该打就打）
没信息 → 三个合法选项，选一个：
   A. 架一个「敌人可能出现、我却不暴露」的角 → 等信息上门（这就是 #5）
   B. 用侦察技能换信息（角色有的话）
   C. 走「能随时退」的路线继续推进 → 带退路的推进不是接敌
```

**#21 不是「不动」，是「不动到没有信息的地方」。** 停在原地什么都不做 = 第九节灰名单。

### 11.4 四个高危场景对照

| 场景 | 错误做法 | 正确做法 |
| --- | --- | --- |
| 进攻过角 | 凭「感觉他不在」直接过 | 停半秒 → 空 → 选 A：先架这条角，等 2 秒 |
| re-peek 追枪 | 「他残血了我去收」→ 无信息复读 | 换角度（#23），从新的角重新走 11.1 |
| 回防路上 | 直线跑过开阔地 | 贴掩体走，每个掩体后做一次 11.1 |
| 残局 1vX | 「必须做点什么」上头开枪 | 耐心本身就是动作（#29）：让对方先制造声音 |

### 11.5 怎么练（一次只改一个场景）

- **W1**：只在「进攻过角」这一个场景执行 11.1（频率最高、最容易觉察）
- **W2**：加上 re-peek
- **W3**：加上跑图转场
- 四个场景同时改必然崩——旧习惯会在压力下全部回来

### 11.6 验收挂钩

回放只看「首次交火」和「死亡」两个瞬间倒推 3 秒，记**每局次数**（Q025.2 §2.2）。目标：相对首周 **×0.7**。

自查线索：无信息接敌次数高，几乎总是对应「买枪阶段没做 #1（定死架位）」——回合前没想清楚，回合中就会用枪法赌信息。
