### 三个自定义列的定义（不要改口径）

| 列 | 定义 | 记什么 |
|---|---|---|
| **摩擦↓** | 我**想做但没做**的动作，原因是"需要队友配合" | 计数。这是"接口数量"的直接测量 |
| **独成立↑** | 我做的、**不需要任何回应**就有效的动作（架点拿到信息 / trade 成功 / 残局接住 / 单点守住） | 计数。这是你形态的产能 |
| **一句话体感** | 只写身体和节奏，不写评价 | ✅"第 6 回合开始手腕发紧" ❌"队友太菜" |

**关键比率**：`独成立 ÷ (独成立 + 摩擦)` = **形态纯度**。

- ≥ 80% → 你的形态成立，随机性伤不到你
- 50–80% → 形态在形成，还有一半动作挂在别人身上
- < 50% → 你其实在打"5 人队"，只是没有 5 人队的配合

## 四、W4 三问判定

| 问 | 你的答案 | 通过标准 |
|---|---|---|
| ① 队友全崩，这套还能不能执行？ | | 能，且**不需要改动作** |
| ② 连打 5 把，我是更稳还是更燥？ | | 更稳或持平 |
| ③ 有没有一个数字在动？ | | 30 天里至少一个指标显著变化 |

### 结论

- [ ] **三问全过** → 形态确认。把它写死成默认动作（见主报告 5.3），以后不再讨论。
- [ ] **①②过、③不过** → 这是**舒适区**，不是形态。要么加一个可量化目标，要么承认自己就是在娱乐。
- [ ] **①不过** → 你的形态偷偷依赖了别人。回 W3，把动作再降一级接口。
- [ ] **②不过** → 张力预算在透支（Q024）。先修排位时长和进入程序（主报告第八节），别修打法。

## 五、W3 用：把你的打法写成三条"不需要队友"的动作

填空，写完就是你的最小动作单元。每条必须满足：**主语是"我"、不包含"等队友"、失败时能自己复盘。**

1. 进攻时，我 ____________________________________（例：只走第二身位，站队友进去后 1 秒内我会看到的那只角）
2. 防守时，我 ____________________________________（例：只站非默认位，等对方先探；不主动拉）
3. 残局时，我 ____________________________________（例：只骗枪/拉扯，不拼第一枪）

**破局补丁**（短板补偿，每 3 回合一次）：第 ______ 回合我主动开一次，允许打得难看。
