## 一、一句话结论

**不要去调队友，也不要去找一个"理想打法"，而是先定你自己的三个变量：接口数量、触发方式、负荷长度。**

这三个变量决定了一局里你被随机性伤到几次。你的三个变量，本地数据已经给出答案：

> **0 接口 × 被动触发 × 短爆发 = 接应 / 二突型**

而 B站 这轮实证给出了一个比 v1 更准的说法：

> **形态不是"选"出来的，是"训练史"长出来的。**

你的 1371 轮全是单人瞄准训练，没有一轮带队友、没有一轮带决策约束——所以你天然长成"二突/接应"，不是因为你选了它，而是因为你只练过它的前半段。B站 高赞评论把这个道理说得更直白：*"大部分玩家就是适合玩二突的，大家平常练的基本都是练枪、练瞄准、练预瞄、练架枪，二突就需要这些……拿了二突对枪就是很舒服"*（`BV1RxMWzwEUA` 评论 544 赞）。

**为什么英文站会错**：它们假设"补位能换来队友配合"。但 B站 评论直接把这个假设打穿了——

### 2.2 🟡 但有三层限定，不能一刀切

**限定一：分段。** 两条"反补位"视频都明确限定在低中段——`BV19wqNYqEDk` [02:06] 原话是"**在神话以下就专注于一个英雄就好了**"。高段位才需要多位置理解。

**限定二：位置。** 评论给出结构性理由（`BV1wB2eBEE6w` 26 赞）：

> *"这个游戏的角色定位从设计上就有大问题：先锋又要记点位，又要捏道具，Rank 单排你又要开麦沟通打道具，学习成本高的同时**开火权又低**，ACS 里人头权重又高，然后 ACS 又和每局加的分挂钩——这个设计天然地对先锋玩家不友好。"*

**先锋位是单排的最差投资**：学习成本最高、依赖沟通最多、加分权重最低。这解释了为什么"补位"通常等于"补先锋"等于"白给"。

**限定三：存在一个例外角色。** `BV1xf1oYfEYK`（标题就叫"为什么 Clove 是最舒适的单排冲分选手"）最高赞评论（**537 赞**）指出：

> *"慕蝶（Clove）技能简单、封烟快、在烟位里不容易漏 timing，主要是**补位的人补到烟位也很好上手**，不像 omen 和 viper 以及亚星卓太吃熟练度，不玩几百盘很容易失误。"*

**裁决**：不是"永远不补位"，而是——

| 情况 | 该怎么做 |
|---|---|
| 低中段（下三～神话以下）+ 你不熟练那个位置 | **不补**。熟练度损失 > 阵容收益，且路人不会兑现配合 |
| 补的是低门槛角色（Clove 这类自带独立功能、几百盘就能稳的） | **可以补**。这是唯一"补位收益为正"的区间 |
| 神话+ | 需要多位置理解，补位开始变成正期望 |

## 三、"舒服"拆成三件事

| 你以为的舒服 | 真实机制 | 判定指标 |
|---|---|---|
| 打起来顺 | **低摩擦**：动作不需要说服别人就能执行 | 一局里"想做但做不了"的次数 |
| 打得不累 | **可持续**：不预支张力预算（Q024 三账户） | 连打 5 把后是更稳还是更燥 |
| 打完不空 | **可累积**：每次都在练同一个可量化的东西（Q025） | 有没有一个数字在动 |

缺一个的后果：只有低摩擦 → **舒适区**；只有可持续 → **温水**；只有可累积 → **苦练**。

目标函数不是 `max(舒服)`，而是 `max(舒服 ∩ 被奖励)`（第七节）。

## 四、随机队友的真实约束：不是"水平差"，是"协作成本"

三条外部证据 + 一条 B站 实证：

1. **陌生人团队的协调靠"共享任务抽象"，不靠详细沟通**。ad hoc teaming 研究：分层策略（高层子目标 + 低层执行）在与**未见过的队友**配合时比黑箱策略高 **47.9%**（对 BCP）/ **18.0%**（对 FCP）；实时信号的价值恰恰是**补偿"缺失的共享预期"**。
2. **隐式协调比显式省时，但前提是 shared mental model 一致**（医疗急救团队研究）。你和随机队友必然不一致 → 只能降级成"单向广播"。
3. **单排最有效的战术形态是 default 不是 exec**：原因不是 default 更强，而是它的**接口数是 0~1**。
4. **B站 实证**：*"你和你萍水相逢的队友，成功复刻那些精妙战术的可能性无限接近于零"*（`BV1PF9bBsEXY` [01:51]–[01:56]）。

> 单排不是"5 人队的弱化版"，是**另一种游戏**。它的赢法单位不是"回合战术"，是"个人行动单元"。

## 五、三圈模型：把注意力放对地方

```
┌─ 不可控圈（投入 0%，只做识别）──────────────┐
│ 队友水平 / 配合意愿 / 心态 / 语言 / 阵容      │
│ 对面是否炸鱼 / 匹配时段 / 网络                │
└──────────────────────────────────────────┘
        ↓ 只观察，不评价
┌─ 可控圈（投入 90%）────────────────────────┐
│ 选什么角色 / 站哪个位 / 打什么节奏            │
│ 开麦等级 / 每回合第一个动作 / 什么时候停      │
└──────────────────────────────────────────┘
        ↓ 用示范而非指挥
┌─ 可影响圈（投入 10%）──────────────────────┐
│ 队友的第一步（跟着你走，还是各走各的）        │
│ 信息广播（ping / 三条事实）                   │
└──────────────────────────────────────────┘
```

判断自己有没有错配，有个很硬的信号：**一局结束后，你能不能说清自己三个具体失误？** 说不清，说明注意力整局都在别人身上。

B站 侧证：*"低分段队友之间的协同是非常差的……要更专注于自我的提升"*（`BV1WE421K7PY` [07:07]–[07:34]）。

### 6.2 为什么是"二突/接应"——训练史的映射

B站 评论 544 赞那条是这轮最重要的外部佐证：

> *"大部分玩家就是适合玩二突的，大家平常练的基本都是练枪、练瞄准、练预瞄、练架枪，二突就需要这些。我看好多人都觉得自己枪软不敢拿二突，其实**拿了二突对枪就是很舒服**。"*（`BV1RxMWzwEUA`）

把这条和你自己的训练史叠起来看：

| 你练过什么（1371 轮） | 长出了什么 | 对应什么位置 |
|---|---|---|
| 单人瞄准、预瞄、架点、甩枪 | 重捕获、短爆发、0 接口 | **二突 / 接应 / 自由人** |
| **没练过**：道具时机、多目标协同、带人节奏 | 决策 + 约束（Q024 说练枪不共享这两项） | 指挥 / 先锋 / 主烟都不该是第一选择 |

**这就是"形态"的真正来源**：不是性格测试，不是"你适合玩什么"的自我感觉，而是**你已经在练的东西决定你已经在行的东西**。想换形态，代价是先换训练内容，而不是先换英雄。

### 6.3 三个变量定形

| 变量 | 取值 | 依据 |
|---|---|---|
| **接口数量** | **0~1 人** | 强项全部来自单场景；B站 侧证："一人成军"是判定标准（`BV1PF9bBsEXY` 评论 253 赞） |
| **触发方式** | **被动触发** | 折返类大幅进步 / 持续贴合退步 → 你对"目标先动"的响应远好于"自己主动维持" |
| **负荷长度** | **短爆发** | 局内 60 秒零衰减，但**跨轮会掉**：第 3 轮 94.4% → 第 6 轮 87.2% |

> **0 接口 × 被动触发 × 短爆发 = 接应 / 二突型**

### 6.4 翻译成一天的具体动作

| 场景 | 默认动作 | 为什么适合你 |
|---|---|---|
| **进攻** | 不第一个进点。走第二身位，站"队友进去后 1 秒内你会看到的那只角"，做 trade | 第一枪需要静精度（你的弱项），第二枪需要重捕获（你的强项） |
| **防守** | 站 off-angle（非默认位），等对方先探 | 被动触发 + 短爆发；**不需要任何队友报点**就能成立 |
| **残局** | 接，不强开。用"骗枪/拉扯/制造多打少"而不是"拼一枪" | PSGS 1 Shot **−9.7%** → 一枪定生死是弱项 |
| **选角** | **专精 1 个角色**（自带独立功能、低配合依赖），不主动补先锋 | 2.1–2.2 的裁决；`BV19wqNYqEDk` [02:06] |
| **开枪方式** | 上半身稳定击杀 + 小连发附带爆头，不强求一枪头 | `BV1v1Gw6YE8J` [00:30]–[01:28]；状态差也能有正常发挥 |
| **经济** | 能起就起满，不做团队经济协调 | 0 接口 |
| **回防 / 转点** | 只跟"已经打起来的那一侧" | 有声音/击杀提示 = 有触发信号；没信号就不动 |

**关键补充（B站 唯一的"入门级"诊断）**：`BV1sht262EfJ` [01:07] 指出低段位单排的**首要问题**是——*"不知道自己该架哪里"*。你的形态要落地，第一步不是"等对方先探"，而是**在回合开始前就把"这回合我架哪"定死**。这一步没做，被动就变成了发呆。

### 6.5 这个形态的短板（必须诚实）

1. **打不开局面**。没人先动时你没有创造机会的工具。队友全是被动型，这局就僵死。
   **补丁**：每 3 回合强制主动一次。当"练短板"，不当"赢法"——主动那回合允许打得难看。
2. **容易"数据好看但不赢"**。低死亡率 + 高 KAST，但影响小。
   **补丁**：验收用 **KAST / ADR / trade kill**，不用 K/D。
3. **队友全崩时你救不了**。这是形态的代价，不是失败。
4. **专精的风险**：`BV1iajVzdE1n` 标题就是"看完直接抛弃你辛苦练的本命英雄"，说明"专精"也有失效边界（版本削弱/被针对）。B站 评论给了现实版：*"没办法啊，玩保安削保安，玩夜露削夜露，玩慕蝶削慕蝶，迷茫的一笔"*（`BV1wB2eBEE6w` 436 赞）。

## 七、最尖锐的张力：「最舒服」≠「被奖励」

**证据一（学术）**：一项对 **292 名各区前 50 名 VALORANT 玩家**的分析（KMeans + PCA），得到三种原型 **All Aim No Brain / Support / Balanced**，结论是：**支持型打法对团队有价值，但在排位里上分效率偏低**——因为排位奖励的是**可测量的个人影响**。同一分析里，**KAST 是胜率最强的预测因子之一**，而 ACS、爆头率、平均伤害反而不是最好的预测变量。

**证据二（B站，玩家自己算出来了）**：`BV1wB2eBEE6w` 26 赞评论把这件事讲成了结构问题——

> *"先锋又要记点位，又要捏道具，Rank 单排你又要开麦沟通打道具，学习成本高的同时**开火权又低**，ACS 里人头权重又高，然后 ACS 又和每局加的分挂钩——这个设计天然地对先锋玩家不友好。"*

**证据三（学术）**：CS2 研究（1052 名选手 / 222 支队伍）表明**单一综合评分不能跨角色比较**——角色差异主要集中在 **opening block**（entry 开局击杀 +0.92 SD、开局死亡 +1.00 SD）。

| 如果你的"舒服"是… | 你会经历 | 真相 |
|---|---|---|
| 辅助 / 兜底 / 给队友做球 | "我打得不错但就是不上分" | 不是错觉，是奖励结构不匹配 |
| 追求 ACS / 爆头率 | "数据很好看，段位不动" | 你优化了一个弱预测变量 |
| 追 KAST / 存活 / 交易 | "赢得莫名其妙，输得明白" | 你在优化真正被奖励的东西 |

**出路**：不是放弃舒服去当突破手，而是**把你已经在做的事，换成能出数的指标**。你的反打型恰好落在交集里：0 接口（舒服）+ trade/KAST/clutch（被奖励）。

而它**不需要**你去优化：爆头率（预瞄指标）、ACS（弱预测变量）、小目标静精度（投入产出比最低的短板）。

## 八、接口设计：最小可行协议

沟通不是"多说话"，是**选一个你能连打 5 把维持的等级**。

| 等级 | 内容 | 张力成本 | 适用 |
|---|---|---|---|
| **L0** | 全静音 + ping | 最低 | 状态差 / 队伍有毒 / 只想稳一把 |
| **L1** ✅ | 三条事实广播：①我在看哪 ②我看到谁 ③我什么时候动 | 极低 | **推荐默认** |
| **L2** | L1 + 时机（"3 秒后我进"） | 中 | 队友有回应、气氛正常时 |
| **L3** | 指挥 / 分配 | 高 | 只在队友明显愿意听时（响应率低，别硬撑） |

**关键区别：广播 ≠ 请求。** L1 的三条全部以"我"开头，不要求任何人回应——这就是隐式协调的接口：**只同步状态，不同步计划**。它不会因为没人理你而失效，这是它比"指挥"更可靠的原因。

B站 侧证：指挥者的自述原话就是*"我并不能指挥你，我只能在游戏里指挥你"*（`BV1w642137tw` [06:27]–[06:30]）。

**把队友当信息源，不是当执行器**：队友无沟通地冲进去死了——他死的位置 = 对面有人；死的方向 = 对面架点方向；枪声数量 = 对面人数；活了多久 = 对面火力强度。这不是坑队友，是**把随机性转成数据**。社区原话更狠：*"把所有队友当信息位补枪"*（`BV1UtFke9ETL` 113 赞）。

## 九、什么时候排位：用你自己的曲线排

| 本地事实 | 数字 |
|---|---|
| 每天第一轮比后面低一整个标准差 | d 中位 **−1.05**，20 个场景里 **17 个**成立，与场景方差无关（r=+0.13） |
| 一轮之内完全不衰减 | 命中率后半−前半 中位 **+0.00**，TTK **+0.000**（839 轮） |
| 一天呈倒 U | 第 3 轮 = 当天最好成绩的 **94.4%**；第 6 轮掉到 **87.2%** |

| 时间点 | 你的状态 | 该做什么 |
|---|---|---|
| 第 1 轮 | **低位（废轮）** | 只当进入程序，**不评估自己** |
| 第 2–3 轮 | 上升 → **峰值** | **排位进入窗口**（开练后约 20–25 分钟） |

**为什么这对"舒服"重要**：固定进入程序本身就是舒适感的最大来源——因为它把"今天我状态好不好"这个不可控变量，换成了"我按流程走了"这个可控变量。

| 周 | 主题 | 做什么 | 产出 |

| **W1** | 只记录，不改 | 每局后 5 个数字 + 1 句体感（用 `Q026.1-形态定位记录表.md`） | 20 局基线 |
| **W2** | 固定角色/位置 | 只改角色，不改节奏。看"接口数量"对体感的影响 | 哪个角色让你最少需要队友 |

| **W4** | 验收 | 三问判定 + 数据对比 W1 | 形态确认 or 修正 |

### 三问判定：是"舒适形态"还是"舒适区"

| 问 | 通过标准 | 不通过意味着 |
|---|---|---|
| ① 队友全崩，这套还能不能执行？ | 能，且**不需要改动作** | 你的形态偷偷依赖了别人的配合 |
| ② 连打 5 把，我是更稳还是更燥？ | 更稳或持平 | 你在用意志力硬撑（Q024 张力预算透支） |
| ③ 有没有一个数字在动？ | 30 天里至少一个指标显著变化 | **这是舒适区，不是形态** |

第三问是分水岭。中文攻略反复点名单排的四种固化——**英雄池变浅、以自我为中心、习惯自己节奏、不听信息**——它们和"舒适形态"长得一模一样，区别只在第三问。

**一个 B站 给的具体判定标准**（`BV1PF9bBsEXY` 评论 253 赞）：

> *"如果你觉得自己不属于这个段位，那就考虑玩一玩幽影、亚星卓、瑞纳、火男这种**一个人就可以完善功能**的角色，**一人成军**打穿对面。如果做不到，那说明你就是这个段位的。"*

这条可以直接当 W4 的验收题：**用你专精的那个角色，能不能在不指望队友的情况下把这一局的功能补齐？**

## 十一、反面意见（7 条）

1. **"找固定队才是真解"**。有站点称双排胜率高出 32%（来源是双排匹配平台，利益相关，需打折）。B站 侧证只是"体感"：*"带了一个钻石二……一路升到神话二一局没输，现在我和他是固排了"*（`BV1KBAaztEQQ` 6 赞）。**它不解决你的问题**——你问的是"随机队友时怎么舒服"，不是"怎么不打随机队友"。
2. **高分段单排本身就难稳定**。中文攻略明确：超凡/神话以上配合拉满，单排冲高分难度极高。→ 目标高段位时，形态之外还需要"队友池"这条腿。
3. **"舒适形态"极易变成固化借口**。对抗方式只有一个：第三问的数据。
4. **如果所有人都反打，就没人开局**。补丁（每 3 回合主动一次）不是可选项。
5. **⚠️ 社区存在大量"甩锅合理化学"**。`BV1hqZxBKEV3` 的机制说法（"系统故意给你坑队友""挂常用英雄会被平衡"）**没有任何官方依据**，其 80 赞评论"输了就是队友不行"更是典型错误归因。我采信它只有一条：**连输两局就停**——这条与主流一致。
6. **心态建议容易鸡汤化**。"别生气""放平心态"没有可执行性。本报告每层都落到数字（局数/轮次/KAST/三问）。
7. **"专精"也有失效边界**。版本削弱、被针对、队友先锁——`BV1iajVzdE1n` 整期视频就在讲这个。所以"专精"要配一个 B 计划角色，而不是只留一个。
