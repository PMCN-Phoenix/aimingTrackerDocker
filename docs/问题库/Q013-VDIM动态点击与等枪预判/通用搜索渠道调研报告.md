## 核心发现

### 1. VDIM Dynamic Clicking 的官方定义
- 目的：练阅读技能、速度、精度、命中确认、平滑进入、外围视觉
- 操作：短暂阅读目标 → 确认能命中 → 快速进入 → 确认后点击
- 分类：可预测运动（练阅读判断）vs 不可预测运动（练快速射击+微调补枪）

### 2. 跟枪的两大分类
- **Precise Tracking**（平滑跟枪）：变向少、可预测 → 专注平滑度，匹配目标速度
- **Reactive Tracking**（反应跟枪）：变向多、不可预测 → 不要预判，假设目标不变向，变了再反应

### 3. 认知科学：人对加速度不敏感
- 眼睛能跟上加速/减速目标的速度曲线（平滑追踪系统会持续调整）
- 但手的拦截时机 = 用遮挡前最后一刻的速度外推（一阶运动模型）
- 系统性误差：加速目标拦截晚了，减速目标拦截早了
- 经过 8-12 次重复同一加速度可以部分补偿

### 4. "预判 vs 反应"的表面冲突与调和
- Voltaic 官方："Be reactive, not predictive" → 说的是**有意识的预判**不要做
- aimbetween.games："Tracking IS prediction" → 说的是**自动的视觉追踪预测**是跟枪的生理基础
- 不矛盾：有意识的预判会被 juke；自动的速度模型是跟枪能成立的前提

### 5. 微定位/垂直抖动（追加主题）
- 微调整 = 手腕/手指发力，前臂固定，小肌肉群更精细
- Claw Grip 的优势：大动作用手腕，微调整用手指
- 常见错误：无名指和小指过度紧张 → 摩擦 → 微调整不流畅
- 垂直方向力度不对称：向下拉（向掌心）天然比向上推（向外）更有力 → 容易过冲
- 复合运动目标策略：水平方向精确追踪，垂直方向（随机抖动）留宽容窗口，不要追每一次抖动

## 反面意见

1. **VDIM 集中练习法的批评**：缺乏日常多样性可能导致 RSI，非专注类别会暂时生锈（Shapes.inc）
2. **Season 5 基准过度重视反应性**：牺牲了实战中的战术定位能力（Shapes.inc）
3. **"不要预判"是错的**：纯反应永远追不上目标，跟枪本质就是预测（aimbetween.games）

## 对用户的关键启示

1. "匹配目标速度才点击"在 Dynamic Clicking 中正确，在 Tracking 中不适用
2. 跟枪慢 = 可能混淆了动态点击和跟枪的技术要求，或灵敏度/握持问题
3. 垂直抖动目标难受 = 认知负荷过载 + 垂直修正不对称 + 握太紧，不是手不行
4. 复合运动目标策略：水平精确跟，垂直不追噪声
