# Q013 VDIM 动态点击与等枪预判

## 问题概述

在练习 VDIM 动态点击（dynamic clicking）时，"等枪"（anticipation aiming / pre-aim）到底是什么——把准星移到目标下一刻出现的位置、等目标过来再点击，这是如何实现的？用户当前跟枪慢，习惯"匹配目标速度才点击"，这种方式是否合适？什么时候该跟、什么时候该等、什么时候该甩？

## 子问题

1. **等枪是什么**：anticipation aiming 的定义，与 tracking（跟枪）、flicking（甩枪）的本质区别
2. **等枪如何实现**：速度匹配/提前量/轨迹预测的认知-运动机制，操作细节（准星放哪、提前多少、何时点击）
3. **用户现状评估与改进**："匹配目标速度才点击"是否合适，跟枪慢的原因诊断，从跟枪到等枪的过渡训练
4. **【追加】小球平移+垂直不规律抖动的微定位**：小目标水平匀速+垂直随机抖动时，跟枪/等枪/甩枪如何混合使用？微定位为什么"难受"？Thin Gauntlet 等场景的训练方法（2026-10-14 用户追加）
5. **【追加2】Floating Heads Timing 400% 正确训练方法**：Kovaak's 具体场景的机制、正确技术（跟枪/等枪/甩枪）、400% 难度训练策略、常见错误、VDIM 定位、成绩基准、可执行训练步骤（2026-10-14 用户追加）

> **主报告结构**：技术原理（三技术对比）→ 具体场景应用（Floating Heads Timing + 小球抖动）→ 训练阶梯
