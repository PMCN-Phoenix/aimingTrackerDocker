# Q011 跑步速度-心率关系

> 核心问题：长时间跑（有氧持续跑）和短时间跑（间歇/冲刺）的速度与心率有什么对应关系？有没有通用的换算/比对方法？
> 调研日期：2026-10-14
> 关联：[Q001.2 BET脑耐力训练](../Q001-状态维持与注意力耐力/子问题/Q001.2-BET脑耐力训练实施方案/)（有氧强度控制）、[Q009.1 休息日恢复](../Q009-练枪与上分匹配安排/子问题/Q009.1-休息日精神状态恢复/)（有氧恢复强度选择）

---

## 一句话结论

**两者共享同一条速度-心率曲线但落在不同区段：长时间跑在亚极量稳态区（用心率控上限，因心率漂移配速会自然下降），短间歇在极量区（用配速/RPE控，因心率滞后15-60秒）。最通用的比对方法是组合范式：近期比赛成绩→VDOT反推E/M/T/I/R配速→Karvonen法算心率区间→RPE并行校验。220-年龄公式个体误差±22bpm，不能作为个体化处方依据。**
