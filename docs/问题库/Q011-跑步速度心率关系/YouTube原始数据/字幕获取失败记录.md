# 字幕获取失败记录

## 结论
**全部 12 个精选视频的字幕均未能获取。**

## 尝试过程
按 agent-hint 指示，依次尝试了以下方案，均被 YouTube 机器人墙拦截：

| 尝试 | 命令关键参数 | 结果 |
|---|---|---|
| 1. 默认 + 代理 + ejs:github | `--proxy http://127.0.0.1:7897 --remote-components ejs:github` | `Sign in to confirm you're not a bot` |
| 2. Chrome cookies | `--cookies-from-browser chrome` | `Failed to decrypt with DPAPI`（Chrome 运行中 + App-Bound Encryption） |
| 3. Edge cookies | `--cookies-from-browser edge` | `Could not copy Chrome cookie database`（Edge 运行中，数据库锁定） |
| 4. 等 90 秒后重试 | 默认参数 | 仍然 `Sign in to confirm you're not a bot` |
| 5. tv/web_safari client | `--extractor-args "youtube:player_client=tv,web_safari"` | 仍然机器人墙 |
| 6. ios client | `--extractor-args "youtube:player_client=ios"` | 仍然机器人墙 |
| 7. 直连（不走代理） | 去掉 `--proxy` | 请求挂起超时（本机网络必须走代理） |
| 8. 等 120 秒后重试 | 默认参数 | 仍然机器人墙 |
| 9. tv_embedded/web_creator/mediaconnect | `--extractor-args "youtube:player_client=..."` | web_creator 仍机器人墙；其余 client 不支持 |
| 10. 直接 timedtext API | `urllib` 直连 `api/timedtext?type=list&v=ID` | HTTP 200 但空 body（现代 YouTube 需签名 token） |
| 11. --impersonate chrome | `--impersonate chrome` | 仍然机器人墙 |
| 12. web.fetch 抓 watch 页 | `web.fetch https://youtube.com/watch?v=...` | link fetch error（web.fetch 无法访问 YouTube） |

## 根因
- 共享代理 IP（127.0.0.1:7897 出口）已被 YouTube 标记为数据中心/滥用 IP，watch 页与 player API 全部触发机器人验证
- **ytsearch 搜索 API 不受影响**（返回了完整的标题/频道/时长列表，已用于构建 `YouTube搜索结果-全部.md`）
- 浏览器 cookies 无法解密（Chrome/Edge 正在运行，DPAPI/App-Bound 加密 + 数据库锁定）

## 替代方案（按 agent-hint 第 5 条执行）
1. 用 ytsearch 已获得的视频标题/频道/时长作为"元数据"基础
2. 用 `general_search` 搜索每个视频的主题 + 频道名，找二手汇编（博客、训练指南、引述）
3. 调研发现文档中**所有条目均标注"元数据/二手汇编"**，不编造字幕原文与时间戳
4. 时间戳列统一标注"字幕未获取"

## 备注
- 若后续需要字幕原文，建议：关闭 Chrome/Edge 后再用 `--cookies-from-browser`，或导出 cookies.txt 文件后用 `--cookies cookies.txt`
- 或切换到住宅 IP 代理后重试 yt-dlp
