# Q007 - 平滑大移动后微调僵住 & 蹲拉peek预瞄偏差后大角度修正卡住

> **用户问题**：手臂平滑移动时候做微定位，要克服平滑之后再微调的不适应——大移动结束后想微调时手臂/手腕僵住，小幅度动不了
> **追加场景**：蹲拉peek预瞄偏差后，从静止预瞄保持切换到大角度flick时同样卡住挪不动
> **调研日期**：2026-10-13
> **父问题**：Q004-场景技术问题（子问题Q004.2小目标微调）/ Q006-移动中瞄准定位

---

## 一句话结论

> **僵住不是反应慢、不是灵敏度不对、不是微调能力差——是"肌肉张力档位切换失败"。大移动时为制动攒的张力有生理释放时滞，你在它没卸掉时就想微调，于是手被锁死。解药是"按肌肉群分配张力预算"：大移动只绷紧手臂/肩，手腕和手指从一开始就保持低张力。**

## 核心要点

1. **机制命名**：B站叫"肌肉锁死"（甜糖/夜莲/晨曜），YouTube叫"tension release lag"（Viscose逐字解剖），Reddit社区叫"Tension Switching failure"，三渠道独立交叉验证
2. **核心解法：Tension Budgeting**——三套独立张力预算：手臂（大动作/flick）、手腕（中速跟枪）、指尖（像素微调），分别控制不要整只手一起绷（Viscose 9JoDMDXVTcg 09:01）
3. **制动用"卸力"不用"急刹"**：拉枪途中主动释放紧绷肌肉，配合鼠标垫摩擦力自然停住，不要到终点再反向发力（晨曜 BV16eaA6bE9F 06:30）
4. **palm grip结构性放大**：趴握把手指"焊死"，垂直微调只能用肩代偿（精度差）；推荐palm-claw混合（relaxed claw），不必全切fingertip
5. **桌面/肘高是隐形杀手**：肘低于桌面→前臂压桌→垂直微调被锁（West Proter EqeDWH4kcME 03:28）；桌子过高/椅子过矮→代偿→两个物理运动相悖（克礼无明 BV1EZ4y1m7EA）
6. **反向场景同机制**：蹲拉peek预瞄偏差后卡住=等长收缩（静态）切不到爆发（动态），解药是架枪时A/D微动不要完全静止+预瞄离墙角远一点减少大角度修正
7. **Discord数据边界确认**：Woohoojin #vod-review 12个文件（2.1MB）中grip/tension/desk height全部0命中——社区语言体系不覆盖肌肉层，肌肉层解释全部来自B站/YouTube/Reddit
