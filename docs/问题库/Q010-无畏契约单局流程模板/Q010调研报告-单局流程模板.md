# Q010 调研报告：无畏契约单局流程模板

> 调研日期：2026-10-14
> 调研主题：在一把排位/一个回合里，除枪法外，按什么流程/清单执行（决策→信息→身位→道具→沟通→残局…）才能稳定增长实力？有没有现成的权威（职业教练/知名UP主/官方）单局流程模板？
> 渠道：B站（9组搜索/223去重/15精选/14字幕）+ YouTube（70+结果/10精选，字幕受bot墙限走二手汇编）+ Reddit（方式C+生态镜像）+ 通用搜索（12组/3页精读）+ 本地语料挖掘（Q005 19场景+Discord语料，71条要点）
> 交叉验证原则：B站+YouTube 一致→核心结论；通用搜索→教练/官方/研究口径；Reddit→社区经验；本地语料→已调研结论复用的权威锚点

## 〇、结论先行

**问题答案（直接版）**：

1. **不存在一份"职业教练背书、从买装到残局一条龙、编号可照做"的官方单局流程清单**——官方（拳头）只做到战术术语和 Performance Score 量化维度；职业教练圈（BoostRoom 等）做到"回合四阶段×角色职责"的粒度；中文圈最接近的是大东彦等知名UP主的"模块级流程"（经济/默认/peek/道具/残局各自成模板）。
2. **最接近"权威可量化单局模板"的是两个现成骨架，可直接照做**：
   - **BoostRoom「回合四阶段结构」**（职业教练级，S）：Early round（图控+信息）→ Mid-round（打/假打/转）→ Execute（空间转化）→ Post-plant（时间游戏），每阶段拆到 4 个角色的具体动作 → 覆盖"整局流程链"的权威骨架；
   - **Boosteria「残局 1vX 十步清单」+ Switchblade「回合开始前 5 步信息检查」**（教练站级，B/C）：Reset→Count→Locate→Time→Utility→Reduce angles→Create doubt→Isolate→Reposition→Finish，是"个人可照做"粒度最完整的现成 checklist。
   - **Woohoojin「How to Make Plans Like a Radiant」回合规划框架**（职业教练，S）：https://www.youtube.com/watch?v=TwVJ5TEGfd0 （9:06）；配套三支柱 Awareness/Positioning/Timing + 死后复盘循环（rewind 5-10 秒）——英文圈公认的单回合决策元框架。
3. **可量化部分有官方锚点**：Riot 官方 Performance Score（每回合 0-500 分，涵盖击杀/死亡/trade/助攻/道具/下包拆包），以及社区追踪表（Trade Participation 45-60%、DbD%<15-20% 等）。
4. **因此最终交付 = 把环节级权威模板按单局时间线拼成一套可执行清单（见第五节）**。逐条标注了"权威原版"（BoostRoom/Boosteria/Switchblade/大东彦等）与"本报告拼装"（阶段串联与个人层条目）。

**一句话**：单局内增长实力的流程 = **回合前定计划 → 默认阶段拿信息抢图控（不当对枪阶段）→ 决策窗口打/撤/转 → 道具链条进点 + 同步补枪 → 下包守包时间游戏 → 残局信息处理 → 回防五步协议 → 死亡后 8 秒复盘**；没有整局一条龙的官方模板，但有每个环节的权威模板可拼。

### ★ 模板候选 5｜Woohoojin「回合决策三要素框架」（社区汇编的职业教练体系）

来源：社区汇编《Valorant Concepts》https://docs.google.com/document/d/1h6cl_3LRNmvmadWY6U3VlyL-X_BY9VZ_TbCEun86YnA （Reddit 生态内高玩反复转帖；Woohoojin 本地 Discord 语料同源）
- 一切决策归为三要素：**Awareness（意识）/ Positioning（身位）/ Timing（时机）**
- 只在"不该接敌的 downtime"看小地图（转点/换弹/下包/队友吃接触时）
- 人数优劣势打法相反：优势方不冒险不送1v1、用交叉火/补枪设战斗；劣势方不蹲角等死、主动打快找孤立1v1；eco 回合 stack 点/前压偷枪
- mid-round 三问：我有地图控制吗？敌人大概在哪？还剩多少道具？
- 每 5 秒扫一次小地图；记敌方经济与大招进度
- Default 阵型三选：2-1-2 / 1-3-1 / 1-1-3；空间三分类：borrowed（借来）/ owned（已占）/ converted（转化）——与 BoostRoom 空间分层同源（Dignitas 官方同口径）
- 防守道具 Stalling vs Separating 二选一（拖延 vs 拆分），资源兑换"ebb and flow"
- Lurk 红灯/绿灯 + Tempo 匹配：回合慢则慢清，回合快则刀出速推
- Post-Plant 三硬规则：先 bomb tap 逼道具 / smoke 包上不包外 / 下包 tucked into corner
- 沟通三规则：trust comm 100% / 报点公式 location+agent+damage / off-angle 不 jiggle
- mid-round = IGL 70% 的工作（VLR 职业社区共识，FNS 为史上最佳 midrounder）

## 三、单局内可量化指标（可追踪部分）

> 分两层：官方现成指标 + 社区现成追踪表。**B站渠道确认：中文圈没有现成打分表，只有定性锚点。**

### 3.1 官方现成：Riot Performance Score（A）

每回合 0-500 分，官方口径涵盖：调整击杀/死亡、trade 参与、助攻、道具使用、下包/拆包——这就是拳头官方认可的"单局非枪法贡献"量化维度清单。来源：https://support.riotgames.com/en-us/valorant/gameplay/performance-score

### 3.2 社区现成追踪表（plussupermarket，C——独立博客，数字为建议区间非官方）

| 指标 | 建议区间 | 说明 |
|---|---|---|
| DbD%（deaths without trade） | <15-20% | 死了但队友无法补枪的比例——Q005 场景09/17 的唯一追踪指标同源 |
| Trade Participation | 45-60% | 参与补枪/被补枪的比例 |
| Entry Success% | — | 首进成功率 |
| Anchor Delay Time | — | 哨位锚点拖延时间 |
| IGL Plan Compliance% | — | 团队计划执行率 |

### 3.3 本地已验证的口径（Q005 锚点）

| 指标 | 定义 | 追踪方式 |
|---|---|---|
| **死了但队友无法trade的次数** | 死亡瞬间无队友能在1-2秒内补枪 | 每局手动计数（BoostRoom 10局计划唯一追踪指标） |
| 道具使用率 | 该用的烟/闪/侦察用了没 | DOR 三问复盘 |
| 信息获取 | 默认阶段是否拿到≥1条有效信息 | 复盘对照 |
| 补枪响应 | 队友开枪→我swing延迟 | 复盘计时 |

## 六、每回合微型决策循环（信息→决策→执行→复盘）

> 把清单"跑起来"的回合内 100 秒时间分配（【拼装】，骨架参考 BoostRoom round-clock + Woohoojin 体系）：

```
[0-10s]   定目标：本回合任务=拿信息/进点/守包/残局？（阶段0）
[10-60s]  收集信息：默认阶段拿到什么？对面用了什么道具？每5秒扫小地图（阶段B）
[60-80s]  决策：基于信息选 hit/split/fake/pivot；mid-round 三问（阶段C）
[80-100s] 执行：按角色链条做——道具→同步→trade→下包/守包（阶段D/E/G）
[死亡/回合结束] 8秒复盘：1个错误+1个修正；死后只报位置不分析（阶段H）
```

元框架（贯穿全程）：**Awareness（意识）/ Positioning（身位）/ Timing（时机）** 三要素——每次死亡归因到三要素之一（【原版】Woohoojin 体系）。只在 downtime（转点/换弹/下包/队友吃接触）看小地图。回合规划思维框架参考 Woohoojin「How to Make Plans Like a Radiant」：https://www.youtube.com/watch?v=TwVJ5TEGfd0 （9:06）。
