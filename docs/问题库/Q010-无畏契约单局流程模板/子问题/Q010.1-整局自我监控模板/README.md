## 反面意见摘要

- 局中想太多=choking（Beilock，场景19）；analysis paralysis（Woohoojin）
- 想太多拖慢操作是误解，真相是根本没想（疾风扳机）
- autopilot=大脑节能，低风险时刻无需监控（顺其自然派）
- 监控对象应是"读对手"而非内省手感（yay）
- 自我监控别变内耗（nAts）
