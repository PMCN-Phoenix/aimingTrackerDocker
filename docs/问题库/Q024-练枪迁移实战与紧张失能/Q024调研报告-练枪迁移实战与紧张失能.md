## §0 三十秒结论

**你说的不是一件事，是三件互相独立、但症状长得很像的事。分开治，一起治一定失败。**

|       | 你描述的症状        | 真正的故障                           | 一句话                                     |
| ----- | ------------- | ------------------------------- | --------------------------------------- |
| **T** | 「场景很像但发挥不出来」  | **迁移断点**：练枪和实战共享的是"画面"，不共享"需求"  | 你练的是执行，实战考的是"执行 + 决策 + 约束"，后两项在练枪里权重是 0 |
| **A** | 「肌肉变紧、控制不住肌肉」 | **张力预算透支**（不是情绪，是资源耗尽）          | 张力是有限的，实战里你在**进战斗之前**就把它花光了             |
| **C** | 「思路变紧」        | **注意力窄化 + 担忧占满工作记忆**（不是"想动作太多"） | 70 名专家运动员在压力下想的几乎全是"担心"，不是"动作"          |

**最硬的三条本地证据：**

1. **你每天第一轮比后面低 1 个标准差**（d 中位 **−1.05**，20 个场景里 17 个成立，且与场景方差无关 r=+0.13）——这不是噪声，是热身衰减。
2. **但一轮之内 60 秒完全没有衰减**（命中率后半−前半中位 **+0.00**，TTK 中位 **+0.000**，839 轮）——你的损耗不在"过程"，在"进入"。
3. **当天第 3 轮是峰值（当天最好成绩的 94.4%），第 6 轮掉到 87.2%**——练过头再进游戏，你是带着一条下坡曲线进去的。

**所以最重要的一个动作是：把"练枪"和"实战"之间的顺序改掉，并且把第一轮当成废轮。**

## §1 先分诊：三种故障，三个 30 秒自测

不要一上来就"放松""别紧张"。先确定你今天是哪一种。三种的解法互相冲突，用错会加重。

### 30 秒自测 A：你紧的是"手"还是"脑子"？

打一轮你最熟的场景（不要难的），然后在第 30 秒时问自己一个问题：

> **我现在的注意力在"目标上"，还是在"我的手上"？**

- 在目标上 → 走 **T 或 A**
- 在手上 / 在"我这一枪要打准"上 → 走 **C**

### 30 秒自测 B：张力预算还剩多少？

进入死斗，**不打架**，只做一件事：连续在 3 个点位之间甩枪预瞄 20 秒（模拟你实战里"点与点之间不停甩"的状态），然后立刻做一次微调瞄准（打一个远处静止目标的头）。

- 前 3 次微调**发飘、有台阶感、要"等一下才顺"** → **A 型，张力预算已透支**
- 微调依旧干净 → 你的问题不是张力，走 **T 或 C**

> 依据：Viscose 的 `lockout` 自测——"把手臂绷到快发抖 5–10 秒，然后立刻做很小幅度的动作，前几下一定是抖的、要过一会儿才平滑。这叫 lockout，就是你用了超过你拥有的张力。"

### 30 秒自测 C：你是"怕输"还是"怕打不准"？

回想上一次发挥不出来的一局，问：

> **我当时脑子里出现的是"别死""别送""这局要输了"，还是"我的准星要贴上去""别抖"？**

- 前者（担忧）→ **C 型的 distraction 分支**（占多数）
- 后者（动作）→ **C 型的 self-focus 分支**（占少数）

> 依据：Oudejans 2011（PMID 20425657），70 名专家运动员在高压比赛中自报注意力焦点——**"注意力经常落在担忧上，几乎从不落在动作执行上"**。这条把"我以为我在想动作"这个自我归因推翻了一大半。

## §2 本地数据：损耗集中在"进入"，不在"过程"

数据源：`D:\1_game\1_steam\...\FPSAimTrainer\stats`，839 轮（每轮 ≥8 杀）逐杀解析 + 325 个"日×场景"组合。脚本 `_local_stats.py` / `_local_stats2.py` / `_local_stats3.py`。

**这是本次调研最重要的一条本地结论。** 你每天的第一轮，平均比当天后面几轮低**整整一个标准差**。而且这不是"难场景才这样"——连 `Wide Wall 3 Targets TE`（12 天、轮间只有 2.2% 波动、非常稳的图）都有 d=−1.69。

### 2.2 但一轮之内，60 秒完全不衰减

```
样本 839 轮（每轮 ≥8 杀，前半 vs 后半）
命中率 后半 − 前半：中位 +0.00 个百分点｜变差占比 49%
TTK    后半 − 前半：中位 +0.000 秒｜变慢占比 50%
```

**中位数精确地落在 0。** 你在一轮 60 秒里不会越打越差。

把 2.1 和 2.2 放在一起，指向一个很具体的结论：

> **你的损耗不在"撑不住"，在"还没进去"。** 所以解法是**热身协议**，不是耐力训练。

### 2.3 热身曲线：第 3 轮是峰值，之后开始掉

同一天同一场景内，第 k 轮 ÷ 当天最好一轮：

| 轮次    | 样本  | 相对当天最好    | 说明       |
| ----- | --- | --------- | -------- |
| 第 1 轮 | 281 | **88.0%** | 冷        |
| 第 2 轮 | 281 | 92.0%     | 快速回升     |
| 第 3 轮 | 281 | **94.4%** | **峰值**   |
| 第 4 轮 | 120 | 90.4%     | 开始掉      |
| 第 5 轮 | 53  | 89.5%     | 继续掉      |
| 第 6 轮 | 19  | **87.2%** | 已低于第 1 轮 |

分组看：

```
WARMUP 场景  n=35   第1轮 88.5%  第2轮 94.4%  第3+轮 97.1%
正式场景     n=246  第1轮 87.9%  第2轮 91.7%  第3+轮 94.1%
```

**倒 U 型。** 第 1→2 轮涨 4 个点，第 2→3 轮再涨 2.4 个点，第 3 轮之后开始下滑，第 6 轮已经比第 1 轮还低。

> ⚠️ 第 5、6 轮样本只有 53 / 19，结论强度弱于前 4 轮。但第 3→4 轮（n=120）的 −4.0 个点已经足够稳。

这条直接对上大东彦那句：「**你练枪练了很长时间，然后在这种精力消耗的情况下要去打天梯，那你练枪分数即使练得再高，因为精力消耗太严重了，实战反而会显得非常拉胯。**」他还给了个算术：练枪 2 小时让瞄准从 1.0 到 1.1，但精力从 100% 掉到 90% —— `1.0 × 100% > 1.1 × 90%`。

### 2.4 方差分解：日内波动 ≈ 日间波动

```
修正版（between 已扣除抽样误差 within/n）：日内 SD ÷ 日间 SD 的中位比值 = 1.15
Jumbo Tile Frenzy LG56 WARMUP   日内 10.5% / 日间 0.0%  → 比值 ∞
voxTS Voltaic LG56 WARMUP       日内 11.4% / 日间 2.3%  → 4.89
patTS Voltaic Iron              日内  4.0% / 日间 1.5%  → 2.74
Flower Easier 50cm              日内 21.7% / 日间 17.6% → 1.23
```

**你同一天内轮与轮之间的波动，和天与天之间的波动一样大。** 也就是说：你的表现有一半是"今天什么状态"，不是"你什么水平"。

这条的意义：**任何只看单轮分数的自我评价都是无效的**。你必须看 3 轮的中位数。

## §3 为什么"练的东西用不出来"——迁移的 5 个断点

### 断点 1：练枪是"低压 + 纯瞄准"，实战是"高压 + 决策"

大东彦（B站 `BV1te4y1x7EC`）说得最直接：

> 「练枪软件会为你提供一个**没有其他外部压力的、为特定目的服务的场景**……我们在此前的视频中多次提到，你的瞄准能力与实战中的枪法不是直接挂钩的。实战中的枪法除了需要手眼协调、瞄准能力之外，还需要**左右手协调、移动补偿**——你要学会用移动来补偿瞄准、用瞄准来补偿移动。只有好的实战枪法也还是不够的，你需要**临场做出正确的决策**，才能在实战中把枪法转化为高效击杀。」
>
> 「我们在练枪软件里能练习的**只有纯粹的瞄准能力**。」

同一位作者在 `BV15L411p7oi` 里给了边际效用曲线：把瞄准能力量化成 100 分，**拐点在 80 分**。80 分之后，瞄准再涨对实战的提升趋近于零；到 13 万分（他的口径）以上，练枪软件就该"完全沦为热身工具"。

琪露诺（B站 `BV1m14y1q7rX`）给了更狠的一张图——**各游戏对瞄准的"转化率"阶梯**：

```
Quake 97%  >  COD/战地（转火）80%  >  OW（长TTK，不限制瞄准）高  >  Apex（1v1）不低  >  瓦罗兰特 靠后  >  CS 最低
```

他对瓦罗兰特的判断是：「这个游戏的核心还是传统 FPS 的核心，还是要学急停、站位、预瞄……**在这种游戏里，发挥瞄准和杀敌并不能帮助你特别多，反而是对游戏的理解、大局观，能帮助你获得更多取胜的概率。**」

**你打的是瓦罗兰特——它本来就在转化率阶梯的末端。** 这不是你的问题，是游戏结构决定的。

### 断点 2：迁移取决于"共享需求"，不取决于"看起来像"

这是"近迁移"的核心理论，Oei & Patterson 2014（PMID 24782722）的 **common demands hypothesis**：

> 迁移只在训练任务和目标任务**共享同一批认知/知觉需求**时发生。他们综述了动作游戏与非动作游戏的研究，结论支持"每个任务都是被单独训练的，因为游戏和实验室任务**含有相似的需求**"这一派，而不是"一般能力提升"那一派。
>
> 「在游戏和任务**不共享需求**的地方（例如执行功能），迁移的证据是模棱两可的。」

翻译成你的话：**"场景很像"是个视觉判断，"需求是否相同"是个任务分析判断。你的眼睛告诉你很像，你的任务分析告诉你完全不同。**

一个残酷的实证：Romeas 2025（PMID 39427852），62 名职业足球学院的球员，随机分到双任务 3D-MOT 训练组和对照组。结果：

> 「训练组在 3D-MOT 上显著提升（p < 0.001）。**然而，两组在近迁移认知测试和场上表现上都没有显著的前后差异（ps > 0.05）。**」

练的东西涨了，场上没变。Harris 2020（PMID 32116972）在 84 人上重复了同样的失败：**无近迁移、无远迁移**。Kassai 2019 的元分析（PMID 30652908）给了分界：**近迁移 g=0.44 显著，远迁移 g=0.11 不显著**。

### 断点 3：训练和比赛的行为统计，差得像两个运动

Maloney 2018（PMID 29445348）是这条最漂亮的证据。他们让 10 名高水平跆拳道运动员在**训练**和**比赛**两种情境下打，然后同时测行为、情感、认知：

| 指标            | 训练 vs 比赛  | 效应量           |
| ------------- | --------- | ------------- |
| 发起攻击的频率       | 训练中**更少** | d = 0.81      |
| 发起攻击的距离       | 训练中**更远** | d = −0.20     |
| 运动轨迹的**可预测性** | 训练中**更高** | **d = 0.84**  |
| 焦虑            | 训练中更低     | **d = −1.26** |
| 唤醒度           | 训练中更低     | d = −1.07     |
| 心理努力          | 训练中更低     | d = −0.77     |
| 双方间距          | 训练中**更大** | d = 0.80      |

**注意方向**：训练里你**更保守、更被动、更可预测、更不用力**。这跟直觉相反——大家以为训练里更敢打，实际上训练里你在"安全地重复"。

而且 d=0.84 的"可预测性"差异，正好解释了为什么你觉得"场景很像"：**画面确实像，但你的行为统计完全不一样**。你在实战里做的动作，在训练里从来没出现过。

### 断点 4：Kovaak's 里根本没有的那三个约束

这条是 YouTube 侧最有价值的一条，来自 `F5Tj4akXGWM`（"The Real Reason Why Your Aim Training Doesn't Transfer"）：

> 「**瞄准训练不能迁移，是因为它强化的整套方式本身就是错的。** 大多数人这样瞄准：看到人 → 停下 → 瞄准 → 开枪。停、瞄、打。**瞄准训练把你训练成只在站着不动的时候才舒服地瞄准。**
>
> 但在"停下"和"开枪"之间的这个空档里，**你选择成为一个静止的靶子**。……正确的方式是把瞄准段移到停下**之前**。所以不是 `停 → 瞄 → 打`，而是 **`瞄 → 停 → 打`**。」

第二个原因更硬——**枪械机制**：

> 「问你自己一个问题：**你真的控制你的枪吗？** 具体说，你真的控制你的子弹去哪吗？……如果任何一发子弹往上飘，那你就没有控制你的枪。**这是最简单、最基础的机制，但连不朽段位的人都在忽略它。**」

他的练法：对墙打，看弹道。Vandal **前三发是一组，第四发有个巨大的间隙**，所以先只练前三发。

把这三条约束列清楚：

| 约束                   | Kovaak's         | 瓦罗兰特            | 后果                          |
| -------------------- | ---------------- | --------------- | --------------------------- |
| **跑射惩罚**             | 无（移动中照样精准）       | 移动中第一发随机        | 你在练枪里养成的"边走边打"在实战里是纯送       |
| **弹道 / 后坐力**         | 无（LG/beam 或单发精准） | 前 3 发成组，第 4 发起跳 | 你只练了第一发，第 2–3 发完全没练过        |
| **stop-to-shoot 时序** | 无（不需要停）          | 必须先归零再开枪        | 你缺的是"瞄准在移动中完成，停下只是为了确认"这个时序 |

第三条还有个实操 cue，Scyfe（`WGS-xDCvS7M`）讲得最清楚：

> 「**低分段玩家按开火键是为了"打中"目标；高分段冷静型选手按开火键是为了"确认"已经打中。** 当你在准星还在移动的时候开枪，你不是在瞄准，你在赌博。」
>
> 「**isolate your hands：你的左手必须完全停下，你的右手才被允许点击。**」

### 断点 5：你知道得越多，越容易 choke

这条最反直觉，但实验很硬。Lee 2019（PMID 29777527，*Psychon Bull Rev*）：

> 「我们证明，**只有那些在训练和测试时使用了"允许预备性运动规划的前置线索"（premovement cues）的参与者，才会因为大额金钱激励而在压力下 choke**，而且这个效应**与达到的技能水平无关**。
>
> 相反，那些**通过"附带学习"（incidental training）被减少显性技能知识的参与者，不会因为激励而调节表现，看起来对 choking 免疫**。」

**"与技能水平无关"这几个字很关键。** 不是"你练得不够好所以崩"，是"你知道得越清楚，越容易被压力劫持"。

这条对改法有直接影响：**你在练枪时越"知道自己在练什么技术点"，实战里越容易 choke。** 所以"带着明确技术目标练枪"这件事，本身有代价——它让你在实战里有一堆可以被劫持的显性知识。

配套的是 Baumeister 1984（PMID 6707866）的原始模型：

> 「压力增加了**对自己执行过程的意识注意**，而这种增加的意识注意**破坏了执行的自动化/过度学习性质**。」

以及 Law & Wong 2021（PMID 32909081）的因果验证——61 人投镖，随机给"内焦点指令"（关注自己的动作）vs 无指令：

> 「内焦点指令导致投镖**精度更低（p = 0.008）、投掷时间更长（p = 0.001）、心理压力更高（皮电，p < .05）**。」

**"想动作"这件事，本身就会让你更紧、更慢、更不准。** 这是你"思路变紧"最直接的实验对应。

### 断点 5 的反面：别把这条读成"练枪没用"

必须诚实标注三个限制，否则会走向另一个极端：

1. **随机练习（contextual interference）的迁移优势，在实验室里成立，在应用场景里不成立。** Czyż 2024（PMID 39205981，42 项研究 / 34 项进元分析）：总体 SMD=0.55 支持随机练习；但**实验室 SMD=0.75 显著，应用场景 SMD=0.34 小且不显著**。另一篇 retention 元分析（PMID 38987617，54 项）结论一样：**应用场景里随机练习的好处"几乎可以忽略"**。
2. **训练"类型"不决定迁移"类型"，但训练"量"决定迁移"量"。** Schoenfeld 2024（PMID 38081160，N=450，双任务学习）：「**技能训练的类型与技能迁移的类型无关。然而，技能训练的量与技能迁移的量正相关。**」
3. **练枪确实在提分。** 你的数据里 `Pokevox Easy LG56` 从 10-11 的 7% 完美一束到今天的 90%（Q004 已记录），这是真实的能力提升。问题不在"练没用"，在"练到的东西没有接到实战那根管子上"。

## §4 为什么"一打就紧"——张力预算模型

这一节是本次调研最大的理论收获：**它把 Q021、Q022、Q024 三篇统一成一个模型。**

### 4.1 核心：张力是有限的，而且分三个独立账户

Viscose（YouTube `9JoDMDXVTcg`，"Solving the most common aiming issue - Tension Management Guide"）——注意这是**你的 VDIM 清单体系里的作者本人**：

> 「网上教你怎么变平滑，你大概会看到"保持冷静、让肌肉完全放松"。这对某些情况有用。**但这个方法有一个巨大的弱点：你的肌肉才是让你的瞄准变快的东西。** 一直靠放松来求平滑，会严重限制你的速度——或者说限制你在高速下的平滑度。**我知道，因为我试过。**」

他的模型：

```
张力预算（tension budget）—— 有限，且分三个独立账户：
  ① 手臂（arm）      大角度甩枪的主力，速度上限最高
  ② 手腕（wrist）    小幅动作、微调
  ③ 指尖 / 握力       稳定与"脆感"（snap），不负责移动鼠标

规则：高张力 = 冲刺。爆发力强，但耗能，之后必须恢复。
      三个账户独立 → 手臂透支时，手腕仍然可以微调。
```

**Lockout（锁死）**：

> 「我们只有有限量的张力可以分配。你可以自己试：把手臂绷到几乎发抖，坚持 5–10 秒，然后立刻用这只手臂做非常小的动作。**它需要一段时间才能从那次用力中恢复。最初几下会抖、会有台阶感，要过一会儿才平滑。这叫 lockout，就是你用了超过你拥有的张力。**」

### 4.2 刹车的两种方式——这里修正了 Q021

Q021 的结论是"到点卸力滑停"。Viscose 把它精确化了：**不是"到点"卸力，是"到点之前"卸力。**

> 「我当时的做法是**在甩枪结束时加更多张力**。我习惯把张力想成 1–10 的刻度：一次动作的开始可能是 5，结束时可能是 8。看起来有效——我的准星确实停住了。**但看看之后发生了什么：我做不出需要的那种平滑微调了。**」
>
> 「停住 flick 动量的第二种方法，是把同一个想法压缩进一次鼠标移动之内：**在到达目标之前，就释放掉甩枪开始时的张力，让已经产生的动量把你带完剩下的路。**」

他自己的复盘：

> 「实现这个技术之后，我能做出那种脆利的动作，同时之后仍然能流畅地调整。**我不再被困在那个恢复期里。**」

而且**甩得越大，这条越重要**：

> 「你移动鼠标越多、越快，你用的张力和产生的惯性就越大，这些都必须被抵消才能停下来。所以**用张力来刹车，需要更多张力**。缺点变严重了，但**通过释放张力来刹车反而变容易了，因为你必须释放它的那个窗口变大了**。」

### 4.3 实战里到底发生了什么——这一段直接命中你的原话

> 「对我来说一个大问题是：**在点位之间尽可能快地甩枪。** 我的想法是这样能减少可能被拉出来打个措手不及的空档，让我保持"锁在状态里"。这些确实是真的，**但我没意识到这些动作花了多少张力。**
>
> 在点位之间快速甩，短期内造成了"甩枪和之后动作之间的延迟"，**长期则造成了张力预算问题。我一直在点位之间甩，张力就逐渐累积。等到我真的进入一场枪战时，我已经没有张力可用了**——既因为张力本身已经很高，也因为我全程只用手腕。」


**这就是"一打实战就紧"的机制，不需要任何情绪解释。**

你在点位之间不停地甩枪预瞄（这是好习惯，教练都这么教），但你没意识到这是**在花张力预算**。等真正开打时，你的账户余额是 0。所以你感觉"肌肉是紧的、控制不住"——**因为你的肌肉确实已经处在恢复期里了，那不是错觉，是生理状态。**

而且他明确点出了"神经"这个变量：

> 「在一场需要大量张力的枪战之后，**很容易不小心把张力留着不放，尤其是当神经紧张这个因素加进来的时候**，结果就是：你几乎在 lockout 的边缘进入下一场枪战。」

### 4.4 为什么"呼吸"有用——它不是在安慰你，它在回填账户

> 「这大概就是"深呼吸、放松、保持冷静"这类建议在游戏里为什么有效的一部分原因：**它通过让你放松肌肉，来帮助你做好张力管理。**」

这就把 B站 `BV1bj411Q7bw` 的生理机制接上了：

> 「压力反应源自交感神经的活跃，那么为了对抗压力，我们要做的就是激活相反的部分，也就是负责让我们冷静下来的**副交感神经**。……**生理性叹气（physiological sigh）**：1~2 次短而快速的吸气，伴随一次长时间的呼气。**实验表明，在这个模式下呼吸循环 3~5 次之后，压力水平会经历一个十分明显的下降。**」

以及 `BV12p411o7oh` 里的军方版：**战术呼吸 4-4-4**（吸 4、停 4、呼 4），激活迷走神经、降心率、降血压。"纽约市警察接受训练来对抗肾上腺素对工作的影响，军队成员和其他高风险专业人员也是如此。"

### 4.5 神经层面：压力不是"不够努力"，是"准备过头"

Smoulder et al. 2024（PMID 39270654，*Neuron*）——这是目前 choking 研究最硬的一篇：

> 「我们研究了执行一项有挑战性伸取任务的恒河猴，当一笔异常大的"头奖"奖励悬于一线时，它们表现下降……**我们发现，奖励的增加会把运动准备期间的神经活动推入、然后推过一个最优表现区间（into, and then past, a zone of optimal performance）。**」

**"推过最优区间"** —— 这就是"肌肉变紧"的神经解释。压力让你的运动皮层**准备得更多**，而准备过头 = 拮抗肌共收缩 = 关节僵硬 = 自由度被冻结。

这也解释了 Tanaka & Sekiya 2011（PMID 21684618）在高尔夫推杆里测到的东西：

> 压力条件下：**旋转动作的角位移减小、手臂与球杆的运动时间缩短、下摆阶段肘部加速度增大**——而**平均表现没有变**。

翻译：**动作幅度变小、时间变短、加速度变大，但结果暂时还撑得住。** 这就是"紧"的量化形态。而"平均表现没变"说明这是一种**代偿**——你用更僵的动作维持了同样的输出，直到压力再高一点点，代偿就撑不住了。

### 4.6 "思路变紧"的三个物理来源

不是比喻，是三个可测的现象：

**① 认知隧道（cognitive tunneling）**。Dirkin 1983（PMID 6844068）：「所谓压力下的"隧道视觉"，描述的其实是**注意的窄化，而不是视觉的窄化**。」Williams & Andersen 1997（PMID 9138624）在 201 名大学运动员上测：**压力任务下所有知觉变量都显著变差**，而且"高负面生活事件者周边视觉窄化更多、中央视觉反应时更慢"。

对应你的体验：实战里你只看得见准星附近，看不见小地图、看不见侧面、听不见脚步。**这不是你不专注，是你过度专注。**

**② 担忧占满工作记忆**。Oudejans 2011（PMID 20425657）的 70 名专家数据：压力下注意力落在**担忧**上，几乎不落在动作上。所以"思路变紧"更可能是"想的事情太多太急"，不是"想动作想太多"。

**③ 时间感扭曲 + 失控感**。Furuya 2021（PMID 33406149）用 258 名钢琴家的问卷做了因子分析，提取出 8 类压力下的功能异常，其中两类是 **"feeling rushed"（感觉被催/赶）** 和 **"a loss of body control"（失去身体控制）**——而且分析显示：**演奏中的"错误动作"是由"感觉被赶"和"失去身体控制"共同影响的。**

**你说的"思路变紧"和"控制不住肌肉"，在这篇里是两个被独立命名、且被证明互相驱动的因子。**

### 4.7 一个能验证这个模型的预测

如果张力预算模型是对的，那么你的实战失误应该**不是均匀分布**的，而是集中在两种情境：

| 预测                              | 为什么                                      |
| ------------------------------- | ---------------------------------------- |
| **A. 连续交战 / 连续预瞄甩枪之后的第二、第三场枪战** | 张力在第一场就花完了，第二场在 lockout 边缘开打             |
| **B. 静止对峙 / 架点等待 / 残局 1v1**     | 没有其他注意需求来分走注意力 → 显性监控容量充足 → 最容易 reinvest |

B 这条有独立证据。Hoskens 2023（PMID 37665924）曲棍球研究：**"意识性运动加工"（conscious motor processing）与点球（shoot-out）表现负相关，但与场上（in-field）表现无关**。作者的解释是：

> 「场上情境中必须在许多**非静态的注意需求**之间切换，这可能**减少了在表现中进行运动特异性 reinvestment 的容量**。」

**翻译：混战里你没空 choke，1v1 静默对峙你才有空 choke。** 这跟你说的"残局手抖"完全对上，而且它反过来说明：**如果某次你是在多人混战里崩的，那大概率是 A 型（张力），不是 C 型（reinvest）。**

## §5 改进方案

### 5.1 修 T（迁移）：把"练枪"接到"实战"那根管子上

#### 技术 1（最高优先）：把练枪时间和游戏时间"拴"在一起

Void Hunt（YouTube `POcSo23KtgU`）：

> 「这个问题最好的解决方案之一，是**把你的练枪时间拴（tether）在你的正常游戏时段上**——保证你做了其中一个之后，紧接着做另一个。关于"训练放在游戏前还是游戏后"意见不一，**但两种选择都远远优于"练枪和游戏隔天交替"这种安排，更不用说"连续几周只练枪然后再回去打游戏"——那只会招来 rage 和挫败感。**」

这条跟你已有的安排直接冲突的话要改：**"这周集中练枪、下周集中实战"是错的**（大东彦也提过这个交替法，但他说的是"周"级交替，Void Hunt 说"日"级拴连更好——两者有冲突，我倾向 Void Hunt，因为日级拴连的迁移间隔更短，且能被你的本地数据支持：第 1 轮冷启动 d=−1.05 说明"手的状态"半衰期很短）。

#### 技术 2：补上 Kovaak's 里没有的 stop-to-shoot 时序

来自 `F5Tj4akXGWM` 的靶场练法，直接可执行：

```
1. 进靶场，杀 50–100 个 bot
2. 唯一规则：永远在移动中（不许站定）
3. 在移动中瞄 bot，当你认为能杀的时候，停下、开枪
4. 视觉 cue：移动时枪口朝内收，停下时枪口弹出来 —— 枪弹出来才是"可以精准开枪"的信号
5. 顺序口诀：瞄 → 停 → 打（不是 停 → 瞄 → 打）
```

配套的左手隔离（Scyfe `WGS-xDCvS7M`）：**"左手必须完全停下，右手才被允许点击。"**

#### 技术 3：把"弹道"当成一个独立技能补

`F5Tj4akXGWM`：Vandal 前三发成组、第四发有大间隙。所以：

```
阶段 1：对墙打，只练前 3 发的落点一致性（目标：3 发打成一个拳头大的洞）
阶段 2：加入 bot，只打 3 发点射，不许连发
阶段 3：加入移动，移动中瞄、停下打 3 发
```

这条在 Kovaak's 里练不到，只能进游戏练。**它是你"练枪分数高但实战打不过"里最容易被忽略的一块。**

#### 技术 4：在练枪里人为制造"决策需求"

练枪场景最大的问题是**它替你做了所有决定**：目标在哪、打哪个、什么时候打。补法是加一层 if-then 预设：

| 加什么            | 具体做法                                                                   |
| -------------- | ---------------------------------------------------------------------- |
| **if-then 预设** | 进图前写 2 条规则，例：「如果目标从左边出现，我先往左偏 10% 再贴」；「如果同时有两个目标，先打离准星近的那个」。一轮只执行这 2 条 |
| **信息剥夺**       | 关掉分数显示 / 关掉声音 / 只看屏幕中央 1/3（强制用周边视觉）                                    |
| **随机化**        | 不要按固定顺序打场景。同一天混着打 3 个不同类型的场景（虽然元分析说应用场景效果小，但成本为零）                      |
| **单次机会**       | 每个场景只打 1 轮，不许重开（模拟"这局只有一次"）                                            |

#### 技术 5（反直觉，但证据最硬）：练枪时**少**给自己贴技术标签

Lee 2019（PMID 29777527）的结论是"显性知识越少，抗压越强，且与技能水平无关"。所以：

- **不要**在每一轮练枪时都默念"我在练 Q021 的卸力"
- **要**把技术要点写在纸上/文档里（练之前看），**练的时候只想一个动词**
- 这一条和你现在"每轮只盯一件事"的习惯兼容——&#x4F46;**"盯"的对象要从技术名词换成一个动作意象**（"滑"、"贴"、"松"），不是"制动"、"张力预算"这种概念词

> 这条和 Q021/Q022 的"只盯一件事"表不冲突：表照用，但**盯的词要降级成动词**。

### 5.2 修 A（张力预算）：这是你现在最该动的一层

#### 技术 6：把"到点刹车"改成"到点前释放"

**Q021 的"到点卸力"要升级成"到点前卸力"。**

```
错误：甩 → 甩 → 甩 → 到目标 → 加张力刹住 → (lockout) → 微调不动 → 再推一次 → 过头
正确：甩 → 甩 → 甩 → 还差 10~15% 距离时松开张力 → 动量把你带到位 → 手腕/指尖微调
```

Viscose 的原话：「**在到达目标之前，就释放掉甩枪开始时的张力，让已经产生的动量把你带完剩下的路。**」

**甩得越大越要这么做**，因为大甩的"释放窗口"更大（更容易做对），而"用张力刹车"的代价更大（需要的张力更多）。

#### 技术 7：三账户分工——手臂甩，手腕留，指尖稳

```
手臂：所有 > 90° 的转点、跨点位甩枪
手腕：< 90° 的甩、所有微调
指尖/握力：不移动鼠标，只提供"脆感"和稳定；随用随加、用完立刻撤
```

关键用法（Viscose）：**"手臂甩枪时不要同时绷手腕。"** 因为账户独立——即使手臂的张力来不及释放，手腕仍然是干净的，可以立刻微调。

这条直接解决 Q021 的"大角度用手腕 → 腕到极限 → 落点后无微调余量"：**不是"别用手腕"，是"大角度用手臂、把手腕的额度留到最后"。**

#### 技术 8：交战间隙"回填"——0.5 秒松手

Viscose：「在一场需要大量张力的枪战之后，很容易不小心把张力留着不放……结果就是几乎在 lockout 的边缘进入下一场枪战。**这就是为什么养成放松肌肉、释放张力、为下一次交战回填张力预算的习惯是好的。**」

具体做法（每场枪战结束后，无论输赢）：

```
1. 手指离开鼠标按键（物理动作，不是想）
2. 手掌松开到"别人能把鼠标从你手里抽走"的程度
3. 一次生理性叹气（短吸 2 次 + 长呼 1 次）
4. 然后才继续走位
```

**这 4 步加起来不到 1.5 秒**，在一场枪战结束到下一次遭遇之间完全放得下。

#### 技术 9：不要"努力放松"

这条要单独说，因为它是"越想放松越紧"的机制解释。Viscose：

> 「这（加压）会制造一种**控制感**。当瞄小目标或在高压情况下，加压是很自然的。**那种控制感是假的。** 在那些情况下增加张力，会让任何动作——有意的或无意的——都更难做。所以你可能会变得稍微稳一点，但**它会让"调整"变得几乎不可能**。」

所以：

- ❌ "我要放松" → 这是一个内焦点指令 → 按 Law & Wong 2021，它会让你**更紧、更慢、更不准**
- ✅ "手掌摊开" / "手指离开按键" → 这是一个**具体动作**，不是状态要求
- ✅ 更好：把注意力放到**目标上**（外焦点），让张力自己掉

Wulf 2001（PMID 11765737）给了这个的实验室版本：外部焦点组比内部焦点组**平衡误差更小**，而且**探针反应时更短**——说明"自动化程度更高、意识干扰更少"。

#### 技术 10：入场前的张力基线校准（30 秒）

```
第 1 步：握力测试 —— 握住鼠标，然后松到"别人一抽就走"的程度，再紧一点点。这是你的实战基线。
第 2 步：甩枪测试 —— 在点位间甩 3 次，每次甩完立刻做一次微调。如果微调发飘 → 你已经在透支，减量。
第 3 步：叹气 3 次 —— 生理性叹气，回填账户。
```

**这个校准要放在"进排位之前"，不是"进图之后"。**

### 5.3 修 C（reinvest / 担忧）：打断"想"这件事

#### 技术 11：单一外部线索词

只留一个动词，在整局里反复用。候选（选一个，不要多）：

```
「贴」 —— 跟枪/贴脸
「滑」 —— 转火/停枪
「停」 —— stop-to-shoot 时序
```

**禁止在比赛中出现技术名词**（"张力预算""制动""欠瞄"这类词）。理由：这些词是显性知识，一调用就进入 reinvest 通道。

#### 技术 12：赛前写完，赛中封存（parking）

```
开局前 2 分钟：把今天要做的 1–2 个技术点写在纸上或手机备忘录里
然后：合上 / 收起 / 不再看
比赛中：如果想起技术点，对自己说"已记下"，然后回到线索词
```

这本质上就是 Lee 2019 的"把显性知识留在训练场"的操作版。

#### 技术 13：chunking——给意识一个小到不会干扰的任务

`eCYhI3sWsSE`（The Calm Competitor, Ep6）讲的就是这个。它先讲了 Beilock 2001 的高尔夫推杆实验：

> 「一组被告知正常挥杆。另一组被告知**在挥杆时监控自己的推杆动作，特别是注意杆头接触球的瞬间**。**第二组推得明显更差。不是新手，是专家。**」
>
> 「**记忆里什么都没丢。技能是完整的。受损的不是知识本身，而是"访问知识的方式"。**」

解药：

> 「**给意识一个很小的、即时的任务，让你的自动肌肉记忆去完美执行。**」

在你的场景里，这个"小任务"可以是：

- 数自己这一波的**子弹数**（1-2-3，停）
- 默念"左手停"（只管左手，不管准星）
- 盯着目标的**一个具体特征**（头带的颜色 / 肩膀的边）

**共同点：它是一个外部锚点，占住了意识，让意识没空去管动作。**

#### 技术 14：注意力外投 + 拓宽视野（针对"思路变紧"）

两条实证：

- **quiet eye**：Vickers & Williams 2007（PMID 17827115）冬季两项，10 名精英射手，在最高生理负荷下——「**把视觉注意力外部地指向关键任务信息，似乎能让运动员与压力下的 choking 隔离开**」（d-QE 增加解释 58% 的方差，且独立于心率）。
- **拓宽视野降警觉**：B站 `BV1bj411Q7bw`——「压力大时瞳孔不自觉扩张，视线高度集中在某一小片区域。**可以尝试有意识地拓宽视野，四处扫一扫，把集中于一小片区域的微观视野调节至宏观视野。这个行为会有助于降低神经系统的警觉度。**」

实操：**每回合开始（买枪阶段 / 走到点位途中）做一次"扫一圈"**——刻意看一遍屏幕四个角 + 小地图。不是"注意周边"，是**主动把眼睛移到四角**。

### 5.4 热身协议（本地数据直接支撑，优先级仅次于 5.2）

基于 §2 的三条数据（第 1 轮 d=−1.05 / 第 3 轮峰值 / 局内无衰减）：

```
【进排位之前，20 分钟，四段】

第 0 段（2 min）身体
  - 手部回暖（Q023 已给方案）+ 3 次生理性叹气
  - 目的：把交感基线降下来，不是"兴奋起来"

第 1 段（5 min）open-skill 热身，2 轮
  - 用反应类 / 跟枪类场景（D 清单、C 清单），不要用纯静态点击
  - 依据：Anshel 1995（PMID 7563292）——closed 任务能消除更多热身衰减，但 open 任务之后的实际表现更好
  - 心态：这 2 轮是废轮，分数不看

第 2 段（8 min）主项，2 轮
  - 你的当前主项（E 清单 / 当日清单）
  - 只看第 2 轮，不看第 1 轮
  - 依据：第 1→2 轮涨 4.0 个点，第 2→3 轮涨 2.4 个点

第 3 段（5 min）stop-to-shoot 专项
  - 进靶场，按技术 2 的 5 步做 50 个 bot
  - 目的：把"瞄→停→打"的时序装进手上，而不是装进脑子里
```

**硬规则：**

| 规则                                   | 依据                    |
| ------------------------------------ | --------------------- |
| **不进排位前不许跳过第 1 段**                   | 第 1 轮 d=−1.05         |
| **练枪总时长 ≤ 20 分钟（进排位前）**              | 第 6 轮掉到 87.2%；大东彦的精力账 |
| **连续 3 轮分数都低于当天第 1 轮 → 停练，直接进游戏或休息** | 你已在下坡段                |
| **不把第 1 轮分数写进日记/看板当作"今天状态"**         | 那是热身衰减，不是状态           |

### 5.5 压力接种（这是唯一有元分析支持的"提高抗压"手段）

Zeng 2026（PMID 41951087）元分析，21 项研究，干预包括 quiet eye 训练、赛前例行程序、正念、左手握紧、自我对话、理性情绪行为疗法：

```
运动精度      g = 0.660
执行成功率    g = 0.444
目标偏差      g = 0.301
闭式技能场景  g = 0.455（效果更大更一致）
开式技能场景  更小，且经发表偏倚校正后不稳健
```

> ⚠️ **诚实标注**：FPS 是开式技能（对手会反应），所以这些干预在你身上的预期效果要**打折**。这也是为什么我把"压力接种"排在 5.2/5.4 之后。

Cabral 2024（PMID 38376935）给了最直接的做法——**轻度焦虑训练（anxiety training, AT）**：

> 「84 名参与者用 2 天练 300 次高尔夫推杆，一组加入轻度心理压力操纵（AT 组），一组不加。第 3 天全部做后测（无压力 / 轻度压力 / 高压）。**结果：AT 组在三种后测中表现都保持住了，而对照组在压力下表现下降。** 另外，AT 调节了压力下"心理努力"和"运动 reinvestment"的变化。」

落到你的场景，三个可执行的"轻度压力操纵"：

| 做法                             | 强度 | 说明                                                          |
| ------------------------------ | -- | ----------------------------------------------------------- |
| **死斗全程不开枪**（B站 `BV1rcuh6LEvk`） | 低  | 见 5.6，这条同时是"认知重估"训练                                         |
| **录屏，并且事后一定要看**                | 中  | 制造"被观察"的社会评价压力（Baumeister 1984 的 audience-induced pressure） |
| **只给一次机会**                     | 中高 | 每个场景只打 1 轮，打完不许重开，直接记录                                      |

### 5.6 一条特殊的训练：死斗不开枪（认知重估）

B站 `BV1rcuh6LEvk`（o丶b）的方法，我认为是本次调研里"性价比最高"的一个训练：

> 「进死斗，拿把不用大枪，就拿正义。**我们看到人，我们不开枪，我们就一直动。** 动的过程中去瞄他的头。……**你会发现一个什么问题？其实人根本没有那么强，完全没有什么秒的能力。** 等你练多了，你会发现这个问题，**然后你就再也不会紧张了。**」

> 「顶尖高手和普通玩家的区别，**不是他们不紧张，而是他们在紧张的时候，依然能做出正确的技术动作。**」

为什么这个训练有效——它同时做了三件事：

1. **暴露**：反复经历"看到人"这个刺激而不做应激反应 → 条件反射消退
2. **认知重估**：你亲手验证了"对面要 1–3 秒才杀得掉我"，把"我会被秒"这个错误信念推翻了
3. **重建时序**：你被迫在移动中完成瞄准，只有确认在头上才允许自己（在心里）开枪 → 这就是技术 2 的 stop-to-shoot

**执行：每局死斗 5–8 分钟，连续 5 天。判定标准：看到人时的心跳加速消失，或"发现自己有 1 秒以上的余裕"。**

## §6 判定标准（7 天后怎么算成功）

| 指标              | 基线         | 目标                        | 怎么测                         |
| --------------- | ---------- | ------------------------- | --------------------------- |
| **冷启动差距**       | d 中位 −1.05 | 第 1 轮 ≥ 后续均值的 **95%**     | 练枪第 1 轮 vs 第 2–3 轮均值，连续 3 天 |
| **连续交战第 2 场表现** | —          | 第 2 场命中率 ≥ 第 1 场的 **90%** | 录屏，逐场标                      |
| **残局 1v1 命中率**  | —          | ≥ 常规回合命中率的 **85%**        | 录屏，只统计 1v1                  |
| **"松手"执行率**     | 0          | ≥ **70%** 的交战结束后做到        | 每局结束自评（做到了几次 / 共几次）         |
| **练枪时长**        | —          | 进排位前 ≤ **20 min**         | 计时                          |
| **主观**          | "控制不住肌肉"   | 能说出"我现在在第几档张力"            | 每局结束 1 句话                   |

**反向指标（出现就说明方向错了）：**

- 冷启动差距变大 → 你的热身不够，或者练枪时长要再砍
- 第 2 场比第 1 场差更多 → 你的"回填"没做到，或者该减预瞄甩枪的频率
- 分数反而下降但"感觉更稳" → 正常，前 3 天常见（在拆旧动作），第 5 天还不回升再评估

## §7 反面清单（这 6 件事别做）

| ❌ 别做                 | 为什么                                                                                                                                  |
| -------------------- | ------------------------------------------------------------------------------------------------------------------------------------ |
| **"多打排位自然就习惯了"**     | 单纯重复暴露而不改变注意焦点，可能**强化**"看到人就开枪"这个反射。必须配 5.6 的暴露训练（有明确的"不做反应"指令）                                                                      |
| **"放松就好 / 别紧张"**     | "努力放松"是一个内焦点指令。Law & Wong 2021：内焦点 → 更紧、更慢、更不准                                                                                       |
| **"先练到 90 分再打实战"**   | 迁移是"量"的函数（Schoenfeld 2024），但**间隔越长迁移越差**。Void Hunt：连续几周只练枪再回去打游戏"只会招来 rage 和挫败感"                                                     |
| **"打之前先看一遍教学视频"**    | 这会临时增加显性知识。Lee 2019：显性知识越多越容易 choke，且与水平无关。**要看就前一天看**                                                                               |
| **"手抖就是心理素质差"**      | 手抖是肾上腺素 + 肌肉多余能量的正常产物（`BV12p411o7oh`）。它是**生理**，不是**人格**。而且"拉伸缓解肌肉紧张"经常无效——`BV1h94y1v7Th`：「情绪紧张与错误呼吸都有可能让肌肉处于紧张状态」，过度拉伸反而会因为疼痛让肌肉收缩对抗 |
| **"把练枪当主要训练、实战当检验"** | 你的游戏（瓦罗兰特）在转化率阶梯末端。琪露诺：这里"瞄准只占游戏的一小部分"                                                                                               |


## §9 待拍板（5 项）

1. **先改哪一层？** 我的建议：**先改 A（张力预算）**，因为它的证据最直接、见效最快（1.5 秒的松手动作，当天下就能做），而且它能同时改善 T（因为张力低了你才有余量做"瞄→停→打"）。
   - 但如果你打一轮自测 B（点位间甩 20 秒后微调）发现微调依然干净 → 说明你不是 A 型，直接跳到 T。
2. **热身协议要不要写进每日清单的固定段落？** 现在清单是"场景 + 轮数"，没有"热身段 / 主项段 / 收尾段"的时间结构。如果要写，需要改清单模板（会影响 D 清单交接单的格式约束）。
3. **"第 1 轮不进日记/看板"这条要不要落成规则？** 技术上要在 `web/backend` 的统计里把每天每场景的第 1 轮标记出来（类似 `round_stats` 里加个 `is_first_of_day`）。这是代码改动，需要排期。
4. **要不要加一个"实战失误类型"的记录字段？** 现在 `game_reflection` 有 `scenario` 字段但没有"失误类型"（过头 / 落后 / 抢开火 / 决策错）。加了之后才能验证 §8 的那个推论（实战失误像 Q021 还是 Q022）。这是数据模型改动。
5. **死斗不开枪训练要不要做成一个独立清单？** 它不属于现有任何清单（A–G），是一条独立的"抗压训练"。可以放进 D 清单的收尾段，也可以单开一个"压力接种"小清单。

- **PMID 23611248（Joseph 2013）** 的结论是"任务难度与热身衰减的初始水平**成反比**"（越难，WUD 越小）。但我的本地数据显示**越弱/越难的场景冷启动损失越大**（Flower −27.5% / cloverRawControl −16.1%）。方向相反。可能的原因：我测的是"第 1 轮 vs 后续轮"，它混入了**同一天内的学习效应**（不只是热身衰减），而弱项的学习曲线更陡。**所以 §2.1 的 d 值应读作"第 1 轮的总代价"，不纯是 warm-up decrement。**
- **PMID 21807433（Vickers & Lewinski 2012）** 我只读到部分摘要：精英警察射击精度 **74.60% vs 新手 53.80%**；在"要求不开枪（手机）"条件下决策错误——精英 **18.5%** 开枪、新手 **61.5%** 开枪；**而 draw/aim/fire 的时长两组没有差异**。这条的推论是"压力下差的不是动作速度，是判断"，但我没有读到全文的方法细节，标为**中等置信**。
