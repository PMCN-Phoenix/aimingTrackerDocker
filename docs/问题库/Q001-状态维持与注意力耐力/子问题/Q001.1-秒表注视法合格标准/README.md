# Q001.1 秒表注视法合格标准

> 父问题：[Q001 状态维持与注意力耐力](../README.md)

## 问题背景

原调研报告中"秒表注视法"的合格标准是"注意力完全在秒针上没有转移"，这个标准太主观，无法在训练中自检。本问题将其拆解为 5 个可自检、可升阶的阶层。

## 核心思路

把"专注"拆成 3 个可观察维度，每个阶层只叠加一个维度：

1. **视线锁定**——眼睛有没有离开秒针（最容易自检）
2. **思维跟随**——脑子有没有在感知每一次跳动（用报时准不准验证）
3. **抗干扰 / 抗疲劳**——在压力下能不能保持前两层

---

## 五阶升阶体系

### L1 视线锁定（入门）

| 项目 | 内容 |
|---|---|
| **目标时长** | 1 分钟 |
| **训练维度** | 视觉 |
| **合格标准** | 全程视线落在秒针上，结束后能确认"眼睛没离开过表盘" |
| **不合格表现** | 眼睛瞟向别处 / 频繁用力眨眼 / 视线失焦模糊 |
| **升阶条件** | 连续 3 天完成 1 分钟 |

### L2 思维跟随（基础）

| 项目 | 内容 |
|---|---|
| **目标时长** | 2 分钟 |
| **训练维度** | 视觉 + 认知 |
| **合格标准** | 每一次秒针跳动都在心里"感知到"（不是机械数数），结束后闭眼报时误差 ≤ 2 秒 |
| **不合格表现** | ① 数到一半忘了数到几 ② 结束时报时差 >2 秒 ③ 数对了但被突然问"秒针现在指在哪"答不上来（机械数数） |
| **升阶条件** | 连续 3 天完成 2 分钟且报时误差 ≤ 2 秒 |

**L2 关键说明**：练的不是数数能力，是持续感知能力。机械数数可以一边数一边想别的，但"感知每一次跳动"要求大脑真的在跟秒针。报时准不准是客观验证——中间走神了就猜不准。

### L3 无断片持续（中级）

| 项目 | 内容 |
|---|---|
| **目标时长** | 3 分钟 |
| **训练维度** | 视觉 + 认知 + 元认知 |
| **合格标准** | 全程保持元认知觉察——始终"知道自己在注视秒针"。允许短暂无关念头飘过（思维插入），但必须在 1-2 秒内觉察并主动拉回，拉回后计数连续、报时准确 |
| **不合格表现（断片）** | 出现"事后才觉察"的走神——有一段时间完全不知道自己在看什么/数什么，然后突然惊醒"啊我刚才在想什么"。哪怕只有 1 次，这组不算过 |
| **升阶条件** | 连续 3 天完成 3 分钟无断片 |

**思维插入 vs 断片的区分**：

| | 思维插入（合格） | 断片（不合格） |
|---|---|---|
| 发生了什么 | 念头闪过（如"这表长什么样"），当下就觉察到 | 注意力完全离开，进入走神或机械数数 |
| 觉察时机 | **当下觉察**，立刻拉回 | **事后觉察**，过了几秒才惊醒 |
| 计数连续性 | 没断，拉回后接着数，报时仍准 | 断了，可能忘了数到几 |
| 持续时间 | 1-2 秒 | 通常 3 秒以上 |

L3 练的不是"零杂念"，是**元认知灵敏度**——能多快发现走神并拉回。这个能力直接迁移到游戏：状态下滑时能多快觉察并重置。

### L4 抗干扰（高级）

| 项目 | 内容 |
|---|---|
| **目标时长** | 4 分钟 |
| **训练维度** | + 环境抗扰 |
| **合格标准** | 开背景音 / 白噪音 / 人声，仍保持 L3 无断片标准 |
| **不合格表现** | 被声音吸引，视线或思维离开秒针 |
| **升阶条件** | 连续 3 天干扰下完成 4 分钟 |

### L5 疲劳维持（运动员级）

| 项目 | 内容 |
|---|---|
| **目标时长** | 5 分钟 |
| **训练维度** | + 状态抗扰 |
| **合格标准** | 在练枪 / 工作后（注意力已有消耗）完成 5 分钟注视 |
| **不合格表现** | 疲劳状态下明显比清醒时提前走神 |
| **达标条件** | 连续 3 天疲劳下完成 5 分钟 = 原报告运动员标准 |

## 每日训练流程

1. **组数**：3-4 组，组间休息 10-15 秒
2. **每组时长**：用当前阶层的目标时长
3. **不合格就停**：当前阶层没稳，不急于升阶
4. **升阶缓冲**：刚升阶的前 1-2 天，可以先做比目标短 30 秒的时长，适应后再加满

## 记录方法

每组训练后在 [训练记录.csv](训练记录.csv) 中记录：
- 日期
- 当前阶层
- 组号（1-4）
- 结果（合格 / 不合格）
- 不合格时第几秒断了
- 原因（瞟眼 / 走神 / 被干扰 / 眼酸 / 其他）

## 常见问题

**Q：L2 报时误差怎么测？**
A：结束时立刻闭眼，在心里说"刚才过了 X 秒"，然后看秒表实际过了多少秒。误差 ≤2 秒算过。

**Q：L3 的"断片"怎么定义？**
A：就是你突然意识到"我刚才好像没在看秒针"的那个瞬间。出现一次就算这组不合格。

**Q：可以跳级吗？**
A：不建议。L1 是基础，L2 是核心验证，L3 是耐力，L4/L5 是压力测试。跳级会导致基础不牢，后面卡更久。

**Q：每天什么时候练？**
A：建议早上（注意力最清醒时）练 L1-L3，L5 放在练枪后或工作后练。

## L5 之后：秒表注视法已达标，接下来做什么

> **重要说明**：原版秒表注视法（国家体育总局《现役运动员心理指导手册》）到 5 分钟就是终点，没有官方进阶。本文档 L1-L5 是对原版"注意力不转移"标准的细化拆解，L5 之后的方向来自其他有研究支撑的方法，不是秒表注视法本身的延伸。

### 核心结论

5 分钟达标后，**不需要再延长注视时间**。接下来的重点不是"在安静房间里注视更久"，而是"在真实负荷下维持状态"——这才是游戏里需要的能力。

### 维持高水平状态的四大支柱

| 支柱 | 方法 | 来源 | 对你的做法 |
|---|---|---|---|
| **抗干扰能力** | 在噪音/人声/背景音下保持专注 | 国家体育总局手册（原版） | 练枪时开背景音，从低到高逐步适应 |
| **疲劳下认知耐力** | Brain Endurance Training (BET)：身体活动+认知任务同时进行 | RCT 研究：耐力提升 24-32%，职业球员疲劳下技术显著提升 | 练枪后（疲劳时）做 10 分钟：原地慢跑+Stroop/2-back |
| **注意力节奏** | 脉冲式专注（不要全程 100%）+ 活跃眼球 | 电竞研究 + 项目调研报告 | 对枪前 100%，转移时 70%；架枪时在小地图和准星间切换 |
| **恢复与周期** | 局间 30 秒微重置 + 每 90 分钟大休息 + 热身 ≤25 分钟 + 睡眠 7.5-9h | 超昼夜节律研究 + 电竞耐力研究 | 严格执行局间重置和 90 分钟休息 |

### 每日执行方案

| 时间 | 内容 |
|---|---|
| 早上 | 秒表注视 5min × 3 组（维持，不加时）+ 8字形追踪 + 远近焦点切换 |
| 练枪前 | 1 分钟触发词+深呼吸仪式 |
| 练枪中 | 脉冲式专注 + 活跃眼球 + 每 20 分钟 20-20-20 |
| 练枪后（疲劳时） | 10 分钟 BET（身体活动 + Stroop/2-back） |
| 每周 2-3 次 | 抗干扰练枪（开背景音/噪音） |
| 游戏中 | 局间 30 秒微重置 + 每 90 分钟大休息 |

### 关键验证指标

练枪时"状态消退时间"有没有从 10-15 分钟延长到 20-30 分钟。这是检验所有训练有没有迁移效果的客观标准。

### BET 常用认知任务

- **Stroop 测试**：看颜色字（如红色的"蓝"字），说出字的颜色而不是字义
- **2-back**：听/看一串数字/字母，判断当前项是否和往前数第 2 个相同
- **连续减 7**：从 100 开始每次减 7，持续报数
- **Go/No-Go**：看到特定信号才反应，其他信号不反应
