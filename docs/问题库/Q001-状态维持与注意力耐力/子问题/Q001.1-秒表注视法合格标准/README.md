# Q001.1 秒表注视法合格标准

> 父问题：[Q001 状态维持与注意力耐力](../README.md)

## 问题背景

原调研报告中"秒表注视法"的合格标准是"注意力完全在秒针上没有转移"，这个标准太主观，无法在训练中自检。本问题将其拆解为 5 个可自检、可升阶的阶层。

## 核心思路

把"专注"拆成 3 个可观察维度，每个阶层只叠加一个维度：

1. **视线锁定**——眼睛有没有离开秒针（最容易自检）
2. **思维跟随**——脑子有没有在感知每一次跳动（用报时准不准验证）
3. **抗干扰 / 抗疲劳**——在压力下能不能保持前两层

---

## 五阶升阶体系

### L1 视线锁定（入门）

| 项目 | 内容 |
|---|---|
| **目标时长** | 1 分钟 |
| **训练维度** | 视觉 |
| **合格标准** | 全程视线落在秒针上，结束后能确认"眼睛没离开过表盘" |
| **不合格表现** | 眼睛瞟向别处 / 频繁用力眨眼 / 视线失焦模糊 |
| **升阶条件** | 连续 3 天完成 1 分钟 |

### L2 思维跟随（基础）

| 项目 | 内容 |
|---|---|
| **目标时长** | 2 分钟 |
| **训练维度** | 视觉 + 认知 |
| **合格标准** | 每一次秒针跳动都在心里"感知到"（不是机械数数），结束后闭眼报时误差 ≤ 2 秒 |
| **不合格表现** | ① 数到一半忘了数到几 ② 结束时报时差 >2 秒 ③ 数对了但被突然问"秒针现在指在哪"答不上来（机械数数） |
| **升阶条件** | 连续 3 天完成 2 分钟且报时误差 ≤ 2 秒 |

**L2 关键说明**：练的不是数数能力，是持续感知能力。机械数数可以一边数一边想别的，但"感知每一次跳动"要求大脑真的在跟秒针。报时准不准是客观验证——中间走神了就猜不准。

### L3 无断片持续（中级）

| 项目 | 内容 |
|---|---|
| **目标时长** | 3 分钟 |
| **训练维度** | 视觉 + 认知 + 元认知 |
| **合格标准** | 全程没有"断片"——即没有突然意识到"啊我刚才在想什么"的瞬间 |
| **不合格表现** | 出现断片感，哪怕只有 1 次 |
| **升阶条件** | 连续 3 天完成 3 分钟无断片 |

### L4 抗干扰（高级）

| 项目 | 内容 |
|---|---|
| **目标时长** | 4 分钟 |
| **训练维度** | + 环境抗扰 |
| **合格标准** | 开背景音 / 白噪音 / 人声，仍保持 L3 无断片标准 |
| **不合格表现** | 被声音吸引，视线或思维离开秒针 |
| **升阶条件** | 连续 3 天干扰下完成 4 分钟 |

### L5 疲劳维持（运动员级）

| 项目 | 内容 |
|---|---|
| **目标时长** | 5 分钟 |
| **训练维度** | + 状态抗扰 |
| **合格标准** | 在练枪 / 工作后（注意力已有消耗）完成 5 分钟注视 |
| **不合格表现** | 疲劳状态下明显比清醒时提前走神 |
| **达标条件** | 连续 3 天疲劳下完成 5 分钟 = 原报告运动员标准 |

---

## 每日训练流程

1. **组数**：3-4 组，组间休息 10-15 秒
2. **每组时长**：用当前阶层的目标时长
3. **不合格就停**：当前阶层没稳，不急于升阶
4. **升阶缓冲**：刚升阶的前 1-2 天，可以先做比目标短 30 秒的时长，适应后再加满

## 记录方法

每组训练后在 [训练记录.csv](训练记录.csv) 中记录：
- 日期
- 当前阶层
- 组号（1-4）
- 结果（合格 / 不合格）
- 不合格时第几秒断了
- 原因（瞟眼 / 走神 / 被干扰 / 眼酸 / 其他）

## 常见问题

**Q：L2 报时误差怎么测？**
A：结束时立刻闭眼，在心里说"刚才过了 X 秒"，然后看秒表实际过了多少秒。误差 ≤2 秒算过。

**Q：L3 的"断片"怎么定义？**
A：就是你突然意识到"我刚才好像没在看秒针"的那个瞬间。出现一次就算这组不合格。

**Q：可以跳级吗？**
A：不建议。L1 是基础，L2 是核心验证，L3 是耐力，L4/L5 是压力测试。跳级会导致基础不牢，后面卡更久。

**Q：每天什么时候练？**
A：建议早上（注意力最清醒时）练 L1-L3，L5 放在练枪后或工作后练。
