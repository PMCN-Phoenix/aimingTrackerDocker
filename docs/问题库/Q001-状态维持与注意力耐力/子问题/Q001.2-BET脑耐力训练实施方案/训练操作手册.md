# BET 训练精确操作手册

> 配套文档：[BET调研报告-2026-10.md](BET调研报告-2026-10.md)、[README.md](README.md)
> 一句话总结：**原地慢跑的同时做认知任务，每周3次每次15分钟，疲劳时不要停。**

---

## 一、训练前准备（每次训练前 1 分钟确认）

### 1.1 环境
- 找一块 **1 平米** 的空地（能原地踏步就行）
- 穿运动鞋或光脚（不要穿拖鞋，容易滑）
- 手机放在**视线平齐**的位置（做 Stroop/2-back 时要看屏幕）
- 不要在饭后 30 分钟内做（血液在胃里，头晕）

### 1.2 工具
| 阶段 | 需要的工具 | 怎么准备 |
|---|---|---|
| 第1-2周 | 手机秒表 | 打开倒计时 15 分钟 |
| 第3-4周 | 手机/电脑 + Stroop 网页 | 浏览器打开 https://www.psytoolkit.org/experiment-library/stroop.html 或搜"Stroop test online" |
| 第5-8周 | 手机/电脑 + 2-back 网页 | 浏览器打开 https://dual-n-back.com ，选 **single n-back**，n=**2**，刷新间隔 **3000ms** |

### 1.3 身体状态确认
- 如果今天睡眠 < 6 小时 → 训练时长减半（10分钟），不要硬撑
- 如果今天已经练枪/工作超过 3 小时 → 正好，疲劳状态下做 BET 效果更好
- 如果头晕/发烧/身体不适 → 跳过今天

## 二、单次训练精确流程（15 分钟，精确到秒）

```
┌─────────────────────────────────────────────────┐
│ 0:00 - 2:00   热身（2分钟）                      │
│   原地慢跑，速度：能说话但不能唱歌                │
│   不做认知任务，只调整呼吸和节奏                  │
│   呼吸：鼻吸口呼，3步一吸3步一呼                  │
├─────────────────────────────────────────────────┤
│ 2:00 - 12:00  双任务核心（10分钟）               │
│   保持原地慢跑，同时做认知任务                    │
│   ★ 这是训练的核心，身体和脑子必须同时动          │
│   ★ 累了可以放慢脚步，但不要停下来               │
│   ★ 认知任务出错了不要停，继续下一题             │
├─────────────────────────────────────────────────┤
│ 12:00 - 15:00 冷却（3分钟）                     │
│   放慢到原地踏步，逐渐停下                       │
│   回顾刚才：出错了几次？什么时候最累？           │
│   记录到训练记录.csv                             │
└─────────────────────────────────────────────────┘
```

## 三、各阶段认知任务精确操作

### 阶段 1：连续减 7（第 1-2 周）

**精确操作**：
1. 从 **100** 开始，大声喊出数字
2. 每次减 7：100 → 93 → 86 → 79 → 72 → 65 → 58 → 51 → 44 → 37 → 30 → 23 → 16 → 9 → 2
3. 减到 **2** 之后，从 **200** 重新开始
4. 减到 **2** 之后，从 **300** 重新开始
5. 循环往复，直到 10 分钟结束

**判断标准**：
- ✅ **合格**：10 分钟内报错 ≤ 2 次，报数间隔稳定（每次停顿 ≤ 3 秒）
- ❌ **不合格**：报错 > 2 次，或频繁停顿 > 5 秒，或干脆停下来不算了

**常见错误**：
- ❌ 心里默念不出声 → 必须**大声喊出来**，出声本身就是认知负荷的一部分
- ❌ 慢跑变成原地站立 → 脚必须一直在动，哪怕很慢
- ❌ 算错了停下来想 → 错了就跳过，从下一个数继续，不要纠结

**进阶条件**：连续 3 次训练报错 ≤ 2 次 → 进入阶段 2

---

### 阶段 2：Stroop 测试（第 3-4 周）

**精确操作**：
1. 打开 Stroop 测试网页（见 1.2 工具表）
2. 屏幕上会出现**颜色字**，比如：
   - 🔴 蓝色的"红"字 → 正确答案是**蓝**（字的颜色，不是字的意思）
   - 🟢 红色的"绿"字 → 正确答案是**红**
   - 🔵 黄色的"蓝"字 → 正确答案是**黄**
3. 用鼠标点击正确的颜色按钮，或按键盘对应键
4. 连续做 10 分钟，不要停

**判断标准**：
- ✅ **合格**：正确率 ≥ 90%，平均每题反应时间 ≤ 2 秒
- ❌ **不合格**：正确率 < 80%，或频繁停顿超过 3 秒想答案

**常见错误**：
- ❌ 读字的意思而不是看颜色 → 这是 Stroop 的核心难点，刻意训练"抑制本能反应"
- ❌ 慢跑停下来盯着屏幕 → 脚步不能停，屏幕放在视线平齐位置，眼睛看屏幕脚在动
- ❌ 做错了懊恼 → 错了立刻点下一题，不要回看

**进阶条件**：连续 3 次训练正确率 ≥ 90% → 进入阶段 3

---

### 阶段 3：2-back 工作记忆（第 5-8 周）

**精确操作**：
1. 打开 https://dual-n-back.com
2. 设置：**Single N-Back**（不是 dual），N = **2**，刷新间隔 = **3000ms**
3. 屏幕每隔 3 秒出现一个字母（或位置）
4. 你要判断：**当前出现的，和 2 次之前出现的，是不是一样？**
5. 一样 → 按 **A** 键（或点"Match"），不一样 → 不按（或点"No Match"）

**举例**：
```
顺序:  第1个  第2个  第3个  第4个  第5个  第6个
字母:   C      A      C      T      A      K
判断:   -      -    是✓    否    是✓    否
```
- 第 3 个 C，和往前数第 2 个（第 1 个 C）一样 → 按"是"
- 第 4 个 T，和往前数第 2 个（第 2 个 A）不一样 → 不按
- 第 5 个 A，和往前数第 2 个（第 3 个 C）不一样 → 不按
- 第 6 个 K，和往前数第 2 个（第 4 个 T）不一样 → 不按

**判断标准**：
- ✅ **合格**：正确率 ≥ 80%（2-back 比 Stroop 难，80% 就够了），能做满 10 分钟
- ❌ **不合格**：正确率 < 60%，或做到一半脑子一片空白跟不上

**常见错误**：
- ❌ 记成 1-back（和上一个比）→ 必须是**往前数第 2 个**，在心里默念"当前是第N个，N-2是X"
- ❌ 慢跑停下来 → 脚必须一直在动，这是 BET 的核心
- ❌ 刷新间隔调太快 → 起步 3000ms，不要急于调到 2500ms

**进阶条件**：连续 3 次训练正确率 ≥ 80% 且做满 10 分钟 → 可以尝试刷新间隔调到 2500ms，或 n=3

---

### 阶段 4：维持期（第 9 周以后）

- 每周 **2 次**（不是 3 次），每次 15 分钟
- Stroop 和 2-back **交替**做（这周 Stroop，下周 2-back）
- 目标是**保持**，不再加量
- 如果感觉退步了（正确率明显下降），回到阶段 3 重新练 2 周

## 四、每周安排（精确到星期几）

```
周一: ─── 休息 ───
周二: BET 训练（15分钟）
周三: ─── 休息 ───
周四: BET 训练（15分钟）
周五: ─── 休息 ───
周六: BET 训练（15分钟）
周日: ─── 休息 / 补觉 ───
```

**关键规则**：
- 两次训练之间**至少间隔 1 天**（给大脑恢复时间）
- 训练时间固定在**练枪/工作结束后立刻做**（利用已有的疲劳状态，效果最好）
- 如果某天错过了，**不要补**，按原计划下一次做就行

## 五、怎么记录（每次训练后 1 分钟）

打开 [训练记录.csv](训练记录.csv)，填这几列：

| 列名 | 填什么 | 例子 |
|---|---|---|
| 日期 | 当天日期 | 2026-10-13 |
| 阶段 | 当前在哪个阶段 | 连续减7 / Stroop / 2-back / 维持期 |
| 时长（分钟） | 实际做了多久 | 15 |
| 正确率 | Stroop/2-back 填，连续减7填"-" | 85% |
| 报错次数 | 连续减7填，其他填"-" | 1 |
| 训练前疲劳度 | 1-10分，10是最累 | 7 |
| 备注 | 任何异常感受 | 今天慢跑时右腿有点酸 |

**每月底看一次趋势**：
- 正确率是不是在上升？
- 报错次数是不是在下降？
- 训练前疲劳度高的时候，表现是不是比以前好了？（这是 BET 的核心效果）

## 六、效果验证（8 周后怎么知道有用）

### 客观测试（每 2 周测一次）
找一个需要专注的任务（比如写 30 分钟报告、或打一局排位），记录：
- **状态消退时间**：第几分钟开始感觉"脑子转不动"、注意力飘走？
- 基线（训练前）：通常 10-15 分钟
- 8 周后目标：20-30 分钟

### 主观感受
- 长时间工作后"脑子糊了"的感觉是不是减轻了？
- 疲劳时做决策，是不是比以前更不容易出错？
- 切换任务后，是不是更快能进入状态？

### 如果 8 周后没效果
检查这几点：
1. ❌ 是不是做成了"先慢跑10分钟，再做认知任务10分钟"？→ 必须**同时**做
2. ❌ 是不是慢跑强度太低（几乎在走路）？→ 加到"能说话但不能唱歌"
3. ❌ 是不是每周只做了 1-2 次？→ 必须保证 3 次
4. ❌ 是不是认知任务太简单（一直在连续减7没进阶）？→ 按进阶条件推进
