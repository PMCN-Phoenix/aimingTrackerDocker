# Q001 状态维持与注意力耐力

## 问题概述

练枪/游戏时高质量专注只能维持 5-15 分钟，之后状态明显下滑。需要通过系统训练延长注意力耐力，并迁移到真实游戏场景。

**核心矛盾**：注意力不是"意志力"，是可训练的生理能力（前额叶持续专注 + 眼肌耐力），需要渐进超负荷。
