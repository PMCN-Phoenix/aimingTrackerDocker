# Q006 - 移动中瞄准定位（Valorant无畏契约）

> **用户问题**：新手节奏是"先停→再瞄→再开枪"，如何进化到"边移边瞄、停即开枪"
> **调研日期**：2026-10-13
> **父问题**：Q004-场景技术问题 / Q005-对局复盘与实战迁移

---

## 一句话结论

> **你不是瞄得慢，你是把"瞄准"这个动作放在了"停住"之后。把它挪到"移动"期间去做，停住只是开枪的扳机。**

## 核心要点

1. **80ms定律**：Vandal全速→可精确射击只需80ms，远短于瞄准时间，所以瞄准必须在减速过程中完成（Dannew热图分析）
2. **动作链**：大flick落角 → pre-aim在头侧 → 减速惯性带准星过头 → 80ms内micro-adjust → 停稳即开火
3. **用移动代替手瞄**：差一点没对齐时挪步子，不要纯用手腕小挪（vlad?的overaim drill教训）
4. **眼锁敌人、余光准星**：视觉焦点放错是打不中移动靶的首要原因
5. **终极形态：Dead Zone/摇摆急停**：抓AD切换瞬间0.2秒准度窗口开枪，全程不完全停死
6. **不要开枪太快**：大多数人输对枪是因为"准星还没到头上就开枪"，不是瞄不准
