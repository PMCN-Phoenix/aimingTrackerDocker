# Q020 晚间精力耗竭与训练时机

## 30 秒结论

- **晚间锻炼**：基本能练。中低强度睡前 1h 结束、高强度睡前 2h 结束即不干扰睡眠（Stutz 2019/2021 meta；Nat Commun 2025 只有"高 strain"才干扰）。
- **晚间练枪**：能练但要降级。心理疲劳伤当天表现、不伤学习（Q016 已证）；用 5 分钟探针代替感觉决定练多久。
- **你自己的数据**：傍晚 17-21 是个人最佳时段（+2.6%），深夜持平，**清晨最差（-7.5%）**——"晚上涣散练不了"在你身上不成立。
- "意志力耗尽"理论已被多实验室预注册复现否定 → 晚上不想练是动机问题，可绕过（降低启动成本/换内容），不是"没油"。
