# Q019 练枪与健身训练周期耦合

> 立档：2026-10-19 ｜ 触发语："练枪和健身应该是怎样的训练周期？在原型的基础上，他们两个有什么互相的影响？是不是放在同一天更合适？"

## 问题概述

用户同时执行两套训练体系：

- **练枪**：VDIM 6 天主题轮转（动态/静态/平滑/反应/速度转火/移动）+ `Viscose基准 DayN` 清单 + `Viscose基准 DayN` 执行记录，每天约 1 小时（Q018 已拆为 15 热身 + 30 专项 + 15 迁移）
- **健身**：推拉蹲「推容量 / 拉容量 / 蹲容量 / 力量+弱点」四日微周期，每 2 个 mesocycle（约 32 天）重测 PR

要回答三件事：① 两套周期分别该长什么样；② 它们互相怎么影响；③ 是否应该排在同一天。

**核心结论（30 秒版）**：

1. 4 日 × 7 日的最小公倍数是 **28 天**，两套周期不该每天对齐，应按 **4 周共同块**排、块末双测
2. **同日更好，顺序 = 有氧 → 练枪 → 抗阻**，缓冲 30 分钟；练枪永远拿"新鲜的手"
3. 四色分级：**拉日红**（最大冲击，禁静态点击）／**力量日黄**／**推日黄**／**蹲日绿**（可排最难精度专项）
4. 影响不对称：健身→练枪"急性拖累 + 慢性抬升上限"；练枪→健身只有久坐姿态与前臂过用
5. 健身不能替代练枪：抬地板与续航，不抬天花板
