# Q005 对局复盘与实战迁移

> 核心问题：复盘无畏契约对局时，怎么描述才能既准确（不模糊、不自我欺骗）又舒适（有操作性、不是自我攻击）？
> 调研日期：2026-10-12
> 关联：[Q003 VDIM进步方法论](../Q003-VDIM进步方法论/)（benchmark与实战脱节、target reading）、[Q004 场景技术问题](../Q004-场景技术问题/)（具体技术问题诊断）

---

## 一、核心结论：好的复盘描述 = 事实 + 诊断 + 行动，三段缺一不可

### 1.1 坏描述 vs 好描述

| 坏描述（模糊/自我欺骗） | 好描述（准确/可操作） |
|---|---|
| "我这波马枪了" | "第3回合A大，我预瞄在头线偏右5cm，敌人从左侧peek时我手腕甩过头2cm，第二发才命中，原因是转火时眼睛没先移到目标" |
| "我走位不好" | "第5回合防守B点，我站在箱子右侧露出了全身位，被两个敌人同时架到，应该站箱子左侧只露半个头" |
| "我这波没打过" | "第7回合1v1残局，我先开枪但没打头，敌人急停反杀我，原因是我移动中开枪命中率只有30%" |
| "队友太菜了" | "第9回合我单独前压A小，没有等队友同步，被3人包夹——这是我的决策问题，不是队友的" |
| "我状态不好" | "第12回合开始我连续3次先死，回看发现都是同一个错误：peek时没有先丢技能获取信息" |

**关键区别**：坏描述是**评价**（马枪/菜/状态差），好描述是**事实+原因+改进**。

## 二、三段式描述模板（Cause → Mistake → Fix）

这是 ALVIRAN 提出的最简洁复盘格式，每个死亡/失误都按这个写：

```
【回合】第X回合
【事实(Cause)】发生了什么——时间、地点、人物、动作
【错误(Mistake)】我重复犯的决策/技术错误是什么
【修正(Fix)】下一局我具体要改变的一个动作
```

### 2.1 完整例子

```
【回合】第3回合（进攻方，A点）
【事实】我持Vandal从A大peek，预瞄在箱子右上角，敌人捷风从箱子左侧
       拉出，我甩枪到目标时偏右约3cm，开了2枪都没中，被反杀。
【错误】①预瞄位置错误——应该预瞄箱子左边缘（敌人最可能拉出的位置），
       而不是右边缘；②甩枪时眼睛没先移到目标，手先动了。
【修正】下一局A大peek前，预瞄固定在箱子左边缘头线高度；甩枪时
       默念"眼先到手后到"。
```

### 2.2 为什么这个格式"舒适"

- **事实层**：只描述发生了什么，不评价自己——不会产生"我好菜"的情绪
- **错误层**：定位到**可重复的模式**，不是"这一次运气差"——你会发现80%的死亡来自3-4个重复错误
- **修正层**：只写**一个具体动作**，不是"我要变强"——下一局能立刻执行

## 三、"真实问题"识别表（BoostRoom 方法论）

很多人复盘时会把真正的问题归错因。用这张表快速定位：

| 表面现象 | 你以为的原因 | 真正的原因（大概率） |
|---|---|---|
| 一直先死 | "我马枪" | **spacing（站位间距）+ impatience（急躁）**——peek太早、离队友太远 |
| 技能"没用" | "我技能放得不准" | **timing（时机）+ lack of go cues（没有推进信号）**——技能放了但队友没跟上 |
| 输 post-plant | "我守不住" | **role assignment（角色分工）+ time discipline（时间管理）**——谁守哪、什么时候退没规划 |
| 输 retake | "我打不进去" | **trickle peeking（逐个送）+ no isolation（没孤立敌人）**——一个一个上被逐个击杀 |
| 对枪输了 | "我瞄准不行" | **crosshair placement（预瞄）+ movement（移动）**——80%的对枪输在预瞄不对，不是手速 |
| 残局输了 | "我紧张" | **information processing（信息处理）**——没数技能、没算时间、没听脚步 |

> **核心原则**：先怀疑决策和站位，最后才怀疑瞄准。瞄准问题在练枪软件里解决，复盘主要解决决策问题。

## 四、DOR 三问框架（每个交火都问）

复盘时每个交火片段，问自己这三个问题：

### 问题 1：交战开始时，我和队友手上有哪些技能可用？
- 我有没有把技能用在这个交火里？
- 如果技能留着没用就死了——为什么不用？是不知道该用，还是舍不得？
- 队友的技能有没有和我配合？

### 问题 2：我倒下时，队友是否在能补枪（Trade）的位置？
- 反过来：队友倒下时，我是否在能补枪的位置？
- 如果不在——是我站位太靠前/太靠后，还是沟通问题？
- **Valorant 的核心是 trade（补枪），不是 1v1 对枪。**

### 问题 3：我的选择与该回合的目标（安放/拆除炸弹）如何关联？
- 我这波前压/守点/转点，是在为安放/拆除创造条件，还是在无意义消耗？
- 如果这波打赢了，对回合目标有什么帮助？如果打输了，损失有多大？

## 五、20 分钟快速复盘流程（实操版）

不需要看完整局，20分钟足够：

```
0:00-3:00   选对局：选一局 K/D 接近 1.0 的（不要选 25-8 或 6-18 的）
3:00-8:00   看手枪局 + 第3、第8回合（经济转折点）
8:00-15:00  只看自己的死亡片段，每个死亡看前8秒
15:00-18:00 用三段式模板写 3-5 条最重复的错误
18:00-20:00 挑1条最容易改的，写进下一局的"专注点"
```

### 5.1 死亡前 8 秒法（抖音高赞方法）

每次死亡，**倒带回看死亡前 8 秒**，问：
1. 8秒前我在什么位置？
2. 我掌握了什么信息？（敌人位置、技能、经济）
3. 我做了什么决策导致走到这个死亡位置？
4. 当时有没有其他选择？

> 8秒是经验值——大部分死亡的种子在8秒前就种下了（站位、决策、信息处理），不是最后1秒的对枪问题。

### 5.2 怎么和练枪数据关联

复盘发现的技术问题，对应到 VDIM 训练：

| 复盘发现的问题 | 对应 VDIM 训练日 | 对应练枪场景 |
|---|---|---|
| 预瞄不准、peek 头线不对 | 周二 静态点击 | 1wall 6targets、Wide Wall |
| 甩枪过头/不到位 | 周一 动态点击 | Pasu、Bounce 180 |
| 跟枪跟不上移动目标 | 周三 平滑跟枪 | Smoothbot、PGTI |
| 目标变向反应慢 | 周四 反应跟枪 | Midrange Short Strafes、VSS GP9 |
| 转火慢、多目标处理差 | 周五 速度转火 | Target Switching、voxTargetSwitch |
| 移动中打不准 | 周六 移动瞄准 | Dodge、Strafe Tracking |

## 六、常见的"自我欺骗式描述"及修正

| 自我欺骗 | 修正为 |
|---|---|
| "这波是运气差" | "这波我预瞄偏了3cm，如果预瞄正确就能一枪头——这是技术问题，不是运气" |
| "我已经尽力了" | "我这波 peek 时没有用技能获取信息，如果先闪再 peek 结果可能不同——我可以做得更好" |
| "这个敌人是挂" | "这个敌人的预瞄和身法确实很好，但我站的位置露出了全身位，如果只露头他更难打中我" |
| "队友不跟我" | "我前压时没有给队友信号，也没有等队友到位——这是沟通和时机问题" |
| "我今天状态不好" | "我今天连续3次犯同一个错误：peek时不预瞄——这是习惯问题，和状态无关" |

**核心原则**：把"外部归因"（运气/队友/状态/挂）改成"内部可改"（预瞄/站位/时机/决策）。不是自责，是**拿回控制权**——只有认为自己能改，才会真的去改。

## 七、复盘记录模板

每次复盘后，把结果存成这样（可以写进 journal.md 或单独的复盘文件）：

```markdown
## 复盘记录 2026-10-12

**对局**：竞技模式，Ascent，进攻方，13-11 胜
**K/D**：14/12/4

### 重复错误 Top 3

1. **A大peek预瞄偏右**（出现3次）
   - 事实：预瞄在箱子右边缘，敌人从左拉出时甩枪距离多了5cm
   - 修正：下一局A大预瞄固定在左边缘头线

2. **单独前压不等队友**（出现2次）
   - 事实：第5、第9回合单独前压A小，被包夹
   - 修正：前压前先打信号，等队友到位再同步

3. **残局不数技能**（出现1次）
   - 事实：1v2残局不知道敌人还有没有闪，硬peek被闪
   - 修正：残局先在心里列敌人已用技能清单

### 下一局专注点
> 只选1个：A大peek预瞄左边缘
```

## 十、待拍板项

1. **复盘记录存在哪？** 建议和练枪感悟分开，存 `docs/问题库/Q005-对局复盘与实战迁移/复盘记录/` 按日期命名
2. **复盘频率？** 建议每周1-2次，每次20分钟，不要每局都复盘（会 burnout）
3. **是否需要和 VDIM 数据自动关联？** 目前手动对应即可，后续可以在前端加"复盘发现→训练日"的映射
