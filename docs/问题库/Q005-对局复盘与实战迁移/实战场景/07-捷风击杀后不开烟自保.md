## 一、问题本质：这不是技术问题，是"角色脚本"问题

你描述的"杀人之后有危险，却意识不到要开烟自保"，**本质上不是"不会开烟"，而是你的大脑在击杀后进入了"一突脚本"——继续找下一个目标，而不是评估自身安全。**

| 层 | 问题 | 表现 |
|---|---|---|
| **角色脚本层** | 一突=进攻角色，大脑默认"杀完继续冲" | 击杀后准星立刻移向下一个可能出现敌人的位置，完全没想起自己有烟 |
| **工具认知层** | Cloudburst被当作"进点工具"，不是"自保工具" | 烟都用在进点时封视野，击杀后手里没烟或没想到用 |
| **时间感知层** | 击杀后0.5秒后摇期是最脆弱窗口 | 敌人补枪就在这个窗口，你还在看击杀确认 |
| **经济心理层** | "2.5秒烟太短，开了也没用" | 低估了2.5秒足够换位/换弹/急停 |

> "Jett's smoke is a personal tool, not a team smoke. The standard use is throwing one at the base of an entry point... save at least one for a reactive escape rather than burning both on entry." —— Hotspawn Jett Guide

## 二、为什么"击杀后开烟"是Jett最被低估的习惯

### 2.1 通用搜索一致结论

多个英文指南明确指出这一点：

> "Get into the habit of placing a smoke in front of you after killing an enemy to escape from other enemies and surprise them." —— Jett Valorant Guide (webflow PDF)

> "If you had just [killed someone] on the A site, but the enemies have already rotated over... your position has been exposed and you could easily be killed. To add complexity, you can throw a smoke down to cover off enemy vision, giving you more options to reposition." —— Immortalboost Jett Guide

> "Cloudburst's short duration is intentional: it's a personal tool... save at least one for a reactive escape rather than burning both on entry." —— Hotspawn

### 2.2 击杀后的"脆弱窗口"

击杀敌人后，你有三个叠加的脆弱因素：

1. **开枪后摇**：最后一发子弹到准星回正有约0.3-0.5秒
2. **位置暴露**：枪声+击杀确认告诉所有敌人你在哪
3. **注意力转移**：大脑在处理"我杀了一个"的反馈，还没切换到"我现在安全吗"

**敌人的补枪窗口就是这0.5-1.5秒。** 一颗2.5秒的烟，刚好覆盖这个窗口+你换位的时间。

### 2.3 2.5秒到底够干什么

| 动作 | 耗时 |
|---|---|
| 急停+换位到掩体后 | 0.8-1.2秒 |
| 换弹（Vandal/Phantom） | 2.0-2.5秒 |
| 开Tailwind dash到安全位置 | 0.5秒（前摇0.75+冲刺0.45） |
| 从包点退到入口 | 1.5-2.0秒 |

**2.5秒足够完成以上任何一个动作。** 说"烟太短没用"是错觉——你不需要烟持续到回合结束，你只需要它持续到你脱离危险。

## 三、"击杀后开烟"的具体场景与操作

### 3.1 场景A：进点击杀第一个人后

**最常见的场景。** 你dash进点，打掉一个架枪的，此时：
- 包点里可能还有第二个人
- 回防的人已经在听枪声
- 你的位置完全暴露

**操作**：
```
击杀第一个人 → 立刻往脚下/身前丢一颗瞬云 → 同时移动到包点内掩体后
→ 烟散前判断：第二个人在哪？队友进点了吗？
→ 如果安全：继续清点击杀
→ 如果不安全：用Tailwind dash退出，等队友
```

**关键**：烟不是用来"继续杀人"的，是用来"打断敌人的补枪节奏"的。敌人看到烟，第一反应是停火/后退/换位置，这1-2秒就是你的生存窗口。

### 3.2 场景B：对枪赢了但位置极差

你在一个开阔位置和人对枪赢了，但：
- 周围没有掩体
- 至少还有一个敌人知道你在这
- 你的Tailwind可能已经用了

**操作**：
```
击杀 → 立刻往敌人来的方向丢烟（封他的视线）
→ 往反方向移动 → 找最近的掩体
→ 不要站在原地换弹！移动中换弹
```

### 3.3 场景C：一打多杀了第一个

**最需要开烟的场景。** 1v2/1v3时杀了第一个：
- 第二个人一定在补枪的路上
- 你不能站在原地

**操作**：
```
击杀第一个 → 脚下丢烟 → 立刻移动（不要停！）
→ 用烟遮挡第一个人的尸体方向（第二个人会从那边看过来）
→ 移动到第二个敌人的侧面/背身 → 急停击杀
→ 重复：杀第二个→丢烟→移动
```

> "一打多的情况就是不能慌...精准的一次定位和拆分多次1v1很重要" —— 7ommy_（B站33万播放，897赞评论）

### 3.4 场景D：狙完一枪没杀死人

**Jett Operator的经典场景。** 你开了一枪没中/没杀：
- 大狙后摇1.5秒，你完全无法还击
- 敌人会立刻反打

**操作**：
```
狙完 → 立刻丢烟（朝敌人方向）→ 同时Tailwind dash回掩体
→ 不要等看到敌人才动！狙完的瞬间就动
```

> "狙完一枪没带死了，那怎么办？可以狙完以后点烟。" —— 杨弗莱夫捷风保姆级教学

### 3.5 场景E：大招空了/用完后

Blade Storm用完后有超长切枪后摇：
```
大招结束 → 丢烟 → 利用烟的2.5秒完成切枪 → 移动到安全位置
```

> "当你大招用完没有击杀人时，一个超长的切枪动作会要了你的命，但如果结束后丢烟雾弹就能更快的掏出枪反击。" —— B站高赞技巧总结

## 四、怎么培养"击杀后开烟"的意识

### 4.1 核心方法：把开烟绑定到"击杀确认"上

**不要想"我要不要开烟"，要建立条件反射：看到击杀确认→按C。**

就像你开车看到红灯→踩刹车，不需要思考。训练方法：

| 阶段 | 训练内容 | 目标 |
|---|---|---|
| **阶段1（死斗）** | 每次击杀后**强制**按C丢烟，不管有没有危险 | 建立"击杀→C"的肌肉记忆，100次击杀 |
| **阶段2（死斗）** | 击杀后丢烟+立刻移动，不站原地 | 建立"击杀→C→移动"的完整链条，50次 |
| **阶段3（排位）** | 进点击杀后必须丢烟，其他场景可选 | 在真实对局中固化习惯，连续5局 |
| **阶段4（排位）** | 所有击杀后评估：危险→丢烟，安全→不丢 | 精准判断，不浪费烟 |

**阶段1是最关键的。** 哪怕你觉得"这位置很安全不用烟"，也强制丢——目的是建立反射，不是省烟。

### 4.2 击杀后三问（默念）

每次击杀后，在心里快速过一遍：

```
1. 我在哪？（位置是否暴露/是否有掩体）
2. 谁能看到我？（还有几个敌人？大概在哪个方向？）
3. 我有没有烟？（C技能还有几颗？）
```

如果答案是"位置暴露+有人能看到我+有烟"→**立刻丢烟**。

这三问只需要0.3秒，但能把你的大脑从"一突脚本"切换到"生存脚本"。

### 4.3 Cloudburst预算管理

**硬规则：每回合至少留1颗烟给reactive escape。**

| 回合阶段 | 烟的用途 | 预算 |
|---|---|---|
| 进点前 | 封视野/单向烟 | 最多1颗 |
| 进点中 | 击杀后自保 | 1颗（必须留） |
| post-plant | 守包/拖时间 | 剩余的 |

> "Because Jett does NOT reset Cloudburst, managing the two charges across a round matters: save at least one for a reactive escape rather than burning both on entry." —— Hotspawn

**常见错误**：进点时把两颗烟都用了（封A小+封警家），然后击杀后手里没烟，被补枪死。

**修正**：进点只用1颗烟封最关键的角度，另一颗留着击杀后用。队友的烟位会封其他角度。

### 4.4 绑定到Tailwind的使用逻辑

Jett的E（Tailwind）和C（Cloudburst）应该配合使用：

```
进攻时：E dash进点 → 杀人 → C烟自保 → 评估是否继续
撤退时：C烟封视线 → E dash撤退 → 安全后换弹
```

**不要E和C分开用。** 很多人E进点杀人，然后E用完了，C也用完了，变成一个没有位移的普通角色站在包点中间——这就是"进点两颗烟被混死"的原因。

| **保命烟/突脸烟** | 被补枪/换弹/后摇 | **朝脚下/身前瞬发丢烟，争取2.5秒** |

## 八、反面意见/争议点

### 争议1：烟应该留着进点还是用来自保

- **进点派**：Jett的烟是进点工具，两颗都应该用在进点封视野
- **自保派**：至少留1颗给击杀后自保，进点靠队友的烟
- **务实结论**：看阵容。如果队里有烟位（Omen/Brimstone/Viper），Jett的烟主要来自保；如果队里没烟位，Jett需要兼顾进点和自保，但仍然建议留1颗

### 争议2：击杀后应该立刻换位还是先找第二个人

- **换位派**：击杀后立刻移动，避免被补枪
- **续杀派**：击杀后立刻找第二个人，趁敌人没反应过来
- **务实结论**：取决于人数。1v1时击杀后可以继续找人；1v2+时必须先换位再找第二个。烟是换位的掩护

### 争议3：2.5秒烟够不够用

- **不够派**：2.5秒太短，刚移动完烟就散了
- **够用派**：2.5秒足够急停+换位+换弹，不需要更长
- **务实结论**：2.5秒的设计意图就是"个人应急"，不是"团队封视野"。你需要的就是这2.5秒的窗口，不是持续封锁

### 争议4：Jett应该激进还是保守

- **激进派**（Ak1noT，70赞）：自信猛攻，抓timing
- **保守派**：击杀后必保，活着才有输出
- **务实结论**：进点前激进（敢冲），击杀后保守（必保）。这是"自信但不鲁莽"的真正含义
