## 一、结论先行

**回防不是"冲回包点"，而是"把四角度压缩成两角度，再同步进点trade"。90%的回防失败不是枪法问题，是三个结构性错误：①一个一个送（Trickling）②盲目进点（No info）③同时打整个包点（No isolation）。**

| 步骤 | 做什么 | 关键动作 |
|---|---|---|
| **1. Regroup 集结** | 停止掉人，等队友到齐 | 不要单独peek"看看情况"；不能1-2秒内trade就别peek |
| **2. Information 拿信息** | 确认至少一个敌人位置 | 信息工具/安全jiggle/听声音；一个确认位置就把盲回防变成计划回防 |
| **3. Isolation 隔离** | 烟/墙/震把4角度变2角度 | 封最强角度、切长道、隔离高点、逼敌人打近距离可trade的战斗 |
| **4. Entry 同步进点** | 倒计时一起拉，trade优先 | "3-2-1 swing"；第一个人是为了创造可trade的战斗不是为了1v多 |
| **5. Defuse 分工拆包** | 一人拆+一人护近+一清角+一看侧翼 | 拆包赢在有保护，不是赢在快 |

## 二、回防失败的三个根因（BoostRoom）

### 2.1 Trickling（一个一个送）
- 玩家一个接一个peek，进攻方打五场独立1v1轻松赢
- **修复**：永远不要单独进。如果你不能在1-2秒内被trade，你不是在回防，你是在送人头

### 2.2 No information（盲目回防）
- 不知道post-plant玩家站哪，清错角度，被最危险的那个杀掉
- **修复**：硬commit前用一个信息工具或安全jiggle拿信息

### 2.3 No isolation（不隔离角度）
- 试图同时打整个包点——四个角度、两个高低差、多个交叉火力
- **修复**：用烟/墙/震把"四个角度"变成"两个角度"，然后一个切片一个切片回防

> 来源：BoostRoom Retake Guide

## 三、清角优先级（最容易错的地方）

**规则：Clear close danger first, swing threat second, defuse denial third.**

| 优先级 | 清什么 | 为什么 |
|---|---|---|
| **1. 杀你进点的角度** | 能阻止你第一步进包点的位置 | 不先清/隔离它，进点就死 |
| **2. 阻止拆包的角度** | 能看到Spike并瞬间惩罚拆包者的位置 | 不清除它，拆包就是假的 |
| **3. 高点位** | 天堂/二楼/高台，制造交叉火力 | 烟掉或先清，否则被迫同时清多个角度 |
| **4. 点外交叉火力位** | 敌人常玩off-site避免被清 | commit拆包前确认他们在哪 |
| **5. 晚夹击路线** | 侧翼/回防连接道，敌人可能夹击你 | 留一人看 |

**常见错误**：准星甩到最远的危险角度，结果被没人检查的近角杀掉。

## 四、Trade Spacing（回防最重要的机械技能）

回防是trade战斗，**间距比瞄准更重要**。

### 好的trade spacing
- 你离得足够近，能在1-2秒内swing补枪
- 你不站在同一条线上（一个扫射不会同时杀两个）
- 你们错开站位，看到角度的不同部分

### 坏的trade spacing
- 一个人peek时另一个还在跑
- 两个人堆同一个角落，被一个闪或一个扫射双杀
- 人"在附近"但因为墙/高低差实际上无法trade

**铁律：如果你不能trade它，就不要peek它。**

## 五、两波回防法（比一波冲更稳）

很多队一波冲、死两个人、然后没计划了。更好的结构是两波：

### Wave 1：拿立足点
- 用烟隔离
- 用闪/震清第一个角落
- 全队进点
- **拿到一个切片后停住**，不要冲太深

### Wave 2：转化为拆包窗口
- 用剩余道具deny阻止拆包的角度
- 协调tap时的swing
- 一起清最后一个角落
- 有保护地拆包

> 这解决了天梯常见问题：进太深太快→被交叉火力→回防瞬间崩盘。

## 六、B站核心补充

### 6.1 防守轮转：回防从掉人那一刻就开始了（银河Jett BV1P94y1E7AA）

**两个概念：地图区域控制 + 防守轮转**

- 对方打掉点内玩家→占据高点控制权→如果决斗者继续前冲占控制室→回防的人过来就被偷死
- **防守轮转=动态防守**：掉一人后多次补防完成，遵循**就近原则**
- 例子：A包点的人死了→A2楼的人补防到警家位置→中路的人补A2楼→另一侧包夹的人补中路
- 这样即使对手占了整个A包点，你保住了警家+控制室+A2楼，可以**从两个方向夹击包点**，大幅降低回防难度
- 单排时开麦沟通："我去补防包点，离你近的队友补我的位置"

### 6.2 警家回防预瞄：不要贴左墙peek（大东彦 BV1yvE36XEpy）

**核心技巧**：
- 回防警家口子时，**不要贴左墙peek**——这样出去时地速不够，对面预瞄好直接架死
- 正确做法：在远点peek一波→然后**贴右墙**→给自己留足从右到左的加速空间→拉满地速→横拉出去
- 在对面视角里，你就是一个"泥头车撞出来"，架不住
- 长直斜道（如C点车库回防）同理：贴右墙到近点→拉满地速→横拉包点
- **例外**：多打少（5打2）且对面已被警家队友勾完时，可以慢蹭

### 6.3 绕后心理学：有哨位就大大方方绕（JOJO BV15c411t7gc）

- 对面还有存活哨位（奇乐/保安/钱包）时，你决定绕后，**他一定知道你会绕后**，不会大方跟你对枪，而是等陷阱/小鸡响了再回头
- 所以**不用畏畏缩缩静步摸**，大大方方跑过去绕后，**先打掉陷阱**让他"屁股一凉"
- 哨位已死或没有哨位时，长途回防（A到B）多留意中路有没有听脚步干摸的敌人，甚至可以假装大脚步然后回头架他
- 非哨位进攻玩家通常没耐心死架屁股，会主动出击反绕，可以利用这个心理

### 6.4 哨位回防道具：用陷阱拿信息而非杀人（大东彦 BV1j84RzvEpn）

- 高分段玩哨位，不要想着用道具杀人（"求求你来Rush我的点吧"）
- **用陷阱类技能拿信息为主**：前置放置小鸡/兰博，给自己更大反应空间
- 例子：莲花古城C点，兰博放深处而非口子，开局前点旋转跳拿信息，发现没人就直接去补CB点
- 一个前置小鸡可以解放整个C场——对面只要没来人，你就可以永远不管C点
- 后置道具会让你"一辈子被负数在C点"，因为你不知道对面什么动静

### 6.5 道具交换：守不住时的思路转换（职业教练 BV1kjrUYDE4F）

- 前点挂单向烟→直架烟→对面交闪/飞机时→补一颗侧面烟阻隔枪线→把飞机打掉
- 这颗侧面烟的意义：让进攻方不能用几个小道具就控下A大，要Rush还得交道具清酒窖
- 守不住时思考反清：前点单向烟+TP酒窖藏死+推黑+解体拉枪，或机器人雷+闪的反清小套餐

## 七、按角色分工（回防时各做什么）

| 角色 | 回防职责 |
|---|---|
| **决斗** | 第一个进有争议的空间，trade在身后；拿到空间后停住让队涌入；不要单人英雄swing |
| **先锋** | 拿信息减少猜测；用闪/震创造全队"go moment"；道具分层：第一个进点用，第二个留着拆包压力用 |
| **烟位** | 隔离最强进攻角度；创造安全进点通道；为拆包时机封烟保护拆包者 |
| **哨位** | 控制侧翼和回防道，防止被夹击；清除/禁用阻挡进点的敌方陷阱；稳定回防防止敌人绕后 |

**规则**：回防成功是因为每个角色做好一件事，不是因为每个人都在打随机决斗。

## 八、应对不同Post-Plant风格

| 敌方风格 | 应对 |
|---|---|
| **点内交叉火力** | 用烟隔离一个交叉火力角度，闪/震另一个，先清近角，交叉火力没破前不拆包 |
| **点外架枪** | 不要盲目追点外玩家；封掉阻止拆包的视线；tap逼他们从远处peek；只清阻挡拆包窗口的近点外位 |
| **重拖延道具** | 不要冲进伤害区；等第一波道具结束再用第二波回防；至少留一个闪/震给拆包时刻 |

**规则**：不要打他们的强项。烟掉它、隔离它、或逼它移动。

## 九、可操作清单（进游戏直接用）

### 回防前
- [ ] 停止掉人，等队友到齐（Regroup）
- [ ] 拿一个信息：敌人在哪？在点内还是点外？有没有侧翼？
- [ ] 分配角色：谁进点、谁拆包、谁看侧翼

### 进点时
- [ ] 烟掉最强角度（不是最吵的角度）
- [ ] 倒计时"3-2-1"一起swing
- [ ] 第一个人创造可trade的战斗，不是1v多
- [ ] 清角顺序：近角→阻止拆包的角度→高点→点外→侧翼

### 拆包时
- [ ] 一人拆、一人护近、一人清最后角落、一人看侧翼
- [ ] tap逼敌人反应，不要直接硬拆
- [ ] 留一个烟/闪给拆包时刻

### 回防练习（3个drill）
1. **No-solo rule**：10场比赛里，永远不要第一个单独回防，等至少一个队友再swing
2. **Countdown entry**：每次回防说"swing in 3"，即使没人回应你也会自然同步更好
3. **Isolation before ego**：进点前问"哪个角度杀拆包者？"每次先烟掉或清掉它
