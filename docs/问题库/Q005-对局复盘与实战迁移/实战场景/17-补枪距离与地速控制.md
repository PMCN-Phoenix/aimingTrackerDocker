# 场景17：补枪距离与地速控制——锁定位置后队友前推，我该保持什么距离、怎么拉地速

> 调研日期：2026-10-14
> 渠道：通用搜索（BoostRoom peeking/movement guide）+ B站（204视频去重→精选20→20字幕40678字1921评论）
> 用户具体场景："对面漏过枪声了，然后已经锁定位置，队友往前推的时候，我是不是应该保持一定的距离，拉地速来进行补枪"

---

## 一、结论先行

**是的，但要精确到三个参数：**

| 参数 | 正确做法 | 错误做法 |
|---|---|---|
| **距离** | 1-2秒跟进距离：close enough to trade instantly, far enough not to die to one spray | 肩并肩站一起（一个扫射双杀）/ 站队友正后方（挡视线+被串烧） |
| **地速** | wide swing前预留加速空间，拉出掩体时地速已拉满；急停后burst | 地速从零开始涨（像bot）/ 移动中开枪（不准） |
| **时机** | 队友**接触敌人的瞬间**swing，不是队友开始推的时候 | 队友死了才动（太慢）/ 队友还没接触就先拉（变成solo duel） |

**一句话**：你站在队友侧后方1-2秒距离，队友一开枪你就地速拉满大拉出去，急停后burst补枪。

## 二、Trade Spacing——补枪距离的精确标准（BoostRoom）

### Good Spacing vs Bad Spacing

```
❌ Bad: 肩并肩 / 正后方
   你和队友 → 一个spray杀两个 / 一个闪瞎两个 / 挡彼此移动

✅ Good: 错开角度，1-2秒距离
   队友死了 → 你能立刻swing补枪
   你和队友 → 不会被同一扫射/技能双杀
   两人都能 → swing同一个角度
```

**核心原则**：
- "You want to be close enough to trade, but not stacked."
- 你的队友死了，你能swing instantly——但你们不会被同一个spray或ability同时杀掉
- 不要站队友正后方：你会挡住他的移动，他也会挡住你的视线

### 站位的具体选择

| 站位 | 效果 | 适用场景 |
|---|---|---|
| **侧后方45度** | 不挡视线，能同时看同一个角度 | 最通用的补枪位 |
| **平行错开** | 两人同时swing不同角度，防守方二选一 | 已知敌人单守一个角度 |
| **稍远但同线** | 避免被AOE双杀，但补枪稍慢 | 对面有奥丁/大招清场 |

## 三、Swing Together——两个人一起拉比单独peek赢更多（BoostRoom）

**"Two players swinging together wins more rounds than any solo peek."**

### 为什么有效
- 如果同时swing，防守方**不能快速杀掉两个**
- 如果队友死了你犹豫，**trade就没了**
- 防守方必须在两个目标间二选一，无论打哪个，另一个都能补枪

### 正确的Swing Together操作
1. **Call the swing**：喊"swing now"/"go"/"321"
2. **Both commit at the same moment**：同时拉，不要一个早一个晚
3. **Both aim at the same likely target angle first**：先打同一个预瞄点
4. **如果一个早一个晚=两个solo duel，不是trade**

> "If one player swings early and the other swings late, it becomes two solo duels instead of a trade."

### 你的场景（锁定位置+队友前推）
- 队友往前推=他是entry，你是trade
- **队友接触敌人的瞬间=你swing的信号**（参考场景15）
- 不要等队友死了才动——那时候对面已经reset了
- 不要队友还没接触就先拉——你变成solo peek

## 四、拉地速——让对面架不住你的核心技术（B站大东彦+糯玉米）

### 拉地速的本质
> "利用速度优势让对面难以反应。很多人拉出去就死，不是因为对面有多准，而是因为你每次预瞄的身位速度都太慢，在对面眼里就是一个缓慢移动的靶子。"

### 核心原理：1.5身位法则（糯玉米 BV1DHeM6fEJM）
- 静音状态下速度极限=**1.5个身位**（靶场三块半砖的距离）
- 每次分段预瞄移动1.5身位=不漏脚步+最大移动效率
- **但**：连续1.5往外搜点时，由于近大远小，下一个枪位已经提前看到你的移动轨迹
- **正确做法**：每次向外移动1.5身位，**再回拉一个身位**
  - 打乱对方预判
  - 保证面对下一个枪位时**重新拥有加速空间**
- "1.5出去一回来"练成肌肉记忆

### 大东彦的回拉预留加速空间（BV1EthLzMEKw / BV1BSh5zPE2d）
> "你每一波都是地速从零开始往上涨的，你像bot。一般应该回拉一下再横拉，然后再回拉一下——给你的下一段peek预留加速空间。"

**错误模式**：
```
搜点A → 地速0→max→0（停住）→ 搜点B → 地速0→max→0
         ↑ 两次加速减速之间如果站了人，你就是靶子
```

**正确模式**：
```
搜点A → 回拉一下（预留加速）→ 横拉搜点B（地速已拉满）→ 回拉 → 横拉搜点C
         ↑ 每次切下一个角时速度都能拉起来
```

### 什么时候适用
- 从左到右有很长一段距离要排（亚海A点、B通口切二道）
- 连续搜多个角度时
- **你的补枪swing也适用**：swing前先回拉一下，保证拉出去时地速满

## 五、贴墙大拉——角速度优势（大东彦 BV1RezPYCESM / BV1x5hi6tEGJ）

### 原理
> "线速度一定时，角速度与半径成反比。离敌人更近时，相同时间内在敌人视角下移动的角度更大=更不容易被架住。"

- 近大远小不是唯一准则
- 当你已经处在近大远小劣势枪位时，**不如贴近掩体换取更大的角速度**
- 贴墙大拉+较高角速度=配合预瞄，敌人很难架住

### 贴墙大拉的关键细节
1. **预留充足横拉空间**：把地速拉起来，保证拉出掩体前速度已完全拉满
2. **反向出旋转门时**：门转开前往门中段挤=给向左大拉留足加速空间
3. **位置不明确时**：广角晃身锁位置→流畅接贴墙大拉
4. **准星没有确认感时**：不要提前急停，继续往外拉直到瞄准好再停下来开枪
5. **预瞄偏差大时**：移动幅度变大，为自己争取二次微调+开枪机会

> "就算你第一枪没打中头，你继续往外拉，他也很难直接秒杀你，会给你第二枪的机会。"

## 六、Wide Swing完整技术链（BoostRoom）

```
Pre-aim → Swing → Stop → Burst → Reset
  ↓         ↓       ↓      ↓       ↓
准星放头高  地速拉满  急停   控制burst  没中就回cover
           大拉出去  变精准  不spray   或reposition
```

**Stop-Shoot节奏**（BoostRoom movement guide）：
- Strafe → Stop (tiny) → Burst → Strafe → Stop → Burst
- 不是：Strafe → spray while moving
- 不是：Stand still → spray forever
- 停止时间：中距离2-4发，长距离1-2发(tap)，近距离才controlled spray

## 七、你的场景完整操作流程

**场景**：对面漏过枪声→已锁定位置→队友往前推→你补枪

### 步骤1：站位（推之前）
- 站队友**侧后方1-2秒距离**，不要正后方
- 确认你和队友不会被同一扫射双杀
- 预瞄敌人可能出现的头线位置

### 步骤2：队友前推时
- **不要提前动**，等队友接触敌人
- 盯小地图/听枪声，队友枪口火光一亮=信号
- 如果你有技能（闪/烟），考虑在队友接触瞬间丢出

### 步骤3：补枪swing（队友接触瞬间）
- **先回拉一下**预留加速空间（如果空间允许）
- **地速拉满**大拉出去（wide swing）
- 预瞄头线，拉出掩体时速度已满
- **急停**→burst（2-4发），不要移动中开枪

### 步骤4：如果队友已经死了
- 立刻swing（不要犹豫，犹豫=trade没了）
- 打对面reset timing（他刚杀完你队友，准星可能还在队友身上）
- 如果对面已经架好你=不要硬上，保活等下一个机会

### 步骤5：如果补枪成功
- 不要追人，确认点内安全
- 报点："补掉一个，还有几个"
- 继续推进或守包

## 八、可操作训练清单

### 靶场训练（每天5分钟）
- [ ] **1.5身位横移**：靶场找三块半砖距离，反复横移，摆射开枪，控制在1.5身位不漏脚步
- [ ] **回拉-横拉节奏**：搜点A→回拉→横拉搜点B→回拉→横拉搜点C，保证每次横拉地速满
- [ ] **Wide swing burst**：Pre-aim→wide swing→stop→burst(2-4发)→reset，重复
- [ ] **Deadzoning**：strafe→release key→instant burst→strafe again，练急停开枪时机

### 实战训练（10局排位计划，来自BoostRoom）
| 局数 | 专注点 |
|---|---|
| 1-2 | No solo wide swings——wide swing只在有队友trade时 |
| 3-4 | Info first——每回合先jiggle拿信息再commit |
| 5-6 | Stop re-peeking——被看到后换timing/位置再peek |
| 7-8 | Utility before commitment——wide swing前先用道具 |
| 9-10 | Trade-focused——主任务是补枪，队友打就帮，队友死就trade |

**追踪一个数据**：你死了但**没有机会被trade**的次数。降低这个数=胜率上升。
