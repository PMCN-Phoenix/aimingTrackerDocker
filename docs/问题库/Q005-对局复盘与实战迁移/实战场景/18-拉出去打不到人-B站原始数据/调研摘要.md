## 二、核心结论（按根因分组）

### 根因1：拉出时地速没拉满——你是"半加速靶子"，不是"大拉"
- 瓦的移动有加速过程，peek 任何角度都要追求峰值速度；"大拉时被秒的首因"是没预留加速距离、地速没拉满，尤其**不要背靠着墙拉**（碰障碍物骤减速）。〔BV12DevesEtF 1:07–1:15〕
- 大东彦：新手每个角度都"地速从零涨→涨满→跌回零→再涨"，两个加速减速之间站人就是靶子；解法是**peek 完回拉一下再横拉，给下一段留加速空间**。〔BV1EthLzMEKw 0:29–1:23〕
- 静步 peek / 开镜 peek = 慢性自杀：移速太慢，对面视角里"像乌龟爬"，必被架死；新手对 shift 的"虚假安全感"必须克服。〔BV16exyeUEEy 1:55–2:21；BV1fd4y1R7kd 1:26–1:47〕
- peek 只用 A/D 横移，不要按 W 斜着出——斜出去又呆又慢。〔BV16exyeUEEy 12:24–12:43〕

### 根因2：与掩体的距离站位尴尬——"不远不近"最容易死
- 离掩体远 = 近大远小不劣势但角速度慢；贴墙 = 速度快但近大远小劣势；**最尴尬是不远不近，两种优势都没占满**。〔BV1EthLzMEKw 3:04–3:50〕
- 劣势枪位要打杀人 peek：先蹭/晃把对面准星"骗"到贴墙（让他离开缓冲距离），再贴墙大拉——对面准星已没有提前量。〔BV16exyeUEEy 6:03–6:54〕
- 大拉必须靠近掩体再拉：贴墙大拉时对面在你视角里横向移动距离大、角速度快，对面架枪难度反而上升。〔BV1P73G6zE1E 9:00–9:54〕
- re-peek 不能从与上次相同距离拉出去——会撞对面预瞄；要先 shift 走近贴墙换身位换速度。〔BV1EthLzMEKw 6:03–6:50〕

### 根因3：心理紧张→开枪太急→泼水马枪（"拉出去就麻了"）
- 大东彦直接点破：贴墙大拉出去"麻了"= **开枪太着急**。因为知道近大远小劣势、太怕死，就追求快点开枪，一急就泼水，子弹不知道飞哪去。对大拉自信的人会完整经历瞄准过程再开枪。〔BV1EthLzMEKw 4:39–5:12〕
- 均势枪位 peek 被反杀，大多数时候是"你马了"——前两枪空了又开始摆射；peek 千万不要着急开枪。〔BV16exyeUEEy 7:07–7:34 / 8:25–8:32〕
- 确定对面位置的 peek 是"绝对专注"的进攻方，对面架久了会走神——peeker 天然有优势，你慌是多余的。〔BV16exyeUEEy 7:52–8:28〕

### 根因4：拉出后准星/预瞄没跟到位——头线与掩体边缘
- 预瞄的本质 = 让敌人主动撞上你的准星；**提前式预瞄要在掩体后就把准星对到常规位头线**，拉出只是"让准星撞头"，不是拉出去再找头。〔BV1tq4y1A7yA 0:25–0:55〕
- 拉出去那一刻"预瞄没跟到"是常态（一边加速一边找头），所以要靠回拉留速 + 拉出过程中完成瞄准、停稳再开枪。〔BV1EthLzMEKw 5:50–6:00；BV1P73G6zE1E 5:43–6:07〕
- 架枪方视角反向验证：斜角架 vs 直架——直架时你要横移鼠标覆盖的距离大、容错低；对面搜点会先预瞄你常规位，你斜角/非常规站位刚好不在他预瞄点上。〔BV1P73G6zE1E 0:39–2:31〕

### 根因5：第一枪空了之后怎么办——不是泼水也不是蹲射
- 第一枪没中：不要蹲下泼水、不要凭感觉抖枪；要**读对面头与自己准星的相对速度和位置，再做一次冷静的"先瞄准再开枪"**；第二次瞄准的同时必须开始横移，移动距离取决于你二次瞄准有多快——瞄得越快走位越短。〔BV14SkuYSELX 0:58–2:34〕
- 刻意练摆射(ADAD)会拉长对枪时间、降低击杀效率；高效枪是"调整一次移动+瞄准就击杀"。〔BV14SkuYSELX 2:42–2:59〕

### 根因6：动态定位——子弹总落在"敌人移动前的位置"
- 马在动态目标上的两个原因：①视觉失焦——眼睛没锁住移动中的目标就捕不到"静止窗口"，只能靠感觉甩；②**发力太小**——手的定位有滞后，眼睛看到窗口一瞬间手没到位，目标又挪了。〔BV1eehiz9EEc 0:18–0:56〕
- 眼睛/手关系：视觉焦点**始终只看目标身上**，手自然无意识跟上，不能用眼睛去"确认准星重合"。〔BV1eehiz9EEc 2:36–3:06〕

## 三、反面意见（与主流"先瞄准再开枪"不同）

- **电坤小子（57万播放）反对死等"准星完全放头上再开枪"**：专注瞄头再开火，敌人根本不给你窗口——你瞄好时已经被打死，或开枪时人已离开视野；顶分/职业是**边开枪边微调**。练枪软件练出的"看准星确认重合"习惯是坑（他铂金段因此卡了一个月）。确认过程越长误差越大，要用"屏幕中心感"代替眼睛确认重合。〔BV1Q6PmeREP6 0:21–0:35 / 3:17–3:31 / 4:57–5:00 / 10:55–11:15〕
- 与 BV14SkuYSELX（暗辰の薄明，50万）形成对照：暗辰主张"第一枪后要冷静地重新先瞄准再开枪"；电坤主张"第一枪就要早开、开枪本身就是微调起点"。两者折中：**预瞄到位时直接开枪（电坤）；预瞄没到位、第一枪空了之后，按暗辰说的重新冷静读位再打第二枪**。
