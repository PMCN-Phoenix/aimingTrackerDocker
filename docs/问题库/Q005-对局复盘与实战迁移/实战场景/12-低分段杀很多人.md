你的目标：把把稳定20杀
核心公式：击杀数 = 机械胜率 × 接战频率 × 存活时间
         = (你比对面枪准) × (你主动找人杀) × (你杀完不死)

## 二、三层杀人方法论

### 第一层：机械压制——让你对枪胜率 > 70%

**这是基础。你对枪赢不了，后面全白搭。**

#### 1.1 不跑打，急停开枪（最基础但最多人做不到）

- **跑打弹道完全随机**，低分段90%的人还在跑打
- **急停方法**：①松手急停（看到人瞬间松开移动键）②AO急停（往右移动时轻点A，往左移动时轻点D）
- **练习**：靶场侧面100bot，看见bot快速拉枪急停开枪，打中继续下一个

#### 1.2 预瞄头线——减少瞄准距离

- **低分段大多数人瞄太低**（身体/腿部），导致TTK变长
- **预瞄 = 准星始终放在敌人头应该出现的位置**，不是地面或墙壁
- **练习**：自定义跑图，每个常见角度预瞄头线，形成肌肉记忆
- **记3个常用点位的预瞄线**：不用记全图，就记你常玩英雄的守点/进点预瞄位，每天10分钟，一周对枪胜率涨20%

#### 1.3 先开枪再瞄准——比对手快0.2秒

**B站发现**（BV15dEF66EDf，白银到黄金教学）：
> "在一次定位相同水平的情况下，先开枪再瞄准的速度一定比先瞄准再开枪快，快意味着你有更多反应时间！"

- **错误**：先把准星移到头上 → 再开枪（慢）
- **正确**：看到人 → 开枪的同时拉枪到头上（快0.2秒）
- **练习**：靶场侧面100bot，看见bot快速拉枪开枪，打中继续，打不中快速微调

#### 1.4 点射/二连点射——找到自己的开枪节奏

**B站发现**（BV1konPzpEjc，黄金到铂金教学）：
> "原因就是没有找到自己的开枪节奏，所以就要学习点射和二连点射，以此为基础才能找到属于自己的开枪节奏，而不是照抄职业和高分路人的开枪节奏。"

- **暴徒（Vandal）**：远距离开镜单点击杀，中距离2-3连发
- **幻影（Phantom）**：两连发+泼水，近距离直接泼
- **练习**：靶场先一发一发点，熟悉爆头感觉；再两发两发，熟悉两连发；最后尝试121或212节奏

#### 1.5 你的机械优势（VDIM训练基础）

你已经在做VDIM训练（动态点击/静态点击/平滑跟枪/反应跟枪/速度转火/移动瞄准），**机械能力已经超出低分段平均水平**。你的瓶颈不在机械，而在下面两层。

---

### 第二层：信息差利用——让你总是先发现敌人

**低分段最大的信息差来源：敌人不搜点、不看小地图、不听声音。**

#### 2.1 积极游走抢高台（低分段杀人效率最高的打法）

**NGA核心发现**：
> "积极的游走，积极的抢高台就能打的很舒服了，因为基本上没啥人来高台。"

- **高台 = 信息优势 + 射击优势**：你在高处能看到更多，敌人在低处难打到你
- **低分段没人来高台**：大多数人只走常规路线，高台是空的
- **游走 = 不在一个地方等死**：杀完一个立刻换位置，敌人来报仇时你已经在另一个角度了

#### 2.2 用道具创造击杀机会

- **闪光+冲**：闪白敌人后立刻拉出去，低分段敌人被闪后不会转身，就是活靶子
- **烟雾分割**：用烟把敌人队伍拆开，逐个击杀
- **技能先手**：雷兹爆破包贴脸骗闪避再炸；壹决Q技能打中4秒技能全黑+伤害×2

**B站发现**（BV1oUt6ezE9Q，决斗干货）：
> "等道具闪光一爆，先预瞄开光位出去，没人就继续推进。沟通和协同到底有多重要，想上超凡神话不只需要一个好的枪法，决斗者与道具位的沟通协同更为重要。"

#### 2.3 声音信息 = 免费的人头

- **低分段敌人静步意识差**：你能听到他们的位置，他们听不到你
- **听到脚步 → 预瞄那个角度 → 等他出来 → 先开枪**
- **听到换弹/切枪 → 立刻拉出去**：敌人在换弹时0战斗力

### 第三层：选位优势——让你总是在优势位置对枪

#### 3.1 Entry and live（进点击杀后活着）

**Boosteria决斗位carry指南**：
> "Entry and live is a higher-rank habit than 'entry and die.' Conversions win games: stop feeding after first blood."

- **错误**：进点杀一个 → 继续追第二个 → 被第三个打死（entry and die）
- **正确**：进点杀一个 → 退到掩体后 → 等队友补枪 → 再杀第二个（entry and live）
- **活着 = 更多击杀机会**：你死了就0击杀，活着还能继续杀

#### 3.2 选决斗位主动创造击杀

| 英雄 | 杀人方式 | 适合段位 |
|---|---|---|
| **Jett（捷风）** | 精准击杀+安全撤离，Updraft+Tailwind创造击杀角度 | 全段位 |
| **Raze（雷兹）** | 爆破包清空间+爆炸节奏，Satchel跳创造意外角度 | Silver+ |
| **Neon（霓虹）** |  timing压力+近距离控制，高移速主动找人 | Bronze+ |
| **Reyna（雷娜）** | 击杀后回血+隐身，低分段out-aim专用 | Iron/Bronze |
| **Phoenix（菲尼克斯）** | 自带复活容错率，适合新手练枪 | Iron/Bronze |

**B站高赞**（434赞，BV1dyp1zbEFh）：
> "决斗是找着人杀，越杀越有手感，越有手感越杀，非常来劲。"

#### 3.3 不单独前压，但要主动拿信息

**游民星空发现**：
> "低分段有个很常见的问题，总觉得开局必须杀一个，必须拿首杀，必须打出优势，于是开局直接拉出去找人对枪，赢了很爽，输了直接坐牢。尤其是在防守方，很多时候你活着的价值远远大于一个人头，你可以拖时间，可以补枪，可以给信息，可以帮助队友回防。"

- **不单独前压**：没有队友补枪时，前压=送人头
- **但要主动拿信息**：用技能/小身位peek获取敌人位置，然后选择优势位置对枪

## 三、"把把稳定20杀"具体执行方案

### 3.1 每回合杀人流程（可固化）

```
回合开始 → ①选优势位置（高台/非常规位）
         → ②用道具/声音获取信息（敌人在哪）
         → ③预瞄头线等敌人出现
         → ④先开枪再瞄准，急停点射
         → ⑤杀一个 → 退掩体 → 等补枪 → 再杀下一个
         → ⑥回合结束前换位置，不要在同一个地方等死
```

### 3.2 每日训练（15分钟，不增加额外负担）

| 时间 | 内容 | 目的 |
|---|---|---|
| 5分钟 | 靶场侧面100bot（先开枪再瞄准+急停） | 机械手感 |
| 5分钟 | 自定义跑图预瞄3个常用点位 | 预瞄头线 |
| 5分钟 | Deathmatch（只打头，不泼水） | 实战应用 |

### 3.3 10场Ranked追踪计划

| 追踪项 | 目标 | 为什么 |
|---|---|---|
| 场均击杀 | ≥15 → 逐步到20 | 核心指标 |
| 首杀率 | ≥30% | 主动创造击杀 |
| 进点后存活率 | ≥50% | Entry and live |
| 跑打次数 | ≤3次/局 | 机械基础 |
| 高台/非常规位击杀 | ≥5次/局 | 选位优势 |
| 被偷背身次数 | ≤2次/局 | 信息差利用 |

## 四、反面意见与争议

1. **"低分段纯靠枪法，意识不重要"**：Iron/Bronze确实如此，但Silver以上开始需要意识。NGA说"钻石以下枪法大差不差，意识大于枪法"——两个观点不矛盾，关键是你的枪法是否已经超出当前分段
2. **"选决斗位就能carry"**：决斗位给你创造击杀的工具，但不会用道具+不沟通的决斗位就是送人头。BV1oUt6ezE9Q明确说"靶场定位乱杀实战却倒数"的原因是沟通协同
3. **"积极游走=乱逛"**：游走要有目的（拿信息/抢高台/绕后），不是无目的乱跑。无目的乱跑=送人头
4. **"炸鱼就能杀很多"**：炸鱼是降维打击，但你在自己的分段需要的是系统性提升，不是靠段位差。炸鱼爽但不提升自己
5. **"铂金以下不需要补枪"**：BV1rNHp69Eja明确说"卡在铂金90%的原因是爆弹和补枪没做好"——铂金开始补枪重要性急剧上升

## 五、与你的VDIM训练的结合

你已经有VDIM训练基础，机械能力是你的优势。**低分段杀人的瓶颈不在机械，而在：**

1. **接战频率不够**：你在等敌人来，而不是主动找人杀。解决：选决斗位+积极游走+抢高台
2. **存活时间太短**：杀一个就死。解决：Entry and live，杀完退掩体等补枪
3. **信息差利用不足**：你有机械但没利用低分段敌人的信息差。解决：听声音预瞄+用道具创造击杀+非常规位

**VDIM训练继续做（保持机械优势），但排位时重点练上面三点。**

---

## 六、一句话总结

> **低分段杀很多人 = 机械压制（你已有VDIM基础）× 信息差利用（听声音+道具+游走抢高台）× 存活时间（Entry and live，杀完不退就是送）。Iron/Bronze纯靠out-aim，Silver/Gold加预瞄和急停，Platinum加选位和信息。你的瓶颈不在机械，在"主动找人杀"和"杀完不死"——选决斗位、抢高台、用道具创造击杀角度、杀一个退掩体等补枪，把接战频率和存活时间同时拉上去，20杀是自然结果。**
