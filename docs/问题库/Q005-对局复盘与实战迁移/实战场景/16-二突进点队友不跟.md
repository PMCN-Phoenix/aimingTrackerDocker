# 场景16：二突进点队友不跟——一突进了我跟着进，其他三个半天不来

> 调研日期：2026-10-14
> 渠道：通用搜索（NGA团队进点理解）+ B站（209视频去重→精选20→20字幕37670字1269评论）+ YouTube（搜索进行中）
> 用户具体场景："我二突，一突进点了我跟着进了过了半天其他三个才进，黄花菜都凉了"

---

## 一、结论先行

**二突不是"一突进了你就必须跟"。二突的跟是有条件的：道具到位+节奏同步。如果烟位/信息位的道具还没给，一突就不该进，你也不该跟。你跟着进了=2打5，等其他三个来时你已经死了。**

| 你的角色 | 该做什么 | 不该做什么 |
|---|---|---|
| **进点前** | 开麦确认"烟给了吗？闪准备好了吗？" | 一突进了你条件反射就跟 |
| **一突进点时** | 保持1-2秒距离，观察道具是否同步到位 | 无脑冲进点，和一突一起吃交叉火力 |
| **进点后队友没跟** | 躲点内死角保活，等队友进来再展开 | 硬对枪/追人/试图1v多 |
| **道具位磨蹭时** | 喊"等一下，烟还没给"，控制节奏 | 沉默着跟一突送 |
| **单排现实** | 该卖就卖，保活比补枪更重要 | 为了补枪把自己也搭进去 |

---

## 二、团队进点的正确流程（NGA团队进点理解）

**进点不是一突一个人的事，是一个环环相扣的链条：**

```
软先锋探测信息 → 烟位分割战场 → 硬先锋道具协同/闪光干扰 → 一突进点 → 下包占据有利位置 → 守包
```

**每一步都是下一步的前提。** 如果软先锋没探测、烟位没分割、硬先锋没给闪，一突进点就是"盲扎"——谁也不知道面临的是侧身还是三个枪口。

> "一突用位移技能直接进点，本质上和软先锋的信息没有区别——只是他身体进去拿信息，而无人机不能开枪，一突可以。除非万不得已，否则不建议一突无信息位移进点。"

**对你（二突）的意义**：如果前面三步没做，一突进点就是去拿信息的（大概率会死），你跟进去就是第二个去拿信息的。你应该等道具到位再进。

## 三、一突的真正价值——不是杀人，是拉开枪线（BV1c3KT66EGK）

**这是理解二突职责的关键：**

> "一突最大的价值并非冲进点内杀人，而是利用快速位移迫使防守方从只需看守一个入口，变成必须同时兼顾前后。"

**当一突成功近点并存活到队友跟上时：**
1. 防守方必须二选一：打一突，还是打他后面的队友
2. 这两个目标之间的对枪角度往往**大于90度**
3. 无论防守方打哪一方，**另一方都能迅速补枪**
4. 这本质上是一次**小范围前后包夹**——"与其说队友帮一突补枪，不如说是在相互补枪"

**一突的存活是这套配合成立的前提。** 如果一突进点就死，或者你（二突）跟进去也死了，这套包夹就不存在了。

> "有一种胜利叫撤退，有一种失败叫占领。"——如果近点前没夺下足够地图控制权，进攻方冲点消耗了大量技能，防守方回防路线反而更多。

## 四、闷头进点不如静音接触（BV1VWGdztE1c 莉莉丝复盘）

**直接回答你的场景：队友为什么不进？**

复盘案例：一突飞进点，队友全在B大林不进来。
- "是他们不想补枪吗？一是有单向烟，二是门口半线，斯凯都进不了——**换我也不愿意进**。"
- "打提速没有交流，不提前说什么技能清什么点，这是最大的问题。"
- "你往近点箱子飞，队友就算给你补枪，也很可能被斯凯抓到侧身。"

**核心教训**：
1. 队友不进点往往不是"不想"，而是"进不来"——单向烟/半线/陷阱挡住了
2. **进点前必须交流**：什么技能清什么点，谁先谁后
3. 二突跟着一突飞近点箱子→队友补枪时被侧身抓→你和一突都死

## 五、二突的职责定位（少年阿泰 BV1aX4y1C7US + 抖音定位图）

| 位置 | 核心职责 | 进点时机 |
|---|---|---|
| **一突** | 主打前压突破，位移进点拿首杀/拉枪线 | 道具到位后第一个进 |
| **二突** | 贴身跟进，双架补枪，全程跟紧突破位 | **一突接触敌人的瞬间**，不是一突进点的瞬间 |
| **先锋** | 探点拿信息，和哨位分开站位，及时报点 | 进点前给信息道具 |
| **烟位** | 封包点烟，分割战场，支援rush | 进点前给烟，慢一拍进 |
| **哨位** | 单防一个点，控制前压欲望 | 最后进/断后 |

**二突的关键区别**：
- 你不是第一个进点的人（那是一突）
- 你也不是最后进的人（那是烟位/哨位）
- 你是**一突和敌人交火的瞬间**补枪的人
- 如果一突进点时道具没到位，你应该**等一拍**，而不是立刻跟

## 六、道具位为什么磨蹭——以及你怎么引导他们（BV1eQCNYREYZ + BV1RZeY63ERo）

### 道具位的困境
- "FPS共性：你不能闪光和枪同时捏着——你到底是更多心思花在拿闪光服务队友，还是拿枪队友死了补枪？"
- 道具位交流必须有，不然队友根本不知道你放没放技能
- 常见问题：瑞纳不打眼，幽影不推黑，明知道双架人能不给道具，持续干拉白送

### 你（二突/一突）怎么引导
1. **进点前明确索要道具**："瑞纳给个前点眼，幽影推个黑，我数321进"
2. **告诉道具位你要飞哪**："我飞铁板，给个闪"
3. **如果道具没给，不要进**：喊"等一下，眼还没给"
4. **玩一突要知道飞这里的目的**：是拿信息？是拉枪线？是清特定位置？不同目的需要不同道具配合

> "能进点的捷风，都会向队友索要道具！"（BV1Gx421S7Si）

## 七、公式化进点犹如画地为牢（BV1w8CgYjE3u 登神长阶）

**进攻分三阶段，不要跳过：**

| 阶段 | 做什么 | 二突该干嘛 |
|---|---|---|
| **屏障阶段** | 落位，处理前点枪位（A小/中路/前点站位） | 跟队伍一起控图，不要急着进 |
| **前点铺垫阶段** | 队友道具排查前点，夺取地图控制权 | 观察道具是否到位，准备跟进 |
| **近点阶段** | 一突位移进点，二突补枪 | **这才是你该跟的时候** |

**近点阶段不要迷信公式化位置**：
- "不仅可以往这上面E，你也可以往马路中间E，还可以点个烟直接走进来"
- 根据敌人位置调整进点路线，而不是按教学视频公式走

## 八、到了前点不要直接拉（BV1KBpb6JEwx 莲花古城进攻篇）

**直接对应你的场景：**

> "你到了碎石这里，如果直接拉出去会面临什么？瑞纳在AB连、铁臂在门口、甚至于霓虹/捷风在近点——你拉出去面临三个枪线，而你的队友全部都被困在后面，他们帮你补不上枪。"

**这就是你说的"黄花菜都凉了"的本质**：
- 一突和你（二突）到了前点/进了点
- 但队友被烟/闪/地形困在后面，补不上枪
- 你们2个人面对3-5个枪线
- 等队友能进来时，你们已经死了

**解法**：到前点后**先停住**，等队友道具清掉枪线、等队友跟上来，再一起拉。不要到了就直接冲。

## 九、可操作清单（进游戏直接用）

### 进点前（最关键）
- [ ] 开麦确认："烟给了吗？闪/眼准备好了吗？"
- [ ] 如果道具没到位→喊"等一下"，**不要进**
- [ ] 告诉队友你要进哪个位置，需要什么道具
- [ ] 确认谁带包，包在谁身上

### 一突进点时
- [ ] 保持1-2秒距离，不要和一突重叠
- [ ] 盯小地图，看一突是否接触敌人
- [ ] **一突开枪/交火的瞬间**=你补枪的信号（参考场景15）
- [ ] 如果一突进点时道具明显没到位→**停住保活**，不要跟

### 进点后队友没跟
- [ ] 躲点内死角/烟后，不要硬对枪
- [ ] 报点："点内一个，我在死角，快进来"
- [ ] 不要追人/不要试图1v多
- [ ] 如果一突已经死了→你就是一突了，更要保活等队友

### 单排心态
- [ ] 队友道具不到位是常态，不是你的错
- [ ] 该卖就卖——保活比补枪更重要
- [ ] "对队友最大的信任是一突义无反顾的进点。对队友最大的失望是一突脱离团队单摸。"——但你是二突，你可以等
- [ ] 连续几回合队友不跟→考虑换打法（静音接触/单摸/转点）
