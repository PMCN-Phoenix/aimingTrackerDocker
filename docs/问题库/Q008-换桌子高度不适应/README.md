# Q008 换了桌子高度不适应怎么办

## 问题描述
换了新桌子后瞄准不适应，flick过头、跟枪抖、微调不准。DPI/灵敏度/鼠标都没变，但手感完全不对。

## 核心结论
1. **本质是运动学链被打断**：桌子高度变1cm就改变肩-肘-腕角度，肌肉记忆需要重建
2. **先调椅子再调桌子**：椅子是身体基座，桌子围绕身体配
3. **5秒自测**：肩放松+肘90-100度时手刚好在鼠标上 = 合格
4. **适应期1-4周**：期间分数下降正常，不要改DPI补偿
5. **FPS特化影响**：跟枪最先受影响（肩紧张→不平滑），flick距离感知偏差，微调使不上劲
