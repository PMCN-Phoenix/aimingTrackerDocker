### 数据质量问题（上传前建议处理）

1. **伪 measurement**：`scenario=1w2ts reload smallflicks larger` —— 某次写入少了 measurement 前缀，整行被解析成 measurement 名，应删除。
2. **三张成绩表并存**：`kovaak_score`（主用，1729）/ `aim_scenario`（2358）/ `kovaaks_score`（40）语义重叠，`vdim_score`（754）也可能部分重叠。合并前必须先确认去重口径。
3. **`list` tag 只有 2 个值**：`viscose-s2-easier`、`strafe-aiming-day9`。LG56 热身（92 条）全被标成 `viscose-s2-easier`——按约定是有意为之，但语义上不对，上传后如果要做正式分析建议新建 `list=lg56-warmup` 或加 `source` tag。
4. **`aim_daylist_item` 空表**、`????` 场景名 1 个（142 个 scenario tag 之一）。
5. **time 精度**：`aim_bench_row`、`aim_bench_meta` 只有 2026-10-19 一个时间点（快照式写入，非时序）。

### 时间口径提醒

InfluxDB 存的是 **UTC**，看板和人工核对都按 **+8h** 换算（`kovaak_score` 最后一条 `2026-10-19T15:55Z` = 本地 10-19 23:55）。

## 六、上传/备份的建议打包单元

按"恢复一个能跑的系统"最小完备集：

| 优先级 | 内容 | 体积 | 方式 |
|---|---|---|---|
| P0 | InfluxDB `aim` bucket 全量 | 68 MB 目录 / 导出 CSV 约 15–20 MB | `influx backup` 或 Flux→CSV 按 measurement 导出 |
| P0 | `grafana_data/grafana.db` + `grafana/provisioning/` | 16 MB | 直接拷文件（先停容器，避免 SQLite 写中断） |
| P1 | Kovaak stats CSV 34 天 | 5.7 MB | 直接打包（这是**源头数据**，可重放重建 `kovaak_score`） |
| P1 | `docs/`（问题库+记录+日记+清单） | 189 MB | 已在 git，双远程已有 |
| P2 | `nodered_data/`（flows + cred） | 7.6 MB | 需同时保存 `flows_cred` 的加密 key |
| P3 | InfluxDB `/etc/influxdb2` 配置卷 | 8 KB | 含 CLI configs，重建 token/org 时省事 |

**不必上传**：`node_modules/`、`__pycache__/`、`grafana_data/plugins/`（可重拉）、`influxdb_data/wal/`（若是全量备份则包含，若是导出 CSV 则不需要）。
