# 训练日记

> 模块定位：记录「打的过程中」的即时体验与突破感（区别于 `docs/记录/游戏感悟/` 的复盘型感悟、区别于 `docs/问题库/` 的调研结论）。
> 每天一个文件：`YYYY-MM-DD.md`，条目按时间顺序追加。
> 每条必须带**准确时间戳**（来自 Kovaak's stats 文件名，格式 `场景名 - Challenge - YYYY.MM.DD-HH.MM.SS Stats.csv`）。

## 条目格式

```
## HH:MM–HH:MM ｜ 场景名

- 轮次与成绩：来自当天 stats CSV（Score / Hit / Miss）
- 内容：当时的体验原文
- 关联：问题库 / 感悟 / 其他日记条目（可选）
```
