## 二、逐项详解

### 1. VSS Thin Aiming Long Raspberry Easy ×2 ｜ 16855 / 16855

- **✅《变向跟枪核心：反应而非预测》**（Voltaic 官方文档摘录）：
  - 「**反应，而非预测**（focus on reacting not predicting）——不要去猜目标什么时候变向，等目标真的变向了，再快速反应」
  - 「**快速反应 + 平滑过渡**：反应之后要立刻过渡到平滑的跟枪动作」
  - 「**眼睛盯目标，不是盯准星**——准星只是工具，目标才是信息来源」
- **✅《Air 场景训练法》**：变向间隙保持平滑、变向瞬间快速修正但**不要过度甩枪**、修正后立刻回到平滑
- **含义**：VSS = 垂直细目标长条，变向幅度小但要求极高平滑度。你在这里没有掉分（持平），说明"变向间隙平滑"这一半已经稳了

### 2. Midrange Long Strafes Invincible ×2 ｜ 13896 / 14958（−7.1%）

- **◐《变向处理双模式：方案1 精确跟 + 方案2 大致跟》**（B站教学整理）：
  - 「目标直线移动时用**方案1 精确跟枪**，准星紧贴目标拿分——这是主要得分模式」
  - 「目标突然变向时切换到**方案2 大致跟枪**，只要大致跟上方向、不跟丢就行」
  - 「**变向不可怕，可怕的是变向后一直处于方案2，切不回方案1**」
- **含义**：Long Strafes 是慢速长距离横移，变向不频繁 → 几乎全程应该是方案1。掉 7% 通常不是跟不上，而是**变向那一下多做了修正**（跟枪进阶里说的"变向后一直修正、不放松"）

### 3. Midrange Short Strafes Invincible Raspberry Easy ×3 ｜ 5496 / 5976（−8.0%）

- 同 #2 的双模式，但短距离横移变向更密 → **方案2 的停留时间会变长**，切回方案1 的时机就是分数差
- **◐《跟枪进阶：不要抢着猜变向》**：
  - 「❌ 抢着猜变向：目标还没变向，你就提前移动了」

  - 「❌ 过度甩枪：变向时甩过头，还要再修正回来」
