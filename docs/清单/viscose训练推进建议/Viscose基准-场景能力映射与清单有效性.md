## 一、场景 → 能力：完整映射（核心交付）

### 1.1 先说骨架：4 大类、14 子类，各练什么

Viscose 官方定义（`BV1fuyZBqEux`，逐字整理）：

#### CONTROL TRACKING（控制追踪）—— 他称之为"你的基础"

> "任何需要对**可阅读但非线性移动**的目标进行精确跟踪的场景。不过此类别最重要的部分是**目标改变方向时发生的情况**……这是一个渐进的过程，目标需要一段时间才能达到最大速度，这也促使我们在修正方向变化时更加谨慎。"

**4 个子类 = 按"哪个肌肉群主导"分**（这是这个类别的组织逻辑）：

| 子类 | 练什么（Viscose 原话/转述） |
| --- | --- |
| **Arm（手臂）** | 大幅度平滑追踪。"**如果你在将手臂融入瞄准方面有困难，使用更慢的灵敏度仍然可以迫使你学习更多地运用它。**" |
| **Wrist（手腕）** | 中等幅度、高精度修正。"**手腕移动时，手腕带动手指。**" |
| **Fingertip（指尖）** | 最小幅度、最高精度。"**指尖带动手腕移动。它比单纯使用手腕能提供更高的精度**，最好用于配合较大的手腕动作。" |
| **Blending（混合）** | **三个肌群的无缝过渡**。"**单个移动通常需要同时使用所有三个肌肉群，在切换它们之间甚至同时用它们做不同事情时没有明显的延迟。**" |

⚠️ 三条他特别强调的、很多人搞错的：

1. **"你不必使用指握握法才能运用指尖瞄准"** —— 指尖瞄准有两种：①（pinguefy 型）手指随鼠标移动、物理拖动推拉；② 指尖看起来静止，但对鼠标施压
2. **子类名字规定的是"主要依赖"的肌群，不是"唯一使用"的肌群** —— "我实在想不出有什么瞄准场景只用到一组独立的肌肉"
3. **动作的通用结构是**：**较小的肌群先启动动作，然后较大的肌群继续并完成后续动作**

| 子类 | 练什么 |
| --- | --- |
| **Control** | "你**修正的一致性和准确性**，同时仍需要一定水平的速度" |
| **Speed** | "要求你**在更高速度下进行调整时具备良好的控制水平**" |

> 他的核心一句：**"我仍然相信你调整的一致性才是这里最重要的技能。如果你大部分修正回目标的动作都没能跟上，你需要放慢速度，直到你建立起能稳定完成这些修正的能力。"**

> "这些场景类型都以不同的方式提升**同一项技能**……我认为在这里合并它们是合理的"

| 子类 | 练什么 |
| --- | --- |

### 1.3 一条关键规律（这条解释了你"看不懂在练什么"）

**同一个子类里的 2–3 个场景不是重复，是"同一个能力的三个难度/三种形态"。**

拿你的 Arm 举例：

```
SmoothBot    = 纯平滑，几乎不变向      → 练"能不能一直贴住"
Smoothsphere = 球形轨迹，持续移动      → 练"持续不中断"
Whisphere    = 大弧线 + 大幅度         → 练"大幅度下还稳不稳"
```

**它们共用一个子类档位**（该子类最高分场景决定）。所以：
- **从"练能力"看**：三个都要碰，因为它们暴露的是同一能力的三个不同失效点
- **从"升档"看**：只要其中一个过线就行

**这就是你感觉"清单指向性不明确"的机制性原因** —— 同一子类里选哪个场景都能升档，但**练到的东西不一样**。而我一直只按"哪个便宜"选。

### 1.4 关于"看哪个分说明什么"

Viscose 明确说过一句反直觉的：

> "**瞄准是一种技能……所有瞄准都是——解读你所见的，然后移动你的手去匹配。这个定义不区分不同种类的瞄准。**
> 这就解释了为什么**练习跟踪能改善你的点击时机**，尽管这两者看起来完全不相关……**静态练习提高了我的动态，目标切换提高了我的跟踪。我经常发现，即使好处并非立即（显现），练习其他类型的场景也会帮助提升我最擅长的项目。**"

→ **所以"这个场景和我不打的项目无关，所以不用练"是新手最常见的错误之一**（他的原话见 §三.1）。

## 二、"这份清单有没有效"—— 三层检验标准

⚠️ 先说一个前提，Viscose 反复强调：

> "**在某事上变得更好不是线性的 —— 会有那么一些时候，你会暂时变得更糟，然后（才变好）。**"

所以"这两天没涨"不能作为无效证据。下面三层，**每层的观察窗口不同**。

### 2.1 每 1 次训练（过程指标，当次就能判）

| 看什么 | 有效 | 无效信号 |
| --- | --- | --- |
| **动作质量** | 能说出"我刚才是平滑贴上" | 全程"甩到位再修"却说不出哪一轮是干净的 |
| **命中率 vs 分数的方向** | 命中率先动，分数滞后 | 分数涨了但命中率没动 → 你在靠"多打"或"预判"挤分 |
| **出手数**（点击类） | 出手数稳定/上升，命中率也上升 | 出手数掉了、命中率涨了（**Day1 的 Pasu 就是这样，净收益≈0**） |
| **超射数 Overshots** | 稳定或下降 | 上升 = 修正过大（"来回摆"的量化信号） |
| **能不能回答"这个场景在逼我改什么"** | 能 | 不能 → **你在自动驾驶**（Viscose 2020 年就是死在这） |

### 2.2 每 2 周（能力指标）

- **该子类的所有场景是否同步变好**，而不是只有一个场景涨
  → 只有撑杆场景涨 = 你在"打这一个场景"，不是在"练这个能力"
- **命中率是否跨场景普涨**（例：跟枪类三个场景的命中率一起从 25% → 32%）
- **子类档位是否真的动了**

### 2.3 每月（方法指标）

- **我练的子类顺序，是不是"谁最弱先练谁"**？（对比 §四：你现在的顺序是"谁最便宜先练谁"）
- **有没有一个能力是"三个月没碰过"的**？（你的 `cloverRawControl` 41.4%、`Popcorn` 20.0% 就是——它们从 9/16 摸底后**一次没碰**）
- **换过几次清单**？固定 2 个月以上没换 = 该换了

### 2.4 ★ 你担心的"分数涨了实战没变"—— Viscose 的正面回答

他承认这个阶段真实存在：

> "**如果你已经练了几个月瞄准训练，也看到了一些（进步），却很难将这种进步转化到实战中，甚至可能技能下滑或游戏排名下降？** 我认为这就是很多对瞄准训练器持善意怀疑的人达到的阶段。他们达到了不错的技能水平，遇到了瓶颈，然后放弃了。"

他的解释与解法：

> "**最深刻的弱点识别来自于由平台期引发的领悟。**"
> "**你必须把平台期看作成长的机会，而不仅仅是一种你当前所处的状态。**……这种最常见的原因是**平台期本身就是那种成长**——当你第一次扩展你的知识并尝试实施新的（东西）融入你的游戏过程，**可以预期你的整体表现有所下降**。"

他举了个自己的例子：改用拇指按空格键（客观更好的技巧），**当时打字各方面都变差了**——"**这并非技术让我变差**"。

## 三、排布方法论：为什么这个顺序、这个轮数

### 3.1 先看反面教材：Viscose 本人 2020 年怎么失败的

- 照着**通用清单**（15 个场景 × 每天 4 遍 × 1 小时）
- 两周后**放弃**："它确实在帮我提高，但进步没有预期的那么大"，而且"**每天重复同样的场景太无聊，与在游戏中的训练相比似乎不值得**"
- 根本原因（他的原话）：**"我在自动驾驶着，没有思考我在做什么，也没有想为什么这么做。"**

### 3.2 他的转变：**死板清单 → 动态选择**

### 3.3 排布的 5 条硬规则

| # | 规则 | 依据 |
| --- | --- | --- |
| 1 | **主项 = 当前最弱的子类**，不是"最容易升档的子类" | §3.2 的循环 |
| 2 | **一次只攻 1 个子类**，但要攻它的**多个场景** | §1.3：同子类不同场景暴露不同失效点 |
| 3 | **热身用强项、不用弱项**；**弱项要更长校准**（你的数据：跟枪前 5 轮均值比后 3 轮低 16%+） | 你自己的实测 |
| 4 | **"更难"≠"更有用"** | ★原话："**更简单的场景奠定基础并帮助你完善技术，因为潜在的错误来源减少了。更难的场景确保你能保持那种良好的技术**" |
| 5 | **每次只留一个"长期最弱项"占 10–15%**，哪怕它当天不可能过线 | 否则它会像 `cloverRawControl` 一样被永远跳过 |

**便宜的线不该当主项，该当"收尾确认"。** 它们的作用是：**验证你这个子类是不是真的通了**，而不是**用它来练那个子类**。

### 7.1 现在的清单要改三件事

| # | 问题 | 改法 |

### 7.2 新的 1 小时骨架（把"热身/主项/归因"分开）

```
热身   8 min   →  2 个点击类强项场景（只求手醒，不追分）
主项  30 min   →  1 个子类，但打它的 2–3 个场景（不要只打一个）
                   前 1/3 轮 = 校准段（刻意慢速、不看分）
                   后 2/3 轮 = 追分段
最弱项 6 min   →  长期最弱项 ×4，只练动作、不看分
归因   8 min   →  ①最低分/最低命中率的场景 ②"平滑贴上"还是"猛甩再修"
                   ③这个场景逼我改的一个具体动作 ④明天换哪个子类
复习   8 min   →  （每周 1–2 次）慢放看自己最近一次录屏
```

> ⚠️ **如果你当天还要打瓦**：按 §6.5 的共识，**练完枪不要立刻去排位**（练枪消耗精力，状态会很差）。时间紧就把这 1h 放在排位**之后**，或者练完休息一段再打。

### 7.3 每次要记的三个数（30 秒，用于 §6.3 的判据）

1. **今天最低命中率的场景** + 它的命中率
2. **超射数**（跟枪类）—— 比分数更早反映技术变化
3. **一句归因**：今天这个场景逼我改的一个具体动作

### 7.4 换清单的判断（写死，别再凭感觉）

| 触发 | 动作 |
| --- | --- |
| 同一场景打满 **2 周**，命中率/超射数都没趋势 | **换同子类的另一个场景**（不是加轮数） |
| 说出"**我好像习惯这套场景了**" | **立刻换**（§6.8） |
| 某个卡口过了 | 该子类降为维护（4 轮），主项换新的最低档子类 |
| 连续 2 周觉得机械/无聊 | **最危险信号**（Viscose 当年在这放弃）→ 换场景 + 换 BGM/环境 |
